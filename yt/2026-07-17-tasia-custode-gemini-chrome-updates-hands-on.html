TL;DR

이 영상은 Google Chrome에 통합된 Gemini의 최신 기능을 실무 데모를 통해 소개한다. 새로운 사이드 패널부터 웹 이미지 변환, 연결된 앱 연동, 그리고 브라우징 작업을 자동으로 처리하는 에이전트 기능까지, Gemini가 사용자의 멀티태스킹과 정보 검색 방식을 어떻게 변화시키는지 구체적인 사례로 설명한다.

풀시청 판단

이 영상은 Google Chrome에서 Gemini의 새로운 AI 기능을 활용해 생산성을 높이고 싶은 사용자에게 매우 유용하다. 특히 AI 비서가 단순 정보 검색을 넘어 실제 브라우저 작업을 대신 수행하는 '에이전트 기능(agentic capabilities)'에 관심이 있다면 풀시청할 가치가 크다.

영상은 [0:26]부터 [3:00]까지 새로운 사이드 패널의 기본적인 활용법을 설명하며, 이어서 [3:07]부터 [3:40]까지는 이미지 변환 기능인 ‘nano-banana’를 소개한다. 영상의 핵심은 [3:52]부터 시작되는 Gemini의 에이전트 기능으로, 연결된 앱을 통한 이메일 작성 및 웹 페이지 내 자동 탐색 기능이 중심이다.

다만 이 영상은 소개 및 데모에 집중하므로, 각 기능의 기술적 원리나 심층적인 활용 팁보다는 전반적인 기능 시연과 “무엇을 할 수 있는지”를 보여주는 데 중점을 둔다. 현재 기능의 가용성은 미국 내 특정 운영체제와 구독자에게 한정되어 있으므로 [8:36]부터 [8:48]까지의 내용을 확인해야 한다.

핵심 내용

Chrome에 내장된 Gemini 사이드 패널: 브라우징 중 질문과 멀티태스킹 [0:26]

Chrome의 새로운 사이드 패널은 현재 보고 있는 탭과 관련 있거나 전혀 다른 질문을 Gemini에게 던질 수 있게 한다. 예를 들어, 여행 사이트 Viator에서 걷기 여행을 찾을 때, Gemini에게 2시간 이내, 오전 9시 이후 시작, 평점 높은 조건으로 검색을 요청하면, Gemini는 해당 조건을 만족하는 세 가지 투어 옵션과 관련 링크를 사이드 패널에 정리해 보여준다 [0:49]. 이 기능을 통해 사용자는 일일이 수동으로 정보를 찾아볼 필요 없이 원하는 내용을 빠르게 파악할 수 있다.

사이드 패널은 여러 탭을 오가며 작업할 때도 유용하다. Gemini가 한 탭에서 정보를 수집하는 동안 [1:26], 사용자는 다른 탭으로 이동해 다른 작업을 처리할 수 있다. 예를 들어, 투어 검색 중 다른 뉴스 탭을 확인하다가 다시 돌아와 Gemini와의 대화를 이어갈 수 있다 [1:52]. 또한, 한 탭에서 시작된 대화를 다른 탭으로 옮겨 계속 진행할 수도 있고 [2:11], 여러 탭의 내용을 하나의 채팅 안에서 비교하는 것도 가능하다 [2:30].

nano-banana를 이용한 웹 이미지 변환 [3:07]

Gemini in Chrome은 'nano-banana' 기능을 통해 웹 페이지의 이미지를 직접 변환할 수 있다. 예를 들어, 아파트 사진에서 소파를 특정 스타일(예: "모던한 회색 섹셔널 소파")로 바꾸고 싶을 때, Gemini에게 요청하면 몇 초 만에 다른 모든 요소는 그대로 둔 채 소파만 새로운 이미지로 교체해 보여준다 [3:15]. 이 기능은 사용자가 웹에서 공간이나 제품의 모습을 즉석에서 시각화하고 상상하는 데 도움을 준다.

연결된 앱을 활용한 에이전트 기능 [3:52]

Gemini in Chrome의 에이전트 기능은 Gmail, Gcal, Google 지도, Google 항공편, Google 쇼핑, YouTube 등 연결된 Google 앱과 연동하여 작업을 수행한다. 예를 들어, 특정 투어 세부 정보를 Brett에게 이메일로 보내달라고 요청하면 [4:02], Gemini는 Gmail 정보를 활용해 Brett이 누구인지 파악하고, 필요한 정보를 담은 이메일을 자동으로 작성해준다. 사용자는 Chrome 안에서 이메일을 바로 수정하고 보낼 수 있어, 앱 간 이동 없이 작업을 완료할 수 있다 [4:19]. 이 기능은 멀티태스킹을 단순화하고 워크플로우를 효율적으로 만든다.

Autobrowse 기능: Gemini가 직접 웹 페이지 탐색 및 작업 수행 [5:01]

Gemini는 이제 사용자를 대신하여 웹 페이지를 직접 탐색하고 특정 작업을 완료하는 'Autobrowse' 기능을 지원한다. 예를 들어, 항공편 검색 중 각 항공편의 경유 시간을 확인하려면 원래는 수동으로 클릭해야 한다. 하지만 Gemini에게 요청하면 [5:14], Gemini가 탭의 제어권을 가져와 필요한 링크를 자동으로 클릭하고 경유 시간 정보를 사이드 패널에 추가해준다 [5:37].

이와 유사하게, 레스토랑 예약 요청 시 [6:11] Gemini는 자동으로 탭을 제어하여 가능한 예약 시간을 찾아준다 [6:25]. Gemini가 백그라운드에서 작업하는 동안 사용자는 다른 탭에서 계속 작업을 할 수 있으며 [6:38], 작업 완료를 위해 사용자 승인이 필요할 경우 "작업 확인(Check your task)" 알림을 통해 알려준다 [7:00]. 예약이나 구매와 같이 중요한 작업은 사용자의 최종 확인 없이는 진행되지 않아 [7:29] 제어권을 항상 사용자가 가진다.

주요 통찰·논점

브라우징 경험을 근본적으로 바꾸는 '에이전트 AI'의 등장

Gemini in Chrome의 핵심적인 변화는 사용자가 직접 웹을 탐색하고 정보를 찾던 방식에서, AI가 사용자의 의도를 이해하고 직접 웹 페이지 내에서 작업을 수행하는 '에이전트 AI' 모델로 진화한다는 점이다. 이는 단순한 정보 검색 도구를 넘어, 브라우저를 사용자의 개인 비서로 탈바꿈시켜 반복적이거나 복잡한 온라인 작업을 자동화하고 효율적으로 처리할 수 있게 한다. 특히 Autobrowse 기능은 사용자의 마우스 움직임 없이도 웹사이트를 탐색하고 데이터를 추출하는 모습을 직접 보여주며, 미래의 웹 인터랙션이 어떻게 바뀔지 시사한다 [5:37].

멀티태스킹의 확장과 작업 흐름의 연속성

새로운 Gemini 기능은 사용자가 여러 작업을 동시에 효율적으로 처리할 수 있도록 돕는다. 사이드 패널을 통해 Gemini가 백그라운드에서 정보를 검색하거나 작업을 수행하는 동안 [1:26], 사용자는 다른 탭에서 별도의 활동을 할 수 있다. 또한, 연결된 앱과의 통합은 이메일 작성과 같은 작업을 Chrome 내에서 바로 처리하게 하여 [4:19], 여러 앱을 오가는 번거로움을 줄이고 작업 흐름의 연속성을 유지한다. 이는 디지털 환경에서의 생산성을 획기적으로 향상시킬 잠재력을 보여준다.

사용자 제어권과 보안의 균형

에이전트 AI가 브라우저 제어권을 가져가는 기능은 편리함과 동시에 보안 및 통제에 대한 우려를 낳을 수 있다. 그러나 Gemini는 이러한 점을 인지하고 Autobrowse 기능 첫 사용 시 사용자에게 제어권 행사 여부를 묻고 [6:02], 예약이나 구매와 같이 중요한 결정에는 반드시 사용자의 최종 확인을 요구한다 [7:29]. 또한, 진행 중인 작업을 언제든지 일시 정지하고 수동으로 제어할 수 있는 옵션을 제공한다 [6:32]. 이는 AI의 자동화된 편리함과 사용자의 명확한 제어 및 승인 사이에서 균형을 맞추려는 시도로 풀이된다.

모든 대화 및 생성 콘텐츠의 영구 저장

Gemini in Chrome에서의 모든 대화 내용은 자동으로 저장되며, 이는 사이드 패널의 최근 채팅 목록이나 Gemini 웹사이트(gemini.Google.com)에서 접근할 수 있다 [7:45]. nano-banana 기능을 통해 생성된 이미지 또한 저장된 채팅 기록에 포함된다 [8:16]. 이는 사용자가 이전에 진행했던 작업과 생성물을 쉽게 다시 참조하고 관리할 수 있게 하여, AI와의 상호작용 기록이 개인의 디지털 자산으로 기능하도록 한다.

인상적인 지점

Gemini가 직접 웹 페이지를 탐색하는 Autobrowse 기능 시연 중, 화자가 마우스에서 손을 떼고도 Gemini가 자동으로 항공편 정보를 클릭해 경유 시간을 찾아내는 모습은 미래의 브라우징 경험을 직관적으로 보여주며 가장 인상 깊은 장면이었다 [5:45]. 이는 AI가 단순히 정보를 찾아주는 것을 넘어 실제 브라우저 내에서 행위를 수행하는 '능동성'을 실감하게 했다.
