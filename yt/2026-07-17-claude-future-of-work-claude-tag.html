The future of work with @Claude

TL;DR

이 영상은 엔트로픽(Anthropic)의 새로운 협업 AI 도구인 Claude Tag을 소개한다. Claude Tag은 기존의 반응형 AI와 달리 작업 채널에 상주하며 능동적으로 작업을 수행하고, 사용자의 지시를 장기적으로 기억하며, 여러 사용자가 협업하여 결과물을 개선할 수 있도록 돕는다. 이를 통해 개발 팀의 생산성을 혁신하고, AI 활용 방식을 변화시키는 새로운 협업 환경을 제시한다.

풀시청 판단

이 영상은 Anthropic의 새로운 AI 도구인 Claude Tag이 어떤 문제를 해결하고 어떻게 사용되는지 명확하고 구체적인 사례를 들어 설명한다. AI 에이전트의 발전 방향과 실제 업무 적용 사례에 관심 있는 기술 관리자, 개발자, 제품 관리자(PM) 등 지식 근로자에게 유용하다. 특히 AI를 활용한 팀 협업 및 생산성 향상 방안을 모색하는 이들에게 Claude Tag의 능동성, 장기 기억, 다중 사용자 기능은 좋은 통찰을 제공한다.

다만, 이 영상은 Claude Tag에 대한 소개 및 홍보 영상이므로 기술적 깊이가 깊지 않다. 내부 작동 방식보다는 기능과 활용 사례에 집중하며, 다소 낙관적인 전망을 제시한다. Claude Tag의 잠재적인 한계나 고려해야 할 점에 대한 언급은 부족하다. 이미 AI 에이전트 개념에 익숙한 사람에게는 새로운 정보가 제한적일 수 있다.

이런 분에게 추천한다:

  • 협업 환경에서 AI 에이전트 도입을 고민하는 제품 관리자 및 팀 리더
  • AI를 활용한 개발 생산성 향상에 관심 있는 개발자
  • AI 도구의 진화와 실제 비즈니스 적용 사례를 알고 싶은 사람

이런 점은 약점이다:

  • 제품 홍보 영상의 성격이 강해 객관적인 평가보다는 장점 부각에 초점을 맞춘다.
  • 기술적인 세부 구현 방식보다는 기능적 설명에 머무른다.
  • AI 에이전트의 오작동, 제어의 어려움 등 잠재적 위험에 대한 논의가 없다.

핵심 내용

AI 지원 방식의 두 가지 큰 도약: 코드 생성에서 자율 작업까지

지난 2년간 AI 지원 방식은 크게 두 번 도약했다. 초기에는 개발자가 코드를 한 줄씩 입력하면 AI가 자동 완성(typeahead)을 돕는 수준이었다 [0:26]. 이후 Claude Code와 에이전트(agent) 도입으로 AI는 전체 함수, 파일, 나아가 기능 전체를 작성하는 수준으로 발전했다 [0:51]. 이제 Claude Tag의 등장으로 AI는 기능 작성은 물론, 전체 실험을 처음부터 끝까지 수행하고 데이터 분석까지 도맡아 하는 단계에 이르렀다 [1:01]. 이 변화는 사람이 항상 개입하는 방식에서 Claude가 더 주도적으로 작업을 이끌고, 한 명의 사용자뿐 아니라 팀 전체가 AI와 협업하는 형태로 진화했음을 의미한다.

Claude Tag의 핵심 기능: 능동성, 장기 기억, 다중 사용자 지원

기존의 Claude는 사용자가 직접 호출하고 지시해야만 작업했다. 하지만 Claude Tag은 채널에 추가되면 능동적으로 상황을 파악하여 개입한다 [1:50]. 며칠 또는 몇 주가 걸리는 장기 실행 작업도 스스로 수행하고 후속 조치까지 취한다 [1:56]. 또한, Claude Tag의 가장 중요한 특징은 장기 기억력이다. 이전에는 매번 지시를 반복해야 했지만 [2:07], 이제는 채널에서 받은 모든 지시를 영구적으로 기억하고 다음에 적용한다 [2:25]. 뿐만 아니라, Claude Tag은 다중 사용자(multi-player) 환경을 지원하여 여러 팀원이 함께 상호작용하며 결과물을 개선할 수 있도록 돕는다.

Claude Tag을 가능하게 한 기술적 발전: 장기 실행 및 기억력

Claude Tag의 뛰어난 성능은 모델의 장기 실행 능력과 기억력 향상 덕분이다. 최신 모델은 한 번에 최대 16시간 동안 작업을 수행할 수 있으며 [2:42], 스스로 작업을 계획하고 후속 조치를 예약하여 며칠, 몇 주, 심지어 몇 달에 걸친 복잡한 실험도 자율적으로 처리한다 [3:04]. 또한, 모델은 사용자들의 지시를 오랜 시간 동안 기억할 뿐만 아니라 스스로 알림을 설정하고 특정 채널의 지침을 영구적으로 기억하여 다음 작업에 적용한다 [3:37]. 이처럼 Claude Tag은 필요할 때 개입하고, 불필요할 때는 뒤로 물러나며, 사용자의 피드백에 따라 행동을 조정하는 공감 능력(EQ)까지 갖추고 있다 [4:34].

Claude Tag 활용 사례: 개발 및 비개발 업무 자동화

Claude Tag은 다양한 업무에 활용되며 새로운 활용 방식(emergent stuff)을 만들어내고 있다. 예를 들어, 풀 리퀘스트(PR) 작성, 운영 환경 문제 디버그, 데이터 분석 등을 수행하며 [4:58], Q&A 채널에서 질문에 답하고 답변 완료 시 체크 표시를 남기는 등의 자동화된 업무 처리도 가능하다 [5:19]. 데이터 관련 질문이나 Claude Code 피드백 채널에서는 Tag이 초기 답변과 문제 해결을 전담하기도 한다 [5:24]. 제품 관리자(PM)는 여러 기능의 상태를 모니터링하고 일일 보고서를 받는 데 Claude Tag을 활용한다 [8:28]. 심지어 신입 사원이 법무 팀이나 인사 팀에 질문하기 전에 Claude Tag을 통해 사내 정보원 파일(source-of-truth files)에서 빠르게 답변을 얻는 데도 사용된다 [8:36].

주요 통찰·논점

Claude Tag과 기존 도구의 차이: 능동성과 다중 사용자 환경

기존의 AI 도구(Chat, Cowork, Claude Code)는 사용자가 직접 열고 지시해야 하는 '반응형 경험'을 제공했다 [6:46]. 반면 Claude Tag은 채널에 상주하며 '상위 목표(higher-level objective)'만 주면 스스로 작업을 수행하는 '능동형 경험'을 제공한다 [6:55]. 예를 들어, 채널의 모든 버그에 대해 풀 리퀘스트를 작성하라는 지시만 하면 Claude Tag이 알아서 모든 작업을 처리한다 [7:00]. 또한, 대부분의 AI 도구가 개인과 AI의 일대일 작업 방식이라면, Claude Tag은 여러 사람이 함께 AI 세션을 이끌어 더 나은 결과물을 도출하는 '다중 사용자(multi-player)' 환경을 제공한다 [7:10].

Claude Tag이 업무 환경을 바꾸는 방식: 협업, 학습, 생산성 향상

Claude Tag은 개인의 생산성을 넘어 팀과 조직 전체의 업무 방식을 변화시킨다 [11:07]. 공개 채널에서 작동하기 때문에 숙련된 사용자가 Claude Tag을 활용하는 모습을 다른 팀원들이 관찰하며 AI 활용 모범 사례(best practices)를 빠르게 학습하고 새로운 프로젝트에 적용한다 [6:04]. 또한, Claude Tag은 사용자들의 지침을 들으며 학습하고 더욱 효과적으로 협업하는 방법을 개선한다 [7:40]. 이는 팀 전체가 풀 리퀘스트와 같은 결과물을 공동으로 미세 조정하여 최고의 상태로 만들 수 있게 함으로써, 한 사람의 의견에 갇히지 않고 더 나은 최종 결과물을 얻을 수 있도록 돕는다 [7:46]. 코드베이스(code base) 기여에 대한 진입 장벽도 낮춰, 터미널이나 Git 작업에 익숙하지 않은 사람들도 쉽게 참여할 수 있게 한다 [8:02].

Claude Tag의 도입이 가져온 압도적인 생산성 증가

Claude Tag은 회사 전체의 생산성을 크게 높였다. 특히 제품 조직(product org)에서는 작성된 풀 리퀘스트의 약 65%가 Claude Tag에 의해 생성되고 있으며 [9:11], 이 수치는 계속 증가하는 추세다. Claude Code도 엔지니어의 속도를 높였지만, Claude Tag은 엔지니어들이 훨씬 더 빠르게 작업할 수 있게 만든다 [9:22]. 이는 Tag에게 작업을 맡기고 다음 업무로 넘어갈 수 있기 때문에 가능하다 [9:29]. Claude Tag은 간단한 버그 수정이나 데이터 질문부터 시작해 점차 더 복잡한 작업까지 처리할 수 있게 진화하고 있다 [9:56]. 이는 Tag이 엔지니어들이 사용하는 원격 샌드박스(remote sandbox)와 동일한 에이전트 SDK(Agent SDK)를 사용하여 작업의 정확성을 스스로 검증할 수 있기 때문이다 [10:20].

인상적인 지점

  • "이전에 할 수 있을 것이라고 믿지 못했던 작업을 이제는 거의 매번 해낸다." [3:08]라는 언급은 AI 에이전트의 신뢰성과 역량이 얼마나 발전했는지 보여준다.
  • 제품 조직에서 풀 리퀘스트의 65%를 Claude Tag이 작성한다는 통계는 AI가 단순한 보조 도구를 넘어 핵심적인 생산 주체로 기능하고 있음을 강력히 시사한다 [9:11].
  • Claude Tag이 채널에서 "항상 이것을 기억해라"라고 말하면 그대로 행동한다는 점 [5:52]은 AI의 장기 기억력과 사용자 맞춤형 반응의 강력함을 잘 보여주는 일화다.
  • 코드 기여를 두려워하는 사람들이 Claude Tag을 통해 쉽게 참여할 수 있게 되었다는 점 [8:02]은 AI가 기술 장벽을 낮추고 더 포괄적인 협업을 가능하게 하는 잠재력을 강조한다.
