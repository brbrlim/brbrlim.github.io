How are large language models trained?

Google for Developers10:09게시 2026-07-22브리핑 2026-07-30
AI · 테크#LLM#training#pre-training#fine-tuning#reinforcement-learning#evaluation#AI

TL;DR

이 영상은 대규모 언어 모델(LLM)이 유용한 조수처럼 작동하도록 훈련하는 실제적인 과정을 설명한다. 모델은 방대한 양의 텍스트로 다음 토큰 예측 작업을 통해 사전 훈련되고, 이후 지도 미세 조정(SFT)과 강화 학습(RL)이라는 두 가지 후속 훈련 단계를 거쳐 품질과 정렬을 개선한다. 마지막으로, 모델의 성능을 정량적으로 측정하고 평가하는 방법까지 다룬다.

풀시청 판단

이 영상은 LLM이 실제로 어떻게 훈련되는지에 대한 궁금증을 가진 사람, 특히 인공지능 분야 초보자나 개발자가 아닌 일반인에게 매우 유용하다. LLM 훈련의 핵심 개념인 사전 훈련, 지도 미세 조정, 강화 학습, 그리고 모델 평가 방법을 간결하고 명확하게 설명한다.

영상의 가장 큰 장점은 복잡한 기술적 내용을 쉬운 비유와 예시를 들어 설명한다는 점이다. 특히 SFT와 RL의 역할을 '최소 역량(floor) 설정'과 '최고 역량(ceiling) 끌어올리기'에 비유한 부분은 두 기법의 차이점을 직관적으로 이해하게 돕는다. 또한, 모델의 '도움이 되는' 특성을 어떻게 평가하는지 구체적인 기준과 '자동 평가기'(Auto Rater)의 개념을 제시하여, 단순한 정확성 이상의 복잡한 LLM 평가 문제를 잘 다룬다.

다만, 이 영상은 LLM 훈련의 큰 그림을 제시하며 깊은 기술적 세부 사항까지는 다루지 않는다. 각 훈련 단계에 사용되는 구체적인 알고리즘이나 병렬 처리, 보상 모델 훈련 방식 등 심층적인 내용을 기대한다면 다른 자료를 찾아봐야 한다. 하지만 LLM 훈련의 전반적인 과정을 빠르게 이해하기에는 탁월한 입문 자료가 될 것이다.

핵심 내용

LLM 훈련의 첫 단계: 방대한 데이터로 다음 토큰을 예측하는 사전 훈련

대규모 언어 모델(LLM)을 훈련하는 첫 단계는 사전 훈련(pre-training)이다 [0:32]. 이 단계에서 모델은 '다음 토큰 예측'이라는 작업을 수행한다 [0:37]. 이는 텍스트 시퀀스가 주어지면 다음에 올 단어를 예측하는 방식이다. 예를 들어, "몬스테라는 키우기 쉬운 집"이라는 문장이 주어지면, 모델은 "식물"이라는 단어를 예측하도록 훈련된다.

사전 훈련은 '자기 지도 학습(self-supervised learning)'의 일종이므로, 훈련 데이터셋 전체에 일일이 레이블을 달 필요가 없다는 장점이 있다 [0:49]. 대신, 공개된 방대한 양의 텍스트 데이터를 입력과 출력으로 나누어 사전 훈련 데이터셋을 만든다. 이를 통해 LLM은 다양한 입력에 걸쳐 언어 패턴, 글쓰기 스타일, 심지어 "몬스테라가 키우기 쉬운 식물"과 같은 세상의 지식까지 암묵적으로 학습한다 [1:28]. 그러나 수조 토큰에 달하는 방대한 데이터를 처리해야 하므로, 수천 개의 상호 연결된 GPU에 모델과 데이터를 분할하는 복잡한 병렬 처리, 자동 복구 시스템, 그리고 수 페타바이트에 달하는 데이터를 전처리하는 거대한 파이프라인이 필요한 대규모 엔지니어링 과제이다 [1:45].

사전 훈련 후 모델의 정렬과 품질을 높이는 후속 훈련: SFT와 RL

사전 훈련만 마친 모델은 광범위한 지식과 언어 이해력을 갖추지만, 실제 서비스에 바로 사용하기에는 예측 불가능하고 원하는 방향으로 정렬되지 않은 경우가 많다 [2:30]. 따라서 모델의 품질을 다듬고 '정렬(alignment)'에 초점을 맞춰, 생성되는 답변이 안전하고, 형식이 잘 갖춰져 있으며, 유용하고, 정확하며, 상호작용하기 좋게 만드는 후속 훈련(post-training) 단계가 필요하다 [2:53]. 이 후속 훈련은 주로 지도 미세 조정(SFT)과 강화 학습(RL)이라는 두 가지 전략을 포함한다 [3:07].

SFT: 모범적인 답변을 보여주며 모델의 최소 역량을 확보한다

지도 미세 조정(SFT) 단계에서는 모델이 학습하기를 원하는 행동을 보여주는 '황금 표준(gold-standard)' 상호작용 데이터로 모델을 훈련한다 [3:15]. 예를 들어, 모델이 질문에 친근하고 대화적인 방식으로 응답하도록 가르치고 싶다면, "글루텐 프리 머핀은 어떻게 만드나요?"와 같은 질문 프롬프트와 그에 상응하는 '도움이 되는 조수 스타일'의 답변으로 구성된 데이터셋을 만든다 [3:40]. 모델은 이 프롬프트를 입력받아 응답을 생성하고, 이 생성된 응답과 황금 표준 응답 간의 오차(loss)를 측정하여 모델의 가중치를 업데이트한다 [4:01].

이는 기본적인 기계 학습 모델 훈련 방식과 유사하며, 이상적인 예시를 보여줌으로써 모델이 원하는 행동에 부합하는 응답을 생성하는 방법을 학습하게 된다. SFT는 도구 사용법, 수학 문제 해결 능력 등 모델이 개선하기를 원하는 모든 능력에 적용될 수 있다 [4:21]. SFT는 모델의 '최소 역량(floor)'을 설정하여, 모델이 적어도 질문에 대한 답변, 코드 블록, 목록과 같은 기본적인 형식들을 이해하도록 보장한다 [5:27].

RL: 보상 모델의 피드백으로 더 나은 답변을 탐색하며 모델의 최고 역량을 끌어올린다

SFT는 모델이 '좋은 것'이 무엇인지 암기하도록 가르치지만, 새로운, 이전에 보지 못한 작업의 변형에 항상 일반화되지는 않는다 [4:40]. 이를 해결하기 위해 강화 학습(RL)이 도입된다 [4:57]. RL에서는 모델이 프롬프트에 대한 여러 응답을 생성하고, 별도의 '보상 모델(reward model)'이 이 응답들을 평가하여 점수를 매긴다 [5:06]. 보상 모델은 유용하고 안전하며 정확한 응답에 점수를 주고, 원치 않는 응답에는 벌점을 부여함으로써 모델이 원하는 행동 방향으로 나아가도록 유도한다 [3:28].

이 점수를 기반으로 LLM은 가중치를 업데이트하고 시간이 지남에 따라 개선된다 [5:11]. SFT가 큐레이션된 훈련 데이터만큼만 모델을 좋게 만들 수 있는 반면, RL은 수백만 가지의 다른 방식으로 프롬프트에 응답하며 더 높은 점수를 받는 응답만을 유지함으로써 이 데이터를 능가할 수 있도록 돕는다 [5:41]. 모델은 SFT 훈련 데이터셋에 없었던 더 효율적이거나 명확한 응답 방식을 스스로 찾을 수 있게 되며, 이를 통해 모델의 '최고 역량(ceiling)'을 높인다 [5:35]. SFT와 RL의 정확한 균형은 여전히 연구 중인 개방형 문제이다 [5:58].

LLM의 성공을 측정하는 방법: 다음 토큰 예측부터 복잡한 정렬 평가까지

모델 훈련의 모든 단계에서는 모델이 주어진 작업을 얼마나 잘 수행하는지 정량화할 방법이 필요하다 [6:27]. 사전 훈련에서는 모델이 다음 단어를 얼마나 잘 예측하는지를 측정하는 것이 비교적 간단하다 [6:40]. 하지만 후속 훈련에서는 모델이 지시를 얼마나 잘 따르고 안전하고 친근하며 도움이 되는 조수처럼 행동하는지, 즉 '정렬(alignment)'과 같은 더 추상적인 질문에 초점을 맞추기 때문에 측정이 훨씬 어려워진다 [6:54].

수학이나 코딩처럼 폐쇄적인 영역의 문제에서는 모델이 정답을 생성했는지 확인하여 능력을 평가할 수 있다 [7:07]. 그러나 '협력적인지', '통찰력 있는지', '도움이 되는지'와 같이 정량화하기 어려운 특성을 측정하려면, 이러한 용어들이 무엇을 의미하고 어떤 응답이 '좋은 응답'으로 간주될지에 대한 명확한 정의가 먼저 필요하다 [7:26]. 이 기준이 정의되면, 관련 프롬프트로 구성된 테스트셋을 큐레이션하고 모델의 응답을 이 기준에 따라 평가한다 [7:49]. 실제로는 이 과정을 사람이 전부 수동으로 하기보다는, 두 번째 LLM을 '자동 평가기(auto rater)'로 사용하여 채점을 위임하고 사람이 그 결과를 스폿 체크하는 방식으로 확장한다 [8:25]. 이 자동 평가기가 관련 프롬프트와 정의된 기준을 바탕으로 모델의 능력을 정량화하는 수치를 제공하며, 이를 통해 후속 훈련 과정의 진행 상황을 빠르게 추적할 수 있다 [9:00].

주요 통찰·논점

SFT는 '최소 역량'을 확보하고 RL은 '최고 역량'을 끌어올린다

LLM의 후속 훈련에서 SFT와 RL은 서로 보완적인 역할을 한다 [5:23]. SFT는 모델이 최소한의 역량(floor)을 갖추도록 보장한다. 즉, 모델이 목록, 코드 블록, 질문에 대한 답변 등 기본적인 형식과 원하는 행동 양식을 이해하게 한다. 이는 큐레이션된 모범 사례를 직접 보여줌으로써 모델을 '교육'하는 것에 가깝다. 반면, RL은 모델의 최고 역량(ceiling)을 높이는 역할을 한다. SFT가 제공하는 큐레이션된 데이터는 한계가 있지만, RL은 모델이 수많은 응답을 생성하고 보상 모델로부터 피드백을 받으며 더 효율적이고 명확한 응답 방식을 스스로 '탐색'하고 학습하게 한다. 이로써 모델은 초기 훈련 데이터를 넘어선 성능을 발휘할 수 있다.

대규모 언어 모델 훈련은 세 가지 핵심 기둥으로 구성된다

효과적인 대규모 언어 모델을 만들기 위해서는 세 가지 주요 기둥이 필요하다. 첫째는 방대한 양의 텍스트 데이터로 '다음 토큰 예측' 작업을 수행하는 사전 훈련이다 [9:14]. 이 단계에서 모델은 언어의 패턴과 세계 지식을 광범위하게 학습한다. 둘째는 사전 훈련된 모델의 품질과 일관성, 그리고 유용한 조수로서의 정렬을 다듬는 후속 훈련이다. 여기에는 지도 미세 조정(SFT)과 강화 학습(RL)이 포함되며, 모델이 지시를 따르고 안전하며 친근하게 응답하도록 만든다 [9:33]. 마지막 핵심은 이 모든 훈련 과정이 모델의 능력을 실제로 개선하는지 측정하는 효과적인 평가 체계이다 [6:23]. 특히 '도움이 되는' 같은 추상적인 개념을 정의하고, '자동 평가기'와 사람 검수를 조합하여 정량적으로 측정하는 방식이 중요하다.

LLM 평가는 단순한 정확성을 넘어 '정렬'이라는 복잡한 문제로 확장된다

LLM의 훈련 성공을 측정하는 것은 단순히 다음 단어를 맞히는 것(사전 훈련)에서 벗어나, 모델이 얼마나 '도움이 되고', '안전하며', '지시를 잘 따르는지'와 같은 '정렬' 특성을 평가하는 복잡한 문제로 발전한다 [6:54]. 이러한 추상적인 개념을 평가하려면, 먼저 각 특성에 대한 명확한 정의와 '좋은 응답'의 기준을 설정해야 한다 [7:32]. 그 후, 관련성 높은 프롬프트로 구성된 테스트셋을 사용하고, 사람의 판단을 보조하기 위해 또 다른 LLM을 '자동 평가기(auto rater)'로 활용하여 모델의 응답을 평가하는 전략을 사용한다 [8:37]. 이는 LLM의 실제 유용성을 판단하는 데 필수적인 단계이다.

인상적인 지점

  • 사전 훈련은 '대규모 엔지니어링 과제'이다: 단일 칩으로 너무 커서 수천 개의 상호 연결된 GPU에 모델과 데이터를 분할해야 하며, 충돌 처리 및 페타바이트급 데이터 전처리를 위한 복잡한 시스템이 필요하다는 설명은 LLM 훈련의 물리적, 기술적 규모를 실감하게 한다 [1:45].
  • SFT는 '최소 역량(floor)'을 설정하고, RL은 '최고 역량(ceiling)'을 높인다: 이 비유는 두 가지 후속 훈련 기법의 역할과 상호작용을 매우 직관적으로 설명한다. SFT가 기본기를 가르친다면, RL은 그 기본기를 바탕으로 창의적이고 뛰어난 성능을 발휘하도록 돕는다는 점이 인상 깊다 [5:27].
  • 두 번째 LLM이 '자동 평가기'로 작동한다: 모델의 '도움이 됨'과 같은 추상적인 특성을 평가하기 위해 또 다른 LLM을 심판(judge)으로 사용한다는 아이디어는 AI가 AI를 평가하는 현 시대의 흥미로운 단면을 보여준다 [8:37].
