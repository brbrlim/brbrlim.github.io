지금 실리콘밸리는 '여기'에 주목하고 있다 @김단테

신사임당40:53게시 2021-12-29브리핑 2026-06-22

TL;DR

김단테는 현재 실리콘밸리가 주목하는 Web 3.0 기술과 시장 동향을 소개한다. Web 3.0은 사용자에게 서비스 소유권과 투표권을 부여하는 탈중앙화된 인터넷 시대를 의미하며, 기존 주주 자본주의의 한계를 극복하고 네트워크 효과를 극대화하는 대안으로 제시된다. 이 영상은 Web 3.0의 개념과 P2E 게임, 탈중앙 금융(DeFi), 대체 불가능 토큰(NFT) 등 주요 사례를 설명하고, 관련 투자 전략으로 인프라(레이어 1) 프로젝트에 주목할 것을 제안한다.

풀시청 판단

이 영상은 Web 3.0의 기본 개념과 현재 시장의 주요 동향(P2E, DeFi, NFT)을 간결하게 파악하고 싶은 사람에게 유용하다. 실리콘밸리 내 Web 3.0에 대한 찬반 논쟁과 투자에 대한 초기 통찰을 얻을 수 있다. 특히 암호화폐 시장의 인프라 프로젝트에 대한 투자 관점을 제시하는 부분은 현재 시장을 이해하는 데 도움이 된다.

다만 영상의 자막 품질이 좋지 않아 일부 내용 이해에 어려움이 있을 수 있다. 음성 인식 오류로 보이는 단어들이 많고, 특정 사례나 용어에 대한 설명이 다소 불명확한 부분도 존재한다. 또한, 영상 제작 시점(2021년 말~2022년 초로 추정) 이후 많은 변화가 있었으므로, 현재 시점의 최신 정보를 반영하지 않는다는 한계가 있다. Web 3.0 초기 단계의 뜨거운 관심과 논쟁을 엿볼 수 있는 자료로 활용하는 것이 적절하다.

핵심 내용

Web 3.0: 사용자 소유권과 토큰 경제의 등장

Web 3.0은 인터넷 서비스의 소유권이 사용자에게 넘어오는 시대를 의미한다. 기존 웹 2.0 시대에는 사용자가 콘텐츠를 만들고 데이터를 제공했지만, 그 소유권과 수익은 플랫폼 기업에 집중되었다. Web 3.0은 이러한 불균형을 해소하고자 [3:24] 토큰을 통해 사용자에게 서비스의 지분과 유사한 소유권을 부여한다. 예를 들어, 페이스북에 글을 많이 쓰면 페이스북 주식을 받고, 카카오 택시를 많이 이용하면 카카오 택시 주식을 받는 식이다. 이러한 소유권에는 투표권이 포함되어, 사용자들이 서비스의 운영 방향이나 정책 결정에 직접 참여할 수 있다. 이는 [4:17] 단순히 콘텐츠 제작자에게 돈을 지급하는 유튜브의 방식보다 한 단계 더 나아가 서비스 네트워크 전체에 대한 소유권을 공유하려는 시도로 이해할 수 있다.

Web 3.0의 실례: P2E 게임과 탈중앙 금융(DeFi)

Web 3.0 개념이 가장 활발하게 적용되는 분야 중 하나는 Play-to-Earn (P2E) 게임이다. P2E 게임에서는 사용자가 게임 내에서 얻은 특정 아이템을 대체 불가능 토큰(NFT)으로 만들어 [5:32] 외부에서 거래할 수 있다. 또한, 게임 운영에 관한 중요한 의사 결정(예: 수수료율 설정)에 사용자가 투표권을 행사하기도 한다. 이는 주식과 유사하게 자산적 가치와 의결권을 동시에 갖는 형태다. 한국의 위메이드(Wemade)가 출시한 P2E 게임 미르4(Mir4)는 130만 사용자 [7:47]를 돌파하며 큰 성공을 거두었고, 이러한 성공은 내년에 더 많은 P2E 게임이 출시될 것이라는 기대를 낳는다.

탈중앙 금융(DeFi) 또한 Web 3.0의 핵심 분야다. DeFi는 [8:38] 기존 금융기관 없이 블록체인 기술을 기반으로 대출, 예금, 거래소 등의 금융 서비스를 제공한다. 탈중앙화 거래소를 이용하면 토큰을 분배받고, 이를 보유하면 거래 수수료의 일부를 배당처럼 받거나 [9:02] 거래소 운영에 대한 투표권을 행사할 수 있다. 이러한 메커니즘은 사용자에게 인센티브를 제공하여 서비스 참여를 유도한다. DeFi 시장의 예치 자산 규모는 [16:36] 전년 대비 1600% 증가하여 현재 3,000억 달러 (약 400조 원)에 달하는 등 폭발적인 성장을 기록 중이다.

거대한 성장과 버블 우려: NFT 시장의 폭발적 증가

NFT 시장 역시 Web 3.0 시대의 중요한 현상으로 부상했다. 디지털 예술 작품이나 아이템에 고유성을 부여하는 NFT는 [17:55] 원숭이 그림(Bored Ape Yacht Club) 등으로 대표되며 큰 주목을 받았다. 이 시장은 전년 대비 [16:41] 16,600%라는 경이로운 성장률을 기록하며 빠르게 확장되었다. 이러한 폭발적인 성장은 일각에서 닷컴 버블 당시와 유사한 거품 현상이라는 우려를 낳기도 한다. 그러나 지지자들은 이러한 성장이 [18:43] 10,000% 이상의 성장을 보인 시장을 달리 설명할 방법이 없으며, 비록 거품이 끼어 있을지라도 그 내재적 가치를 무시할 수 없다고 주장한다.

초기 단계의 Web 3.0: 1998년 인터넷과 유사한 궤적

Web 3.0은 여전히 초기 단계에 있지만, 그 잠재력은 1998년의 인터넷 초창기와 비교된다. 당시 인터넷 사용자는 약 1.8억 명이었는데, 현재 이더리움 지갑 수는 [14:30] 1.8억 개를 기록하며 연평균 80% 이상의 속도로 증가하고 있다. 이는 Web 3.0이 인터넷과 유사한 성장 궤적을 그리고 있음을 시사한다. 과거 닷컴 버블 시기에 많은 기업이 사라졌지만, 인터넷이 만들어낸 근본적인 변화의 방향은 옳았듯이, Web 3.0 역시 [20:04] 많은 프로젝트들이 사라질지라도 방향성 자체는 옳다는 주장이 제기된다.

기술 대기업의 위기이자 Web 3.0의 기회: 탈중앙화 흐름

Web 3.0은 기존 중앙화된 기술 기업들에게 위협이자 동시에 새로운 기회다. 전통적으로 게임이나 소셜 미디어와 같은 서비스는 중앙화된 기술 기업이 독점하며 사용자에게 아무런 권한을 주지 않았다. 그러나 Web 3.0은 사용자에게 투표권이나 소유권을 부여함으로써 [11:18] 이러한 중앙화된 서비스의 대안을 제시한다. 결국 모든 기술 서비스가 이러한 탈중앙화 흐름으로 변화할 것이라고 보는 시각이 많으며, 이는 곧 [12:13] 기존 기술 기업들에게 위기 요인으로 작용한다.

Web 3.0 옹호론: 네트워크 효과와 개발 속도 가속화

Web 3.0 옹호론자들은 탈중앙화의 비효율성에도 불구하고 여러 장점을 강조한다. 첫째, 토큰을 받은 사용자들이 서비스의 마케터가 되어 [22:46] 네트워크 효과를 극대화한다. 사용자들이 소유권을 가짐으로써 자발적으로 서비스를 홍보하고 확산하는 주체가 된다는 것이다. 둘째, 탈중앙화된 자산 개념 덕분에 [23:57] 게임 간 아이템 이동 등 서비스 간 유틸리티 공유가 가능하다. 셋째, 많은 Web 3.0 프로젝트들이 오픈소스를 지향하므로 [30:08] 개발 속도가 매우 빠르다. 이는 투명하게 서비스를 운영하고 커뮤니티의 참여를 유도하는 핵심 요소로 작용한다.

Web 3.0 비판론: 효율성 문제와 주주 자본주의의 그림자

반면 Web 3.0 비판론자들은 탈중앙화의 비효율성을 지적한다. 중앙화된 시스템은 [22:33] 적은 컴퓨터로 훨씬 효율적으로 작동하며, 개선이 용이하다. 또한, Web 3.0이 사용자에게 소유권을 준다고 하지만, 결국 초기 발행자가 많은 토큰을 보유하고 [32:29] 상당한 지배력을 행사하는 것은 기존 벤처캐피털(VC) 중심의 주주 자본주의와 다를 바 없다는 비판도 제기된다. 이는 [38:48] '주주 자본주의 2.0'에 불과하며, 규제가 부재한 상황에서 사기성 프로젝트가 많아질 수 있다는 우려도 공존한다.

주요 통찰·논점

투자는 애플리케이션보다 인프라: 레이어 1 네트워크 주목

Web 3.0 분야에 대한 투자 관점에서, 개별 애플리케이션보다는 인프라(기반 시설)에 집중할 것을 제안한다. 지금 당장 어떤 Web 3.0 애플리케이션이 크게 성공할지 예측하기는 매우 어렵기 때문이다. 대신 [25:36] 이러한 서비스들이 작동할 수 있는 기반을 제공하는 인프라에 투자하는 것이 더 유효하다. 이를 [26:27] '레이어 1(Layer 1)' 네트워크라고 부르는데, 프로그램이 직접 실행되는 근간이 되는 블록체인 네트워크를 의미한다. 현재 주목받는 레이어 1 네트워크로는 이더리움(Ethereum)과 [27:21] 솔라나(Solana) (속도 경쟁), [27:45] 아발란체(Avalanche) (이더리움 개발자와의 호환성 강조), 그리고 [28:10] 스테이블 코인(stablecoin)과 관련된 테라(Terra) 등이 있다. 이들 신생 레이어 1 프로젝트들은 아직 이더리움(시가총액 400~500조 원)에 비해 [28:57] 시가총액이 훨씬 작지만 (대부분 100조 원 미만), 성장 잠재력이 크다고 평가된다.

코인과 주식의 근본적인 차이: 유연성과 민첩성

코인(토큰)과 기존 주식은 소유권 부여 방식에서 중요한 차이를 보인다. 주식회사는 IPO(기업공개)를 통해 주식을 발행하고 나면 [37:40] 자본 증자나 소각이 매우 어렵고, 정책 변경도 무겁게 이루어진다. 그러나 코인과 토큰은 [36:52] 실시간으로 발행, 소각, 정책 변경이 훨씬 유연하게 가능하다. 예를 들어, 서비스 활성화를 위해 갑자기 코인을 발행하여 사용자에게 분배하거나, 시장 상황에 맞춰 소각하는 등의 정책을 즉시 실행할 수 있다. 이러한 민첩성은 서비스의 경제적 생태계를 동적으로 조절하고 사용자의 참여를 실시간으로 유도하는 강력한 도구가 된다. 또한, 온라인 투표를 통해 [38:22] 서비스 운영에 대한 의사결정이 즉각적으로 이루어지는 것도 주식과 다른 점이다.

Web 3.0은 주주 자본주의의 대안인가, 변형인가

Web 3.0은 기존 주주 자본주의의 한계를 극복하려는 시도로 해석된다. 특히 최근 양극화가 심화되면서 [31:43] 초기 기여자에게 유리하고 나중에 합류한 사람들에게는 기회가 적은 기존 주주 자본주의에 대한 불만이 커졌다. Web 3.0은 서비스 전체의 소유권을 상장하고 [32:08] 다양한 사람들과 지속적으로 소유권을 공유함으로써 이러한 불만을 해소하고 더 공정한 가치 분배를 추구한다. 그러나 비판론자들은 결국 토큰을 많이 가진 사람이 더 많은 투표권을 행사하게 되므로 [38:48] 이는 주주 자본주의 2.0에 불과하며 근본적인 변화가 아니라고 주장한다. 이처럼 Web 3.0이 기존 시스템의 대안이 될지, 아니면 또 다른 형태의 변형에 그칠지에 대한 논쟁이 첨예하게 대립하고 있다.
