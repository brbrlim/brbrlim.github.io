Introduction to large language models

Google Cloud Tech15:46게시 2023-05-08
#llm#large-language-models#generative-ai#google-cloud#prompt-engineering#machine-learning#ai-development

TL;DR

이 영상은 대규모 언어 모델(LLM)의 기본 개념, 핵심 특징, 그리고 활용 이점을 설명한다. LLM이 심층 학습의 한 분야이자 사전 학습 및 미세 조정을 통해 다목적으로 사용되는 인공지능임을 강조하며, 복잡한 모델 훈련 대신 프롬프트 설계를 통해 AI를 개발하는 새로운 패러다임을 제시한다. 마지막으로 Google Cloud의 생성형 AI 개발 도구들을 소개한다.

풀시청 판단

이 영상은 대규모 언어 모델(LLM)과 생성형 AI의 기초 개념에 관심 있는 초보 개발자, 학생, 또는 비즈니스 리더들에게 적합하다. LLM이 무엇인지, 기존 기계 학습(ML)과 어떻게 다른지, 그리고 Google Cloud가 제공하는 관련 도구들을 간략히 이해하고 싶은 사람에게 유용하다.

영상을 풀로 시청하면 LLM의 기본 정의, 주요 이점, 그리고 프롬프트 엔지니어링의 중요성을 체계적으로 파악할 수 있다. 특히 [1:02]에 나오는 개 훈련 비유는 LLM의 '사전 학습'과 '미세 조정' 개념을 직관적으로 이해하는 데 도움이 된다. 또한 [5:27]의 고양이 식별 예시는 AI 개발 패러다임의 변화를 명확히 보여준다.

하지만 이 영상은 LLM의 심층적인 기술적 메커니즘이나 복잡한 구현 방식에 대해서는 다루지 않는다. 또한 Google의 PaLM과 같은 특정 모델 및 Google Cloud 제품에 대한 설명이 주를 이루므로, 특정 클라우드 생태계에 묶이지 않은 순수한 기술적 깊이를 기대하는 사람에게는 다소 표면적일 수 있다. 구체적인 코딩 예시나 고급 활용 전략은 제공하지 않으므로, 실질적인 개발 지침을 찾는 이들에게는 추가적인 학습이 필요하다.

핵심 내용

대규모 언어 모델(LLM)이란 무엇인가: 사전 학습과 미세 조정을 통해 다목적으로 활용되는 AI [0:48]

대규모 언어 모델(LLM)은 심층 학습의 한 분야로, 매우 방대한 데이터를 사용하여 사전 학습된 후 특정 목적에 맞게 미세 조정될 수 있는 범용 언어 모델을 의미한다. 이를 개를 훈련하는 과정에 비유할 수 있다. 먼저 "앉아", "와"와 같은 기본적인 명령을 가르쳐 일상생활에 적합한 '범용 개'로 만든다 [1:02]. 그 다음 경찰견이나 안내견처럼 특정 서비스에 필요한 훈련을 추가하는 것이 미세 조정과 유사하다. LLM도 마찬가지로 텍스트 분류, 질문 답변, 요약, 텍스트 생성 등 일반적인 언어 문제를 해결하도록 사전 학습된 후, 소매, 금융, 엔터테인먼트 등 특정 산업의 문제 해결을 위해 맞춤화될 수 있다.

LLM의 '대규모'라는 특징은 두 가지 의미를 포함한다. 첫째, 페타바이트(petabyte) 규모의 방대한 훈련 데이터셋을 사용한다는 점이다 [2:06]. 둘째, 수십억 개의 매개변수(parameters)를 가진다는 점이다 [2:12]. 매개변수는 모델이 훈련을 통해 학습한 지식과 기억을 정의하며, 텍스트 예측과 같은 문제 해결 능력을 결정한다. '다목적'이라는 것은 모델이 특정 작업에 구애받지 않고 인간 언어의 보편적인 특성을 활용하여 다양한 일반적인 문제를 해결할 수 있음을 의미한다 [2:29]. 이는 거대한 데이터셋과 엄청난 수의 매개변수를 갖춘 LLM을 훈련할 수 있는 조직이 제한적이므로, 이들이 개발한 기초 모델을 다른 조직이 활용하도록 하기 위함이기도 하다 [2:44].

LLM이 제공하는 핵심 이점: 다재다능함, 효율성, 지속적인 성능 향상 [3:13]

LLM을 사용하는 이점은 세 가지로 요약할 수 있다. 첫째, 단일 모델로 다양한 작업을 수행할 수 있다. 페타바이트 규모의 데이터로 훈련되어 수십억 개의 매개변수를 생성하는 LLM은 언어 번역, 문장 완성, 텍스트 분류, 질문 답변 등 여러 작업을 동시에 처리할 만큼 충분히 스마트하다 [3:17]. 이는 개발자에게 "꿈이 현실이 된 것과 같다"고 평가된다.

둘째, 특정 문제 해결을 위해 모델을 맞춤화할 때 최소한의 현장 훈련 데이터만 필요하다 [3:38]. LLM은 소량 학습(few-shot) 또는 무학습(zero-shot) 시나리오에서도 준수한 성능을 보인다. 소량 학습은 최소한의 데이터로 모델을 훈련하는 것을 의미하며, 무학습은 모델이 이전에 명시적으로 훈련되지 않은 개념도 인식할 수 있음을 뜻한다 [3:55]. 셋째, 더 많은 데이터와 매개변수를 추가할수록 LLM의 성능은 지속적으로 향상된다 [4:06]. Google의 PaLM 모델은 5,400억 개의 매개변수를 가지고 다양한 언어 작업에서 최첨단 성능을 달성하는 대표적인 예시다 [4:15].

LLM 시대의 AI 개발 방식 변화: 복잡한 코딩 대신 프롬프트 설계가 핵심 [6:23]

인공지능 개발은 전통적인 프로그래밍 방식에서 신경망, 그리고 생성형 AI로 진화해 왔다. 과거에는 고양이를 식별하기 위해 "종: 동물, 다리: 넷, 귀: 둘, 털: 있음, 좋아함: 실뭉치, 개박하"와 같이 규칙을 직접 하드 코딩해야 했다 [5:27]. 신경망 시대에는 고양이와 개의 사진을 네트워크에 제공하고 "이것이 고양이인가?"라고 물으면 예측을 통해 답을 얻었다. 이제 생성형 AI 시대에는 PaLM이나 LaMDA 같은 모델이 인터넷의 방대한 데이터를 흡수하여 기초 언어 모델을 구축하고, 사용자는 질문을 입력하거나 말하는 것만으로 새로운 콘텐츠를 생성할 수 있다 [5:49].

이러한 변화로 LLM 개발은 전통적인 기계 학습 개발과 차별화된다. LLM 개발 시에는 전문 지식이나 훈련 예시, 모델 훈련이 필요 없다 [6:29]. 대신 명확하고 간결하며 유익한 프롬프트를 만드는 과정인 '프롬프트 설계(prompt design)'에 집중해야 한다 [6:37]. 전통적인 ML에서는 모델을 훈련하기 위한 훈련 예시와 상당한 계산 시간 및 하드웨어가 필요했다 [6:48]. 반면, 생성형 질의응답(QA) 시스템은 컨텍스트를 기반으로 자유 텍스트를 직접 생성하므로, 고객 IT 지원이나 헬스케어와 같은 특정 도메인 지식이 없이도 작동한다 [7:38]. Google의 Bard 모델은 매출, 재고, 평균 센서 수 계산 등 다양한 질문에 정확하게 답변하며 프롬프트 설계의 중요성을 보여준다 [7:47].

프롬프트 설계와 프롬프트 엔지니어링의 차이 및 LLM의 세 가지 유형 [8:50]

프롬프트 설계(prompt design)와 프롬프트 엔지니어링(prompt engineering)은 모두 명확하고 간결하며 유익한 프롬프트를 만드는 과정이지만 미묘한 차이가 있다. 프롬프트 설계는 시스템이 수행해야 하는 특정 작업에 맞춰 프롬프트를 만드는 일반적인 과정이다 [9:04]. 예를 들어, 영어를 프랑스어로 번역하는 작업의 경우, 영어로 프롬프트를 작성하고 프랑스어로 번역해야 함을 명시하는 것이다. 반면 프롬프트 엔지니어링은 모델 성능 향상을 목표로 하는 보다 전문적인 과정이다 [9:24]. 이는 도메인별 지식 사용, 원하는 결과물의 예시 제공, 특정 시스템에 효과적인 것으로 알려진 키워드 사용 등을 포함한다. 프롬프트 설계가 필수적인 일반 개념이라면, 프롬프트 엔지니어링은 높은 정확도나 성능이 필요한 시스템에만 적용되는 전문 개념이다 [9:45].

대규모 언어 모델은 크게 세 가지 유형으로 나눌 수 있으며, 각 유형마다 프롬프트 방식이 다르다 [9:54]. 첫째, 일반 언어 모델(generic language models)은 훈련 데이터의 언어를 기반으로 다음 단어를 예측한다 [10:04]. 검색 엔진의 자동 완성 기능과 유사하다. 둘째, 지시 튜닝 모델(instruction-tuned models)은 입력으로 주어진 지시에 대한 응답을 예측하도록 훈련된다 [10:30]. 예를 들어 "X 텍스트를 요약해 줘", "X 스타일로 시를 생성해 줘"와 같은 지시에 응답한다. 셋째, 대화 튜닝 모델(dialogue-tuned models)은 다음 응답을 통해 대화를 이어가도록 훈련된다 [10:54]. 이는 지시 튜닝 모델의 특수한 경우로, 보통 챗봇과의 질문과 답변 형태의 대화에 더 적합하며 더 길고 맥락적인 대화에 효과적이다.

사고의 사슬(Chain-of-thought) 추론: 모델의 정확성을 높이는 설명 과정 [11:19]

사고의 사슬 추론은 모델이 정답을 직접 출력하기보다, 먼저 답변의 이유를 설명하는 텍스트를 출력할 때 더 정확한 답을 얻는 경향을 관찰한 개념이다. 예를 들어, "로저는 테니스 공 5개를 가지고 있다. 테니스 공 3개가 들어있는 새 캔 2개를 더 샀다. 이제 몇 개의 테니스 공을 가지고 있는가?"라는 질문에 모델이 바로 답을 내기보다는, 중간 계산 과정을 설명하게 할 때 정답률이 높아진다 [11:29]. 이는 모델이 복잡한 문제를 단계적으로 해결하도록 유도하여 성능을 향상시키는 방법이다.

주요 통찰·논점

전통적인 ML 개발과 차별화되는 LLM 개발의 접근 방식 [6:23]

LLM 개발은 과거의 기계 학습 방식과 근본적으로 다르다. 전통적인 ML 모델을 개발하려면 해당 분야의 전문가 지식, 방대한 훈련 데이터 예시, 그리고 모델을 훈련시키기 위한 상당한 계산 시간과 하드웨어가 필요했다 [6:48]. 하지만 LLM 시대에는 이러한 복잡한 과정 없이 '프롬프트 설계'에 집중하는 것만으로 개발이 가능하다 [6:37]. 특히 생성형 질의응답(QA) 모델의 경우, 고객 지원이나 헬스케어와 같은 특정 도메인에 대한 깊은 지식 없이도 컨텍스트를 기반으로 자유 텍스트 답변을 생성할 수 있다 [7:38]. 이는 AI 개발의 진입 장벽을 크게 낮추고, 다양한 분야의 비전문가도 LLM을 활용하여 혁신적인 애플리케이션을 만들 수 있게 한다.

모델 맞춤화: 미세 조정(fine-tuning)과 매개변수 효율적 튜닝(PETM) [12:24]

모든 작업을 수행할 수 있는 단일 모델은 실질적인 한계가 있기 때문에, LLM의 신뢰성을 높이려면 태스크별 튜닝이 중요하다. Vertex AI와 같은 플랫폼은 분류나 감성 분석, 이미지 분석 등 특정 작업에 특화된 기초 모델(foundation models)을 제공한다 [12:01]. 모델을 맞춤화하는 방법 중 하나는 '미세 조정(fine-tuning)'으로, 사용자 자신의 데이터셋을 가져와 LLM의 모든 가중치를 다시 훈련시키는 방식이다 [12:49]. 이는 모델 응답을 특정 도메인(예: 법률, 의료)이나 사용자 정의 사용 사례에 맞춰 조정할 수 있지만, 대규모 훈련 작업과 호스팅 비용이 많이 든다는 단점이 있다 [12:56].

이러한 미세 조정의 비효율성을 극복하기 위해 '매개변수 효율적 튜닝 방법(PETM, Parameter-Efficient Tuning Methods)'이 등장했다 [13:17]. PETM은 기본 모델 자체를 변경하지 않고, 소수의 추가 레이어만 튜닝하여 사용자 정의 데이터에 모델을 맞춤화하는 방식이다 [13:31]. 이를 통해 모델 복제 없이 효율적으로 튜닝이 가능하며, 추론 시점에 해당 레이어를 교체하여 사용할 수 있다. Google Cloud는 Generative AI Studio, Generative AI App Builder, PaLM API 및 MakerSuite와 같은 도구를 제공하여 개발자들이 이러한 LLM을 쉽게 탐색, 맞춤화, 배포하고 생성형 AI 애플리케이션을 구축할 수 있도록 지원한다 [13:41].

인상적인 지점

  • 개 훈련 비유: LLM의 '사전 학습'과 '미세 조정' 개념을 설명하기 위해 강아지에게 기본적인 명령(앉아, 와)을 가르친 후 특정 목적(경찰견, 안내견)을 위해 추가 훈련을 시키는 비유 [1:02]는 매우 직관적이고 이해하기 쉬웠다.
  • AI 개발 패러다임의 변화: 고양이를 식별하는 방식이 하드 코딩 → 신경망 훈련 → 질문을 통한 생성형 AI로 진화하는 과정을 보여주는 예시 [5:27]는 LLM이 가져온 변화의 규모와 핵심을 명확하게 전달했다.
  • LLM의 다재다능함: "단일 모델로 다양한 작업을 처리할 수 있다는 것은 꿈이 현실이 된 것과 같다" [3:20]는 표현은 LLM이 가진 잠재력과 개발자들에게 주는 희망을 잘 드러낸다.
