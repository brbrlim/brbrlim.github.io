클로드는 이렇게 쓰는 겁니다: 나만의 'AI 업무 시스템' 4단계 구축법

TL;DR

이 영상은 Claude Opus 5.5를 활용하여 개인화된 AI 업무 시스템을 구축하는 4단계 방법을 소개한다. 스킬, 세컨드 브레인, 루틴, 확장 기능으로 구성된 'SSR Plus' 체계를 통해 AI를 자신의 손발처럼 활용하여 업무 효율을 극대화하는 방법을 단계별로 설명한다. 이를 통해 AI를 단순한 도구가 아닌 통합된 업무 환경의 핵심 요소로 만들 수 있다.

볼까 말까

AI를 활용한 업무 자동화에 관심이 많지만, 아직 시스템 구축 방법을 모르는 사람에게 이 영상은 실질적인 가이드가 된다. Claude를 중심으로 개인화된 AI 에이전트 시스템을 구축하는 구체적인 단계를 초급, 중급, 고급 수준으로 나누어 설명하여, 자신의 AI 활용 능력에 맞춰 적용할 수 있다. 특히 스킬 개선 방법, AI에 최적화된 자료 관리, 상시 작동하는 루틴 구축, 그리고 확장 기능 연결 및 직접 제작까지 다뤄 개인 맞춤형 시스템을 만드는 데 필요한 전반적인 지식을 제공한다.

  • 이런 사람에게: Claude를 활용해 반복 업무를 자동화하고 개인 지식 관리 시스템을 구축하려는 개인 사업가나 1인 기업가
  • 아쉬운 점: 고급 단계의 일부 내용은 아직 개발 중이거나 일반 사용자가 직접 구현하기에는 전문 지식이 필요해 보충 설명 없이는 접근하기 어렵다.
  • 골라 본다면:
    • [4:25] 스킬을 중급 수준으로 활용하여 복합적인 작업을 수행하는 방법
    • [8:00] AI 에이전트에 최적화된 '세컨드 브레인' 자료 구조 구축 방법

주제별 정리

AI 에이전트 시스템 구축의 첫걸음: 반복 작업을 자동화하는 '스킬' 만들기

AI 에이전트 시스템 구축의 첫 단계는 반복 작업을 AI가 수행하도록 자동화 기능(스킬)으로 만드는 것이다. 동일한 작업을 두 번 이상 반복한다면 이를 스킬로 전환하는 것이 효과적이다.

  • 초급: Claude의 기본 기능과 Skill Creator 활용: Claude 데스크톱 앱의 'Skills' 메뉴에서 제공하는 기본 스킬을 사용한다. 특히 'Skill Creator'는 원하는 스킬을 말하기만 해도 자동으로 만들어주는 유용한 기능이다. 예를 들어, 특정 트윗에서 찾은 컴퓨터 문제 해결 프롬프트를 Skill Creator를 이용해 스킬로 만들고, "Mac PC를 확인해달라"고 요청해 즉시 실행할 수 있다. [3:13]
  • 중급: 참고 자료를 포함한 복합 스킬 구축: 단순한 템플릿 파일이 아니라, MD 파일, 텍스트 파일, HTML 파일, 코드 조각 등 다양한 참고 자료를 스킬 안에 포함시켜 복합적인 작업을 더 원활하게 수행하게 한다. 강연 슬라이드를 만드는 스킬에 디자인 가이드라인, 분위기, 사용 재료 등을 MD 파일로 상세히 포함하거나, HTML이나 코드 조각을 넣어 AI가 코드를 처음부터 작성하는 대신 활용하게 하여 작업을 빠르고 정확하게 만든다. [4:25]
  • 고급: 스킬 자체를 개선하는 스킬 만들기: 스킬이 시간이 지나면서 구식이 되거나 변화에 대응하지 못하는 문제를 해결하기 위해, 스킬 자체를 개선하는 스킬을 만든다. 이는 스킬 자체에 업데이트 기능을 추가하거나, 모든 스킬을 개선하는 별도의 스킬을 만드는 두 가지 방법이 있다. 스킬이 활성화된 대화 기록 전체를 읽어 개선 사항을 제한하는 스킬 생성을 요청할 수 있다.

AI에 최적화된 지식 관리 체계: '세컨드 브레인' 구축으로 AI 이해도 높이기

AI가 여러 번 설명하지 않아도 의도를 파악하고 관련 자료를 스스로 찾아 작업을 수행하도록, AI에 최적화된 지식 관리 시스템인 '세컨드 브레인'을 구축한다.

  • 초급: AI의 행동 지침 명시: 특정 작업 폴더를 지정하고, 그 안에 Agent.md 또는 Claude.md 파일을 만들어 Claude가 항상 따라야 할 가이드라인을 작성한다. 이 파일을 Claude가 항상 읽도록 설정하면, AI는 작성된 지침에 따라 작업을 수행한다.
  • 중급: '안내 파일' 기반의 자료 접근 구조화: 데이터 양이 많아지고 AI 생성 파일이 복잡해질 때, 과거 윈도우 파일 정리 방식에 얽매이지 않고 AI와 자신이 언제든 접근할 수 있는 '안내 파일'을 만든다. 안내 파일은 토픽별로 파일 링크를 모아놓은 트리 키 페이지와 같으며, Agent.md가 이 시스템의 주요 진입점 역할을 한다. 예를 들어, 나의 Agent.md는 각 작업 영역(콘텐츠, 개발 등)의 맥락을 제공하고, 해당 가이드 페이지를 먼저 검색하도록 지시하여 AI가 필요한 파일을 쉽게 찾도록 돕는다. [8:00]
  • 고급: 개인 맞춤형 탐색기(Explorer) 구축: Obsidian이나 Notion 같은 기존 도구에 얽매이지 않고, Claude에게 자신에게 완벽하게 맞는 파일 탐색기 생성을 요청한다. 특정 MD 파일을 중심으로 파일 연결 관계를 한눈에 보거나, 계층적 보기, 미리 보기 등 원하는 방식으로 지식을 시각화하여 불필요한 파일을 뒤지지 않고도 정확히 필요한 것을 찾을 수 있게 한다.

24시간 작동하는 AI 업무 환경: 자동 실행 '루틴'으로 상시 생산성 확보

AI 에이전트 시스템이 특정 시간에 자동으로 작업을 실행하도록 '루틴'을 설정하여, 상시적인 생산성을 확보한다. 스킬이 AI 단축키라면, 루틴은 이 단축키를 특정 시간에 누르도록 지시하는 것과 같다.

  • 초급: Claude 데스크톱의 예약 작업 기능 활용: Claude 데스크톱 앱의 'Scheduled' 메뉴에서 'New Task'를 클릭하여 원하는 자동화 작업과 실행 일정을 설정한다. 예를 들어, 'Daily Morning Briefing' 루틴은 매일 오전 9시경 오늘 일정을 검색하여 작업 목록을 브리핑한다. [11:15]
  • 중급: 상시 작동하는 루틴 환경 구축: 데스크톱 앱의 예약 작업은 컴퓨터와 앱이 켜져 있을 때만 작동한다는 단점이 있다. 이를 해결하기 위해 컴퓨터가 꺼져 있어도 실행될 수 있는 루틴 환경을 구축한다. 클라우드 컴퓨터를 빌려 AI를 설치하거나, 집에 있는 예비 컴퓨터에 OpenClo, GrokBot, LMS, Hermes 같은 AI를 설치하여 24시간 상시 작동하는 루틴을 만든다. 이 경우, Sync와 같은 동기화 프로그램을 활용하여 기존 컴퓨터의 세컨드 브레인 파일을 새로운 AI 환경과 동기화한다. [12:05]
  • 고급: AI와 데이터의 클라우드 통합 (미래): 현재 완벽한 단계는 아니지만, Claude를 처음부터 클라우드에 직접 설치하고 모든 데이터를 클라우드에 업로드하는 방식이 미래의 지향점이다. Claude는 현재 관리형 에이전트와 개인 맞춤형 비서 기능 테스트를 통해 이러한 형태의 시스템을 준비 중이다.

AI 에이전트 시스템의 역량 확장: 외부 서비스와 연결하는 '확장 기능' 추가

AI 에이전트가 실제 업무를 수행하려면 외부 서비스와 연결하는 '확장 기능'이 필수적이다. 브라우저 조작이나 Gmail 읽기 등의 기능이 필요하다.

  • 초급: Claude 데스크톱 커넥터 활용: Claude 데스크톱 앱의 'User Branch Connector' 메뉴에서 제공하는 다양한 커넥터 앱을 직접 연결한다. 예를 들어, Google Drive 확장 기능을 연결하여 AI에게 Gmail 확인이나 Google Drive에서 파일 찾기 등의 명령을 내릴 수 있다. [14:11]
  • 중급: 외부 커넥터 검색 및 활용: Claude에서 기본 제공하는 커넥터 외에 외부 커넥터를 찾아 연결한다. MCP, Click, API 세 가지 연결 방식이 있으며, 난이도는 MCP, Click, API 순으로 어려워진다. 예를 들어, 건축물대장을 연결하고 싶다면 "Building Register MCP"를 검색하고, AI에게 연결 방법을 안내해달라고 요청한다. 커넥터 검색이 번거로울 경우, 커넥터 탐색 전용 스킬을 만들어 자동화할 수도 있다.
  • 고급: 맞춤형 확장 기능 직접 제작: 원하는 커넥터나 확장 기능을 찾을 수 없을 때, 직접 만들어 사용한다. 영상 제작자는 Notion과 Obsidian 사용의 불편함을 해소하기 위해 자신만의 마크다운 뷰어를 직접 만들었다. 또한, AI 에이전트 시스템에서 보여준 브랜드 자료실이나 콘텐츠 자료실 같은 확장 기능도 Claude에게 요청하여 직접 만들었다고 설명한다. 필요한 기능에 대해 AI 에이전트에게 설명하면, 필요한 준비 사항과 지침을 안내받아 직접 제작할 수 있다. [16:03]

기억할 것

  1. 반복적인 업무는 모두 AI 자동화 기능(스킬)으로 만들고, 이 스킬 안에 필요한 모든 참고 자료를 포함하여 AI의 작업 완성도를 높인다.
  2. AI 에이전트가 지식을 효율적으로 탐색하도록, 과거의 폴더 정리 방식 대신 '안내 파일'을 중심으로 한 AI 최적화 지식 관리 체계(세컨드 브레인)를 구축한다.
  3. 컴퓨터 전원에 관계없이 24시간 작동하는 AI 루틴을 구축하고, 필요한 경우 클라우드 환경이나 상시 전원 컴퓨터에 AI를 설치하여 시스템의 연속성을 확보한다.
  4. AI 에이전트의 업무 범위를 확장하기 위해 기본 제공 커넥터 외에 외부 확장 기능을 적극적으로 연결하고, 필요한 경우 AI의 도움을 받아 직접 맞춤형 확장 기능을 개발한다.
