핵심 내용

우리는 불확실성을 확률적으로 이해한다

우리의 뇌는 정보를 이분법적으로 보지 않고, 불분명하거나 불완전한 정보에 직면했을 때 여러 가능성을 각기 다른 확률로 해석한다 [0:14]. 예를 들어, 짙은 안갯속에서 움직이는 모호한 형태를 보고 떠돌이개, 고양이, 또는 쓰레기봉투일 가능성을 동시에 생각하는 것처럼 말이다 [0:00]. 이러한 확률적 관점은 현대 머신러닝의 많은 발전을 뒷받침하며, 데이터의 확률 분포를 학습하고 새로운 샘플을 생성하는 '생성 모델링(generative modeling)' 능력의 핵심이다 [0:43].

확률 분포: '믿음의 정도'를 나타내는 지표

가장 근본적인 개념은 확률 분포다 [4:12]. 이는 추상적인 가능한 상태 집합에 각 상태가 발생할 가능성에 대한 '믿음의 정도'를 나타내는 0과 1 사이의 양수를 할당하는 것이다 [4:15]. 주사위를 여러 번 굴려 특정 숫자가 나올 빈도를 측정하는 '빈도주의적 해석(frequentist interpretation)' [5:10] 방식도 있지만, 내일 비 올 확률이 70%라고 할 때처럼 반복할 수 없는 단일 사건에는 적용하기 어렵다 [5:26]. 따라서 이 영상에서는 확률을 '믿음의 정도'로 더 일반적으로 다루는 '베이즈적 관점(Bayesian view)' [5:51]을 채택한다. 이 '믿음의 정도'는 모든 가능한 상태에 할당된 값의 총합이 항상 1이 되어야 한다는 중요한 법칙을 따른다 [6:15]. 즉, 확률 분포는 특정 시스템 내 불확실성이 개별 상태에 어떻게 분포되어 있는지 완전히 설명하는 함수다 [6:41].

확률 분포를 시각화하고 샘플링하는 방법

확률 분포의 예시로는 공정한 주사위의 균등 분포 [7:08]나 성인 키의 가우시안 분포(종 모양 곡선) [7:15]가 있다. 키처럼 연속적인 변수의 경우, 확률 분포는 합이 아닌 적분(곡선 아래 면적)이 1이 되어야 하지만, 이는 핵심 개념에 영향을 주지 않는 기술적 세부 사항일 뿐이다 [7:23]. 키와 몸무게처럼 여러 변수를 포함하는 경우, 각 변수에 대한 차원을 갖는 고차원 공간으로 생각할 수 있다 [8:04]. 예를 들어, 100x100 픽셀 이미지는 10,000차원 공간을 차지하며, 이 공간의 각 지점(이미지)에 확률을 할당하여 이미지 분포를 다룰 수 있다 [8:45].

이러한 복잡한 분포를 실제로 활용하는 방법은 '샘플링(sampling)' [9:22]이다. 주사위를 굴리는 것이 분포에서 새로운 샘플을 생성하는 것처럼 [9:30], 고차원 분포에서 샘플을 추출하여 새로운 이미지를 생성할 수 있다 [9:40]. 이는 무작위로 픽셀 값을 선택하여 노이즈를 만드는 것과는 달리, 분포가 데이터의 구조를 포착하기 때문에 자연스러운 이미지를 만들어낼 수 있다 [9:50].

사건의 '놀라움'을 숫자로 정의하다

확률 분포를 설명하고 모델링하는 수학적 배경을 이해하기 위해 '놀라움(surprise)' [10:16]이라는 개념을 도입한다. 동전 던지기 결과(50% 확률)를 맞추는 것보다 주사위 굴리기 결과(1/6 확률)를 맞추는 것에 더 놀라는 것처럼 [10:20], 놀라움은 확률이 작을수록 커지고, 확률이 1(확실한 사건)에 가까울수록 0으로 줄어드는 양수 값이다 [11:03].

놀라움의 중요한 특징은 '가법성(additive nature)' [11:20]이다. 세 개의 주사위를 동시에 굴리는 사건의 결과를 정확히 예측하면, 한 개의 주사위를 예측했을 때보다 세 배 더 놀란다 [11:26]. 반면, 이러한 독립적인 사건들의 확률은 서로 곱해진다 [11:37]. 즉, 확률이 곱해질 때 놀라움은 더해져야 한다. 이러한 행동을 보이는 함수는 확률의 역수에 로그를 취한 값이다 (log(1/P)) [11:52].

분포의 평균 놀라움: 엔트로피(Entropy)

각 상태에 대한 놀라움 값을 정의했으므로 [12:07], 분포 전체의 '평균 놀라움'을 구할 수 있다 [12:11]. 이를 '엔트로피(entropy)' [12:18]라고 부른다. 수학적으로 엔트로피는 가능한 모든 상태에 대해 각 상태의 확률과 그 상태의 놀라움 값을 곱한 것을 모두 더한 값으로 표현된다 [12:24]. 예를 들어, 앞면과 뒷면이 각각 49%, 옆면이 2% 확률로 나오는 동전을 여러 번 던졌을 때의 평균 놀라움(엔트로피)은 일반적인 공정한 동전의 엔트로피보다 크다 [12:42]. 이는 옆면이 나올 때의 매우 큰 놀라움(낮은 확률)이 평균을 높이기 때문이다. 즉, 엔트로피가 높을수록 해당 분포에 내재된 불확실성이 더 크다는 의미다 [13:45].

우리의 모델은 언제나 현실의 근사치다

실제 세계에서 우리는 종종 관찰하는 현상의 '진정한' 확률 분포를 직접 알 수 없다 [14:01]. 대신, 우리가 믿는 '내부 모델'을 사용하여 확률을 할당한다 [14:10]. 이 내부 모델은 실제 분포의 근사치이며, 실제 분포는 종종 너무 복잡해서 정확히 파악하기 어렵다 [14:22]. 예를 들어, 공정한 주사위의 실제 분포는 미세한 결함이나 공기 저항 때문에 완벽한 균등 분포에서 약간 벗어나지만, 우리는 이를 간단한 균등 분포(각 면 1/6)로 근사하여 사용한다 [14:32]. 이 모델은 실용적인 목적에 충분하지만, 우리의 모델과 실제 분포 사이의 편차가 클 때는 문제가 발생한다. 예를 들어, 공정한 동전이라고 믿었지만 실제로는 앞면이 99% 나올 확률로 조작된 동전을 던졌을 때, 10번 연속 앞면이 나오면 우리는 매우 놀랄 것이다 [15:22]. 이 놀라움은 진정으로 놀라운 일이 일어났기 때문이 아니라, 우리의 '모델'이 틀렸기 때문에 발생하는 것이다 [16:10].

잘못된 모델이 주는 '추가적인 놀라움': 교차 엔트로피(Cross-Entropy)

이처럼 모델이 틀려서 발생하는 놀라움을 정량화하는 개념이 바로 '교차 엔트로피(cross-entropy)' [16:21]다. 이는 하나의 확률 분포(P: 실제 분포)로 생성된 무작위 과정을 관찰하면서 다른 확률 분포(Q: 우리 모델)가 실제 분포라고 믿을 때 예상되는 평균 놀라움을 측정한다 [16:25]. 수학적으로 교차 엔트로피는 엔트로피와 유사하게 정의되지만, 실제 결과 확률에는 P를 사용하고, 놀라움 항에는 우리 모델 Q를 사용한다 [16:44].

교차 엔트로피가 주는 놀라움은 두 가지 원천에서 온다 [17:01]. 하나는 우리 모델 Q와 실제 분포 P 사이의 불일치이고, 다른 하나는 실제 분포 P 자체의 내재된 불확실성이다. 만약 P와 Q가 동일한 분포라면, 교차 엔트로피는 P의 엔트로피와 같아진다 [17:16]. 중요한 수학적 특성 중 하나는 (엄밀한 증명 없이) 실제 분포 P와 모델 Q 사이의 교차 엔트로피는 항상 P 자체의 엔트로피보다 크거나 같다는 점이다 [17:27]. 즉, 잘못된 모델을 믿는 것은 관찰을 통해 얻을 놀라움을 절대 줄일 수 없고, 오직 증가시킬 뿐이다 [17:45].

교차 엔트로피의 또 다른 중요한 특징은 '비대칭성(asymmetry)'이다 [17:56]. P와 Q의 역할이 중요하며, 이들을 바꾸면 매우 다른 결과를 낳을 수 있다. 예를 들어, 실제는 조작된 동전(P)인데 공정한 동전(Q)이라고 믿을 때의 교차 엔트로피는 약 0.7이지만 [18:11], 실제는 공정한 동전(P)인데 조작된 동전(Q)이라고 믿을 때의 교차 엔트로피는 2.3으로 훨씬 크다 [18:40]. 이는 후자의 경우, 모델이 거의 불가능하다고 예측한 '뒷면'을 절반의 확률로 보게 될 때 발생하는 극심한 놀라움이 평균 놀라움을 크게 증가시키기 때문이다 [18:53].

모델의 부정확성만 측정하는 척도: KL divergence

우리의 모델 Q와 현실 P 사이의 차이, 즉 모델의 '부정확성'에서만 오는 놀라움을 어떻게 분리하여 측정할 수 있을까 [19:24]? 여기서 '쿨백-라이블러 발산(Kullback-Leibler divergence)', 줄여서 'KL divergence' [19:40] 개념이 등장한다. KL divergence는 교차 엔트로피에서 실제 분포 P의 엔트로피를 뺀 값으로 정의된다 [20:09].

KL divergence는 모델 Q를 사용할 때 실제 분포 P 자체에 내재된 놀라움을 넘어서, Q를 잘못된 모델로 사용함으로써 얻게 되는 '추가적인 놀라움'을 측정한다 [20:19]. 동전 비유로 보면, 동전 던지기 자체에서 오는 놀라움과 상관없이, 잘못된 모델을 믿음으로써 발생하는 놀라움만을 분리하여 측정하는 것과 같다 [20:30].

머신러닝에서 KL divergence와 교차 엔트로피의 역할

많은 머신러닝 시스템의 궁극적인 목표는 어떤 데이터의 실제 확률 분포를 잘 근사하는 '모델'을 구축하는 것이다 [20:46]. 예를 들어, 실제 고양이 이미지 분포에서 직접 샘플링할 수 없기 때문에 [21:05], 우리는 신경망을 통해 그 분포를 근사하는 모델을 만든다 [21:28]. 모델의 매개변수를 경사 하강법(gradient descent) 같은 기술로 최적화할 때 [21:54], 어떤 근사 모델이 좋은지 나쁜지 판단할 '오차 함수'가 필요하다 [22:06].

여기서 KL divergence가 바로 우리가 최소화하고자 하는 '목표 함수(objective function)' [22:19]가 된다. 이상적으로는 KL divergence 값을 0으로 만들어 우리 모델이 데이터 분포와 완벽하게 일치하도록 하는 것이다 [22:29]. 하지만 실제 모델 훈련 코드에서는 KL divergence 대신 '교차 엔트로피'를 손실 함수(loss function)로 사용하는 경우가 많다 [22:37].

그 이유는 KL divergence 정의에서 실제 분포 P의 엔트로피 항(H(P))이 우리 모델 Q와 전혀 무관한 '상수'이기 때문이다 [22:56]. 이 값은 훈련 데이터에 내재된 불확실성에서 기인하며, 신경망의 매개변수를 아무리 조정해도 실제 고양이 이미지의 다양성에는 영향을 미치지 않는다 [23:10]. 따라서 KL divergence를 최소화하는 것은, 교차 엔트로피를 최소화하는 것과 사실상 '동일한 목표'가 된다 [23:30]. 데이터 엔트로피 항은 KL divergence 값을 상수만큼 이동시킬 뿐, 최적의 모델 Q를 찾는 데에는 영향을 주지 않는다 [23:44]. 결과적으로, 계산량 절약을 위해 이 상수 항을 제외하고 교차 엔트로피를 최소화하는 방식으로 모델을 훈련한다 [24:12].

주요 통찰·논점

'놀라움'을 통해 확률 이론의 핵심 개념을 직관적으로 이해한다

이 영상의 가장 큰 통찰은 '놀라움'이라는 매우 직관적인 인간 감정을 확률 이론의 핵심 개념으로 연결시켜 설명하는 방식이다 [10:16]. 사건이 발생할 확률이 낮을수록 더 '놀랍다'는 보편적인 경험에서 출발하여, 이 놀라움의 정도를 정량화하는 '놀라움 척도'를 정의한다. 여기서 독립적인 사건들의 확률이 곱해질 때 놀라움은 더해진다는 중요한 성질을 통해 로그 함수가 도입되는 과정을 설득력 있게 보여준다 [11:20]. 이렇게 정의된 놀라움의 평균값이 곧 '엔트로피'이며 [12:18], 이는 한 분포가 가진 내재적인 불확실성의 정도를 나타낸다. 이러한 접근 방식은 엔트로피, 교차 엔트로피, KL divergence 같은 추상적인 개념들이 단순히 복잡한 수식이 아니라, 현실 세계의 불확실성을 측정하고 모델링하기 위한 직관적인 도구임을 깨닫게 해준다.

KL divergence와 교차 엔트로피는 머신러닝 모델의 핵심 목표 함수다

영상의 핵심적인 논점 중 하나는 KL divergence와 교차 엔트로피가 현대 머신러닝, 특히 생성 모델을 훈련하는 데 있어 왜 핵심적인 목표 함수(objective function)가 되는지를 명확히 설명하는 부분이다 [20:41]. 우리는 실제 데이터 분포를 직접 알 수 없으므로, 신경망 같은 모델(Q)을 통해 이를 근사한다 [21:02]. 이때 우리의 목표는 모델 Q가 실제 분포 P에 최대한 가까워지도록 만드는 것이며, 이를 정량적으로 측정하는 것이 바로 KL divergence다 [22:19]. KL divergence는 모델이 실제를 얼마나 잘못 설명하는지, 즉 모델의 부정확성으로 인해 발생하는 '추가적인 놀라움'을 측정한다 [20:19]. 더 나아가, KL divergence의 구성 요소 중 실제 데이터 분포 P의 엔트로피는 모델 Q와는 무관한 상수이므로, KL divergence를 최소화하는 것은 교차 엔트로피를 최소화하는 것과 수학적으로 동등하다는 중요한 사실을 밝힌다 [23:30]. 이러한 이해는 많은 머신러닝 알고리즘에서 교차 엔트로피가 손실 함수로 활용되는 근본적인 이유를 설명하며, '모델과 현실 사이의 간극을 측정하고 최소화하는 것'이라는 핵심적인 머신러닝 목표를 명확히 제시한다 [25:40].

인상적인 지점

  • 공공 와이파이 네트워크의 위험성을 설명할 때, "확보되지 않은 연결을 사용하는 것은 마치 혼잡한 방에서 사적인 대화를 하기를 바라는 것과 같다" [22:28]는 비유가 매우 직관적이고 인상 깊다.
  • 교차 엔트로피가 발생하는 놀라움의 원천을 "모델과 실제 분포 사이의 불일치"와 "실제 분포 자체의 내재된 불확실성"으로 명확히 구분한 설명 [17:01]은 개념 이해에 큰 도움을 준다.
  • KL divergence가 교차 엔트로피에서 '실제 분포 자체의 불확실성(엔트로피)'을 빼내어, 오직 '모델의 부정확성'으로 인한 추가적인 놀라움만을 측정한다는 설명 [20:09]은 두 개념의 관계를 명료하게 보여준다.
