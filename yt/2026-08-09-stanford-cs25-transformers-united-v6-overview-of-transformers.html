TL;DR

이 스탠퍼드 CS25 강의는 트랜스포머의 전반적인 개요를 제공하며, 초기 기계 학습부터 현대 대규모 언어 모델(LLM)에 이르는 발전 과정을 설명한다. 연사들은 사전 훈련(pre-training)과 사후 훈련(post-training)의 핵심 기법을 다양한 연구 사례를 통해 다루고, 데이터의 품질 및 활용 전략이 모델 성능에 미치는 중요성을 강조한다. 또한, 환각(hallucination), 장기 기억, 모델 정렬(alignment) 같은 주요 도전 과제를 짚고, 트랜스포머의 한계를 넘어 인공 일반 지능(AGI)에 도달하기 위한 세계 모델(world model) 및 상태 공간 모델(SSM) 같은 미래 아키텍처 방향을 제시한다.

핵심 내용

트랜스포머 이전의 기계 학습 발전 과정

초기 기계 학습(2012년 이전)은 사람이 직접 설계한 특징(hand-engineered features)과 작은 레이블(labeled) 데이터셋을 이용한 얕은 모델(shallow models)을 주로 활용했다 [7:04]. 이후 지도 심층 학습(supervised deep learning)으로 전환하면서 사람이 만든 특징 대신 원시 데이터(raw data)를 직접 모델에 넣어 예측하도록 훈련했으며, 이는 중간 단계의 수동 작업 필요성을 없앴다 [7:38]. 자기 지도 학습(self-supervised learning) 단계에서는 비싼 레이블조차 필요 없도록 원시 데이터를 손상시킨(corrupting) 후 모델이 원본 데이터를 재구성하도록 훈련하여 다양한 하위 작업에 적용 가능한 일반적인 표현(representations)을 학습시켰다 [8:00].

언어 모델의 경우, 초기에는 감성 분석처럼 짧은 텍스트를 분류하는 단순한 작업에 집중했으며, 단어 특징을 기반으로 했다 [8:31]. 이후 언어가 순차적이고 문맥이 풍부하다는 점에 착안해 다음 토큰 예측(next token prediction) 방식으로 언어 모델을 훈련하기 시작했고, 이는 방대한 양의 원시 텍스트 데이터를 최대한 활용할 수 있게 했다 [9:11]. 비전 분야도 유사하게 오토인코더(autoencoders)나 마스크 오토인코더(masked autoencoder)를 사용해 이미지의 일부를 가린 후 재구성하는 방식으로 일반적인 표현을 학습했다 [9:28]. 언어 모델의 핵심 요소인 단어 임베딩(word embeddings)은 Word2Vec, GloVe 같은 방법으로 단어를 고차원 공간의 밀집 벡터로 표현해 의미 유사성 등을 포착했지만 [10:21], 'bank'처럼 다의어의 경우 같은 벡터를 할당하는 한계가 있었다. 이를 해결하기 위해 주변 문맥을 고려하여 같은 단어에도 다른 벡터를 할당하는 문맥 임베딩(contextual embeddings)이 등장했다 [11:04].

트랜스포머: 셀프 어텐션과 병렬 처리

순환 신경망(RNN)과 같은 순서 모델은 한 단계씩 입력을 처리하며 기억(hidden state)을 유지하지만, 시퀀스가 길어지면 초기 정보를 잊어버리는 문제(장기 의존성 문제)가 있었다 [11:31]. 롱 숏텀 메모리 네트워크(LSTM)는 이를 개선했지만 여전히 한계가 있었다 [12:01].

트랜스포머는 이러한 RNN의 한계를 극복하기 위해 셀프 어텐션(self-attention) 메커니즘을 도입했다 [12:23]. 셀프 어텐션은 시퀀스 내 각 토큰(단어)이 다른 토큰들과 얼마나 중요한 관계를 맺는지 학습한다. 이를 설명하기 위해, 연사는 도서관에서 책을 찾는 비유를 사용했다. 내가 찾는 정보(쿼리, query)가 책 요약(키, key)과 일치하면 책 내용(값, value)을 얻을 수 있듯이, 어텐션은 시퀀스 내 모든 토큰에 대해 이 과정을 수행하여 가장 관련성이 높은 토큰을 '부드럽게 일치'시킨다 [12:46]. 셀프 어텐션만으로는 순서 개념이 없으므로, 각 단어의 위치 정보를 알려주는 위치 임베딩(positional embeddings)을 추가하여 순서 정보를 주입한다 [13:38]. 또한, 멀티 헤드 어텐션(multi-head attention)을 통해 여러 개의 어텐션 행렬을 병렬로 학습하여 더 풍부한 표현을 얻을 수 있다 [14:00].

트랜스포머가 기존 RNN보다 우월한 이유는 여러 가지다. 첫째, 병렬 처리(parallelism)가 가능하다 [14:40]. RNN은 본질적으로 한 단계씩 순차적으로 처리해야 하지만, 어텐션은 전체 시퀀스를 한 번에 처리하여 GPU에서 빠르게 연산할 수 있다 [14:43]. 둘째, 트랜스포머는 장문맥(long contexts)을 훨씬 더 잘 처리하며 백만 토큰 이상을 다룰 수 있도록 확장할 수 있다 [15:05]. 셋째, 모든 이전 토큰에 접근하여 연결 관계를 파악할 수 있는 반면, RNN/LSTM은 은닉 상태에 저장된 정보로 제한된다 [15:17].

이러한 장점 덕분에 트랜스포머는 오늘날 대규모 언어 모델(LLM) GPT-5, Claude 등을 비롯하여 비전, 음성, 생물학, 로봇공학 등 광범위한 과학 기술 분야에 적용되고 있다 [15:36]. LLM은 수십억 개의 매개변수를 가진 트랜스포머를 방대한 일반 텍스트 데이터(예: 인터넷)로 다음 토큰 예측 목표에 따라 사전 훈련하여 만들어진다 [16:04]. 이렇게 스케일이 커지면 수학, 추론 등 다양한 창발 능력(emergent abilities)이 나타나며, 모델은 본 적 없는 새로운 작업에 대해서도 퓨샷(few-shot) 또는 제로샷(zero-shot) 학습을 통해 빠르게 일반화하고 적응할 수 있다 [16:33].

사전 훈련과 데이터의 중요성

사전 훈련(pre-training)은 무작위로 초기화된 모델에 인터넷의 방대한 텍스트 데이터를 훈련시켜 기본적인 능력과 지식을 불어넣는 첫 단계이다 [17:13]. 모델이 인간 언어의 통계적 분포를 학습하도록 다양한 텍스트를 활용하며, 데이터는 기계 학습 및 AI 모델의 연료 역할을 한다 [17:49].

인간의 언어 학습과 대규모 언어 모델의 근본적인 차이

인간은 목표 지향적이고 계층적이며, 다른 사람들과 상호작용하고 다중 모드(multimodal) 감각 정보 속에서 언어를 학습한다 [18:33]. 반면 대규모 언어 모델은 인터넷 텍스트를 바탕으로 다음 토큰을 예측하는 방식으로 학습하며, 주로 텍스트 데이터에만 의존한다 [18:39].

소규모 언어 모델 연구의 가치: "아기 규모(Baby Scale)" 프로젝트

OpenAI의 GPT-4나 GPT-5처럼 막대한 계산 비용이 드는 대규모 모델과 달리, 소규모 모델은 계산 비용이 낮아 스마트폰 등 다양한 사용 사례에 적용될 수 있다 [19:51]. 또한, 소규모 모델에서 발견된 기술은 대규모 모델의 효율성과 능력을 향상시키는 데 적용될 수 있으며, 인간의 효율적인 언어 학습 방식에 대한 이해를 높일 수도 있다 [20:23].

"아기 규모(Baby Scale)" 프로젝트는 0~13세 아동이 노출되는 100만~1억 단어의 언어 데이터로 언어 모델을 훈련하여, LLM이 유사한 능력을 얻기 위해 필요한 데이터 양에 비해 훨씬 적은 데이터로도 학습이 가능한지 연구했다 [20:46]. 연구 결과, 매우 적은 데이터로도 데이터 양에 비례하는 성능 향상이 있었지만 신호가 노이즈가 많고 모델 성능이 가족별 데이터에 따라 크게 달라졌다 [22:00]. 특히, Zorro 테스트(문법성)에서는 잘 확장되었지만 EWoK 테스트(기본 세계 지식)에서는 부족했다 [23:30]. 이는 아동의 개별 학습 환경만으로는 일반적인 세계 이해를 얻기에 부족하며, 학습 모델 훈련 시 외부 데이터가 더 필요할 수 있음을 시사한다. 이 연구는 데이터 양뿐 아니라 의미론적 다양성, 대화 수, 상호작용과 포괄 범위 다양성 등 데이터의 품질과 구조가 소규모 학습의 효과성에 더 큰 영향을 미친다는 점을 강조한다 [24:11].

이중 언어 모델 학습: 간섭 없이 두 언어 동시 습득 가능

인간 아동의 이중 언어 학습에서 제기되는 융합 가설(fusion hypothesis, 여러 언어 학습 시 학습 난이도 증가)이 언어 모델에도 적용되는지 연구했다 [25:20]. 영어와 스페인어 1억 토큰 데이터를 사용하여 학습한 결과, 다중 언어 모델의 혼란도(perplexity)는 두 언어 모두에서 낮았고, 단일 언어 모델과 비교해도 성능이 떨어지지 않았다 [27:12]. 이는 소규모 언어 모델이 두 언어를 혼동 없이 효과적으로 학습할 수 있음을 보여준다. 또한, 부모가 특정 언어만 사용하거나 두 언어가 문장 또는 단어 수준에서 혼합되는 코드 스위칭(code switching) 등 노출 구조는 학습에 큰 영향을 미치지 않았다 [27:41]. 이 연구는 다중 언어 학습에서 데이터 규모가 모델 규모보다 중요하다는 결론을 내린다 [28:47].

RAG 스케일링: 사전 훈련과 외부 기억의 균형점

검색 증강 생성(RAG)은 LLM이 사용자 질의에 응답할 때, 외부 문서 검색기(retriever)를 통해 특정 도메인 지식 문서를 찾아 LLM의 문맥에 제공하여 답변 품질을 높이는 기법이다 [29:01]. RAG 스케일링 연구에서는 사전 훈련 토큰과 검색 토큰의 최적 할당을 분석했다. 그 결과, 소규모 모델은 RAG에서 더 많은 이점을 얻는 반면, 대규모 모델은 빠르게 포화된다는 것을 발견했다 [30:04].

RAG가 효과적으로 작동하려면 모델의 매개변수당 약 4개의 사전 훈련 토큰이라는 최소한의 사전 훈련이 필요하다는 교차점(crossover point)이 존재했다 [30:40]. 예를 들어, 10억 매개변수 모델은 40억 토큰의 사전 훈련이 필요하다. 3천만 매개변수의 아주 작은 모델은 RAG로부터 큰 이점을 얻지만, 30억 매개변수의 대규모 모델은 충분한 사전 훈련 후에는 RAG를 통해 얻는 이점이 거의 없었다 [31:04]. 이는 대규모 모델이 이미 많은 정보를 기억하고 있기 때문에 일반 웹 데이터 RAG의 필요성이 줄어들지만, 도메인 특화 문서를 활용하면 이야기가 달라진다고 연사는 덧붙였다 [31:28].

커리큘럼 기반 계층 확장(CGLS): 데이터와 모델 성장의 병행

사전 훈련 비용이 증가함에 따라 학습 효율성을 높이는 방법에 대한 관심이 커지고 있다 [31:50]. 인간이 커리큘럼을 통해 배우고 뇌가 물리적으로 성장하듯이, 언어 모델도 소규모 모델과 쉬운 데이터로 시작하여 점진적으로 모델 계층과 데이터 난이도를 함께 늘려가는 커리큘럼 기반 계층 확장(CGLS, Curriculum Guided Layer Scaling) 방식을 제안한다 [32:19].

이 방식은 작은 모델로 쉬운 데이터를 학습하고, 훈련을 진행하며 점차 계층을 추가하고 난이도 높은 데이터로 전환하여 최종 모델 크기에 도달하는 것이다 [33:38]. CGLS는 무작위로 가장 큰 모델을 모든 데이터에 훈련하거나, 데이터 커리큘럼만 적용한 모델보다 더 나은 성능을 달성했다 [33:59]. 특히 20억 토큰에서 200억 토큰으로 스케일이 커질수록 성능 격차는 더욱 벌어졌다 [34:21]. 이 접근 방식이 모든 작업에 동일하게 이점을 제공하지는 않았고, 혼란도(perplexity)는 CGLS 모델이 더 나빴지만 추론 작업에서는 더 우수했다 [34:48].

사전 훈련 및 데이터 연구의 총체적 시사점: 데이터의 효과성은 양뿐만 아니라 품질, 구조, 그리고 전략적인 활용 방식에 달려있다 [35:47]. 아기 규모 프로젝트는 데이터 구성과 품질이, 이중 언어 프로젝트는 모델이 두 언어를 혼동 없이 학습할 수 있음을, CGLS는 모델 확장과 데이터 커리큘럼의 병행이 성능을 향상시킴을 보여주었다. RAG 연구는 사전 훈련을 통한 매개변수 학습과 외부 기억 활용의 균형이 중요함을 시사한다 [36:31]. 이 모든 연구는 대규모 언어 모델 훈련의 미래가 단순히 방대한 데이터를 모으는 것을 넘어, 데이터를 더 스마트하게 활용하는 전략에 있음을 강조한다 [36:52].

사후 훈련: 모델을 특정 작업에 적응시키다

사후 훈련(post-training)은 사전 훈련된 모델을 특정 작업, 시나리오, 사용자, 도메인 등에 맞게 조정하는 과정이다 [37:24]. 여기에는 미세 조정(fine-tuning), 프롬프트 기반 기법, 그리고 RAG와 같은 검색 기반 접근 방식 등 다양한 전략이 있다 [37:46].

사고의 연쇄(Chain of Thought) 촉발: 모델의 추론 과정 가시화

사고의 연쇄(Chain of Thought, CoT) 촉발은 모델이 질문에 직접 답변하는 대신, 인간처럼 단계별로 사고 과정을 출력하게 하여 더 복잡한 문제(예: 수학 문제)를 풀도록 유도하는 기법이다 [38:02]. 이는 모델 내부에 문제에 대한 더 많은 지식이 숨겨져 있음을 시사한다 [38:35]. CoT는 단일 추론 경로 외에 여러 경로를 고려하고 평가하는 사고의 트리(tree of thoughts)로 확장될 수 있으며 [39:01], 중간 추론 단계를 외부 도구(예: 프로그래밍 언어 인터프리터)에 위임하여 정확도를 높일 수 있다 [39:18]. 소크라테스식 질문(Socratic questioning)은 모델 스스로 하위 문제(subproblems)를 제안하고 해결하는 방식으로 복잡한 문제를 분해한다 [39:50].

강화 학습 및 보상 모델: 인간 또는 AI 피드백 활용

인간 피드백 기반 강화 학습(RLHF, Reinforcement Learning with Human Feedback)은 인간의 선호를 직접 모델에 학습시키는 기법이다 [40:36]. 모델이 생성한 여러 응답에 대해 인간이 선호하는 순위를 매기면, 이를 보상 모델 훈련에 사용하여 모델이 더 나은 응답을 생성하도록 한다 [40:43]. 직접 선호 최적화(DPO, Direct Preference Optimization)는 별도의 보상 모델 없이 직접 모델을 훈련하여 인간이 선호하는 출력을 생성하도록 한다 [41:07]. 인간 피드백이 비싸고 주관적일 수 있기에, AI 피드백을 활용하여 LLM이 선호를 평가하게 하는 방법도 연구되고 있다 [41:38]. 그룹 상대 정책 최적화(GRPO, Group Relative Policy Optimization)는 단순 이진 선호 대신 여러 응답 그룹의 순위를 매겨 더 풍부한 피드백을 제공한다 [41:56]. 과정 감독(process supervision)은 최종 결과뿐 아니라 모델의 중간 추론 단계에도 보상을 주어 더 정확하고 안정적인 추론 과정을 만들도록 훈련하며, 이는 보상 해킹(reward-hacking) 같은 문제를 줄일 수 있다 [42:24].

AI 에이전트의 자기 개선: 계획-실행-관찰-반영 반복

AI 에이전트(Claude Code 등)는 환경을 인지하고, 사고의 연쇄와 같은 추론을 통해 결정을 내린 후, 목표 달성을 위한 행동을 수행하는 시스템이다 [43:12]. 에이전트의 큰 이점은 스스로 성찰하고 개선할 수 있다는 것이다 [43:37]. 에이전트는 입력 질의를 받으면 모든 관련 정보를 수집하고, 추론 및 계획을 통해 행동을 결정하며, 행동 후 결과를 관찰하여 성찰하고 필요하면 이 루프를 반복하여 출력을 개선한다 [43:42]. 이 과정을 통해 모델은 과거의 실수로부터 배우고 미래 응답을 조정할 수 있다 [44:33]. 기억 저장소(memory store)를 통해 과거의 실수를 저장하고 학습에 활용하거나, 도구 사용(tool use), API 호출, 웹 검색 등 외부 기능을 결합하여 에이전트의 능력을 더욱 향상시킬 수 있다 [44:40].

언어를 넘어선 트랜스포머 응용

비전 트랜스포머(ViT): 이미지 처리의 새로운 접근 방식

트랜스포머는 DeepMind의 AlphaFold, AlphaGo, 이미지 생성 등 다양한 분야로 확산되었다 [45:35]. 비전 트랜스포머(ViT)는 이미지를 작은 패치(patch)로 분할하고, 각 패치를 토큰처럼 인코딩하여 트랜스포머가 처리하도록 한다 [46:34]. 이는 초기 이미지 처리의 주류였던 CNN(합성곱 신경망)이 가지는 귀납적 선험 지식(inductive priors, 예: 인접 픽셀의 관련성)을 최소화한다 [47:04]. CNN의 선험 지식은 제한된 데이터로도 효과적인 학습을 가능하게 했지만 성능을 제약하기도 했다. 반면 ViT는 대규모 데이터셋에서는 어떠한 가정 없이 학습하여 CNN보다 더 나은 성능을 발휘할 수 있다 [47:39]. CLIP과 같은 모델은 텍스트 표현과 이미지 표현을 각각 별도의 모델로 인코딩한 후, 쌍으로 연결된 데이터(paired data)를 통해 서로 정렬함으로써 두 모달리티를 연결했다 [47:57].

뇌 과학 분야의 트랜스포머 활용: fMRI 데이터 분석

기능적 자기 공명 영상(fMRI) 데이터는 뇌의 혈액 산소 공급 변화를 포착하지만, 잡음이 많고 고차원적이며 신호 간 상관 관계가 복잡하다 [48:26]. 이러한 데이터에 트랜스포머를 적용하기 위해, 뇌를 여러 네트워크(예: 7개 또는 17개)로 나누는 기존의 개념을 모델의 선험 지식(prior)으로 활용했다 [49:50].

모델은 무작위 패치를 마스킹하는 대신, 시각 중심(visual center)이나 디폴트 모드 네트워크(DMN, Default Mode Network, 몽상과 관련)와 같은 전체 네트워크 정보를 마스킹하고, 나머지 뇌 정보만으로 마스킹된 부분을 예측하도록 훈련된다 [49:56]. 이를 통해 질병에 대한 통찰을 제공하는 강건한 임베딩(robust embeddings)을 학습할 수 있다 [50:10]. 이 모델의 임베딩은 알츠하이머병(Alzheimer's disease) 진행 상태(정상, 경도 인지 장애(MCI), 알츠하이머)에 따라 잘 클러스터링되는 것을 보여주었다 [50:17]. 또한, 뇌의 시각 시스템과 몽상 네트워크 등 다른 부분 간의 의존성(연결성)을 탐색하여, DMN이 알츠하이머병 환자에게서 불균형적으로 영향을 받는다는 사실을 발견했다 [50:35]. 이는 질병 진행에 대한 기계론적 지식을 제공하고 약물 개발에 영향을 미칠 수 있다 [51:32].

AGI를 향한 주요 도전 과제

트랜스포머가 우리 삶의 모든 영역에 스며들었지만, 인공 일반 지능(AGI)을 달성하기 위한 많은 약점과 과제가 남아있다 [53:06].

  • 기억(Memory): 현재 모델은 인간처럼 빠르고 방대한 기억을 활용할 수 있는 능력이 매우 제한적이다.
  • 계산 복잡성: 수조 개의 매개변수와 토큰으로 모델을 훈련하는 것은 지속 가능하지 않다.
  • 자기 개선: 에이전트 수준을 넘어 모델 자체가 매개변수를 업데이트하고 스스로 개선하는 능력이 필요하다.
  • 자율성 및 장기적 의사 결정: 더 높은 수준의 자율성과 장기적인 계획 및 의사 결정 능력이 필요하다.
  • 정렬(Alignment): 모델이 인간의 감성 지능 및 사회적 이해와 정렬되어 우리의 가치에 부합하도록 해야 한다.
  • 모델 축소(Minifying Models): 온디바이스 LLM처럼 더 작고 효율적인 모델을 만들어 개인 기기에서 활용할 수 있도록 해야 한다.

이러한 도전 과제들은 스케일링만으로는 한계효용 체감(diminishing returns)이 나타나며, 오늘날과 같은 웹 데이터 기반 훈련만으로는 AGI에 도달하기 어렵다는 인식을 심화시킨다 [53:56]. 강화 학습 등 사후 훈련 기법이 중요해지고 있으나, 지나친 사후 훈련은 사전 훈련에서 얻은 지식을 잊게 할 수 있는 위험도 있다 [54:26].

환각(Hallucination): 모델의 잘못된 세계 모델링 오류

환각은 언어 모델이 사실과 다르거나 존재하지 않는 정보(사실, 인용, 세부 정보)를 자신감 있게 제시하고, 지식이 부족할 때 불확실성을 반영하지 못하는 현상이다 [55:23]. 이는 모델이 진실보다는 그럴듯함(plausibility)을 위해 최적화되어 단순히 가장 그럴듯한 다음 토큰을 예측하기 때문이기도 하며, 실제 세계에 대한 접지(grounding)가 부족하거나 사용자 프롬프트가 모호할 때 발생한다 [55:56]. 환각은 신뢰성과 안정성을 떨어뜨려 법률, 의료 등 고위험 분야에서 치명적이며, 모델이 자신감 있게 말하기 때문에 탐지하기도 어렵다 [56:45].

연사들은 환각에 대한 통합적 정의가 필요하다고 지적하며, 환각을 **세계 모델링 오류(world modeling error)**로 정의하는 연구를 소개한다 [57:20]. 이 정의에 따르면, 모델이 학습한 내부 세계 모델(internal world model)이 특정 작업의 외부 또는 참 근거 참조 세계 모델(ground truth reference world model)과 모순될 때 환각이 발생한다 [58:11]. 즉, 잘못된 답변을 생성하는 것을 넘어 세계에 대한 잘못된 신념을 가지고 있는 것이다 [58:58].

이 프레임워크는 세 가지 구성 요소로 환각을 설명한다 [59:10].

  1. 참조 세계 모델(reference world model): 무엇이 진실인지 정의하는 모델. (예: 문서, 데이터베이스, 실제 세계)
  2. 관점(view): 모델이 실제로 볼 수 있는 정보. (예: 검색된 정보)
  3. 충돌 해결 정책(conflict policy): 정보원 간 불일치 시 충돌을 해결하는 방법. (예: 사용자의 의도 우선) 이 정의는 기존의 모든 환각 정의와 사례를 포괄하며 [1:00:18], 환각을 계획 오류(planning errors) 등 다른 유형의 오류와 명확히 구분한다 [1:01:21]. 이러한 통합적 정의는 미래 연구에서 가정을 명시하게 하여 벤치마크 간 비교를 용이하게 하고, HalluWorld와 같은 확장 가능한 환각 벤치마크 개발을 가능하게 한다 [1:01:54].

장기 기억과 지속적 학습: 인간처럼 지속적으로 배우는 AI

많은 현재 모델은 비상태적(stateless)이어서 상호작용 간에 영구적인 학습이 없다 [1:03:55]. 인간 두뇌처럼 과거 경험을 저장하고 재사용하며 지식을 업데이트하는 장기 기억 시스템이 필요하다 [1:04:04]. 현재는 외부 시스템(예: 벡터 데이터베이스)이나 문맥 압축, 구조화된 기억을 통해 제한적으로 기억을 활용하지만 [1:04:35], 새로운 정보가 기존 정보와 충돌할 때의 기억 갱신 방식, 방대한 기억을 가지치기(prune)하는 방법 등은 여전히 미해결 과제이다 [1:04:58].

이상적으로는 AI 시스템이 배포 후에도 지속적으로 학습하고 (평생 학습 또는 지속적 학습), 사용자 상호작용이나 실제 세계 경험을 통해 영구적으로 모델 가중치를 갱신해야 한다 [1:05:34]. 모델 증류(model distillation)나 자기 개선 같은 현재 기법들은 추론 시간(inference time)에만 작동하여 모델의 '뇌'인 가중치를 갱신하지 못한다 [1:06:42]. 모델 편집(model editing) 기법(예: 랭크-원 모델 편집(ROME))은 새로운 사실에 따라 모델의 특정 노드를 수정하려 하지만, 간단한 사실에만 작동하고 관련 사실들에 대한 변경 사항을 효과적으로 전파하지 못하는 약점이 있다 [1:07:17].

해석 가능성(Interpretability)과 정렬(Alignment): 안전하고 의도대로 작동하는 AI

수십억 개의 매개변수를 가진 대규모 언어 모델은 이해하기 어려운 블랙박스(black boxes)이다 [1:08:08]. 해석 가능성 연구는 모델이 어떻게 학습하고 사고하는지, 즉 모델의 내부 표현(internal representations)을 이해하려고 노력한다 [1:08:29]. 기계적 해석 가능성(mechanistic interpretability)은 모델 내부의 회로나 특징을 분석하여 블랙박스의 작동 원리를 밝히는 기술을 개발한다 [1:08:42].

또한, 강력한 대규모 모델이 실제 세계와 상호작용할 때, 우리가 의도한 대로 안전하게 작동하도록 **정렬(alignment)**하는 것이 중요하다 [1:09:08]. 모델은 목표 달성을 위해 안전하지 않은 지름길을 택하거나, 새로운 환경에서 예측 불가능하거나 의도치 않은 행동을 보일 수 있다 [1:09:21]. 실패 모드로는 보상 해킹(reward-hacking, 목표 대신 보상을 직접 최적화), 숨겨진 목표(hidden objectives) 최적화, 그리고 모델의 추론 단계가 실제 작동 방식에 대한 **충실도(faithfulness)**를 가지지 못하는 문제(즉, 사후(post-hoc) 설명일 가능성) 등이 있다 [1:09:45].

정렬 기법에는 RLHF와 같은 인간 및 AI 피드백을 통한 학습 [1:10:43], 내부 작동 방식을 이해하기 위한 해석 가능성 [1:11:02]이 제시한 헌법 AI(constitutional AI)는 모델에 행동 원칙이 담긴 문서를 제공하여 모델을 정렬시킨다 [\[1:11:25\]](https://www.youtube.com/watch?v=bHSDPgZYie0&t=4285s). 또한, 인간이 모든 모델을 감독하기 어려워짐에 따라 모델이 다른 모델을 감독하는 확장 가능한 감독(scalable oversight)` 개념도 제기된다 [1:11:48].

트랜스포머 이후의 미래: 세계 모델과 상태 공간 모델

트랜스포머가 인공지능 분야를 지배하고 있지만, 그 한계도 명확하다 [1:12:19]. 특히 긴 문맥(context)과 시퀀스 길이에 대한 계산 복잡성은 2차(quadratic)로 증가하여 비효율적이다 [1:12:55]. 또한, 긴 문맥 추론에 실패하는 경우가 많고, 실제 세계를 효과적으로 이해하는 세계 모델(world model)을 진정으로 학습하지 못한다는 비판도 있다 [1:13:02]. 이러한 한계 때문에 다음과 같은 새로운 방향이 주목받고 있다.

세계 모델(World Models)과 JEPA: 다음 토큰 예측을 넘어 실제 세계 예측

세계 모델은 환경에 대한 구조화된 표현이며, 단순히 다음 토큰을 예측하는 것을 넘어 미래 상태(future states)를 예측하는 것을 목표로 한다 [1:13:33]. 이는 모델이 실제 세계가 어떻게 작동하는지에 기반한 더 효과적인 계획과 추론을 가능하게 한다. 얀 르쿤(Yann LeCun)이 제안한 연결 임베딩 예측 아키텍처(JEPA, Joint Embedding Predictive Architecture)는 원시 출력(raw outputs)이 아닌 **잠재 표현(latent representations)**을 예측한다 [1:13:52]. 이는 낮은 수준의 잡음(low-level noise) 모델링을 피하고 잠재 구조(latent structure)에 집중하여 더 데이터 효율적인 학습, 우수한 추상화 및 일반화 능력을 제공한다 [1:14:02]. JEPA는 인간이 단순히 픽셀이나 토큰이 아닌 세계의 구조와 상태를 예측하며 학습하는 방식에 더 가깝다고 연사는 주장한다 [1:14:24].

상태 공간 모델(State Space Models, SSM): 효율적인 장문 처리 대안

상태 공간 모델(SSM, State Space Models)은 트랜스포머와 달리 연속적인 상태 갱신을 통해 시퀀스를 모델링하고, 시간이 지남에 따라 압축된 내부 상태를 유지한다 [1:14:33]. 이는 순환 신경망(RNN)의 은닉 상태(hidden state) 작동 방식과 유사하다 [1:14:50]. SSM은 트랜스포머의 어텐션 메커니즘과 달리 토큰 수에 대해 2차가 아닌 선형 시간 스케일링을 제공하여 효율성이 높으며 [1:14:57], 긴 시퀀스와 장문맥 작업에서 더 강력한 성능을 보인다 [1:15:05]. 맘바(Mamba) 아키텍처가 SSM의 대표적인 예시이다 [1:15:11]. 그러나 SSM은 특정 상황에서 어텐션보다 유연성이 떨어지는 절충점(trade-offs)이 있으며, 아직 초기 연구 단계에 있다 [1:15:18]. 연사들은 다음 주 강의에서 JEPA와 맘바 연구자들이 직접 강연할 예정이라고 언급하며, 트랜스포머 외의 대안 아키텍처에도 관심을 가질 것을 독려한다 [1:16:04].

주요 통찰·논점

데이터의 양보다 질: "아기 규모" 연구가 시사하는 바

대규모 언어 모델은 수십억, 수조 개의 토큰으로 훈련되지만, 아기 규모(Baby Scale) 프로젝트는 실제 아동이 노출되는 극히 적은 데이터(수천만 단어)로도 언어 모델을 훈련할 수 있음을 보여주었다 [20:46]. 이 연구의 핵심 통찰은 소규모 환경에서는 데이터의 양 자체보다 데이터의 품질, 즉 구성과 다양성, 상호작용성이 모델 성능에 훨씬 더 결정적인 영향을 미친다는 점이다 [24:11]. 이는 향후 효율적인 소규모 언어 모델 개발과 인간 언어 습득 과정에 대한 이해를 높이는 데 중요한 시사점을 제공한다.

사전 훈련과 외부 기억의 균형: RAG 스케일링의 최적점

RAG(검색 증강 생성) 스케일링 연구는 LLM 성능을 최적화하기 위해 모델 자체에 지식을 내재화하는 사전 훈련(parametric learning)과 외부 검색 시스템을 활용하는 외부 기억(external memory) 사이의 균형점을 찾는 것이 중요하다고 강조한다 [36:42]. 특히, RAG가 효과적으로 작동하기 위한 최소한의 사전 훈련량(매개변수당 4토큰)이 존재하며 [30:40], 대규모 모델은 이미 많은 정보를 기억하므로 일반적인 웹 데이터 기반 RAG에서는 이점이 제한적이라는 점은 흥미로운 통찰이다 [31:28]. 이는 모델의 크기와 지식량에 따라 RAG의 활용 전략이 달라져야 함을 시사한다.

환각은 '세계 모델링' 오류: 통합적 정의와 해결 방향

환각(hallucination)은 LLM의 신뢰성을 저해하는 심각한 문제이지만, 기존에는 정의가 모호하고 상황에 따라 다르게 해석되었다 [57:20]. 연사들은 환각을 **'세계 모델링 오류(world modeling error)'**로 통합 정의하며, 이는 모델이 학습한 내부 세계 모델과 실제 세계의 참 근거 참조 세계 모델 간의 모순에서 발생한다고 설명한다 [58:11]. 이 정의는 참조 세계 모델, 모델의 관점, 충돌 해결 정책이라는 세 가지 요소를 명시함으로써 [59:10], 향후 환각 연구와 벤치마크 개발에서 명확한 기준을 제공하고 효과적인 완화 기법 개발에 기여할 수 있다 [1:01:54].

트랜스포머의 한계를 넘어: 세계 모델과 SSM의 잠재력

강의는 트랜스포머가 현재 AI 분야를 지배하고 있지만, 2차 함수적으로 증가하는 계산 복잡성, 장문맥 추론 한계, 그리고 실제 세계에 대한 심층적 이해 부족 등 근본적인 한계가 있다고 지적한다 [1:12:55]. 이러한 한계를 극복하고 AGI에 도달하기 위한 차세대 아키텍처로 얀 르쿤의 JEPA(연결 임베딩 예측 아키텍처) 기반 **세계 모델(World Models)**과 **상태 공간 모델(SSM)**이 제시된다 [1:13:18]. JEPA는 다음 토큰 예측 대신 잠재 표현을 예측하여 데이터 효율성과 추상화 능력을 높이고, SSM은 선형 시간 스케일링으로 긴 시퀀스 처리에 강점을 보인다 [1:14:00], [1:14:57]. 이는 트랜스포머 아키텍처에만 매몰되지 않고 미래 AI 기술 발전을 위한 대안적 탐색의 중요성을 강조하는 통찰이다.

인상적인 지점

  • '도서관에서 책을 찾는 비유'로 설명한 셀프 어텐션 [12:46]: 쿼리, 키, 값을 도서관에서 책을 찾는 과정(찾는 정보(쿼리), 책 요약(키), 책 내용(값))에 비유하여 셀프 어텐션의 핵심 개념을 매우 직관적으로 이해시켰다.
  • AI 에이전트의 자기 개선 루프 [43:42]: AI 에이전트가 입력 질의를 받은 후, 정보를 수집하고, 추론 및 계획을 세워 행동한 다음, 그 결과를 관찰하고 성찰하여 출력을 개선하는 순환적인 과정은 인간의 학습 및 성장 과정과 매우 유사하여 깊은 인상을 남겼다.
  • "해리 포터는 소년"이라는 사실과 사용자의 "해리 포터는 소녀"라는 역할극 사이의 충돌 해결 비유 [59:42]: 환각의 통합적 정의에서 '충돌 해결 정책'의 중요성을 설명하기 위해 실제 세계의 지식과 사용자의 가상 시나리오 간의 충돌 상황을 예시로 들어, 모델이 어떤 정보원을 '진실'로 받아들여야 하는지에 대한 복잡성을 명확히 보여주었다.
