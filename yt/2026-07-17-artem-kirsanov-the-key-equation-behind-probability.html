TL;DR

이 영상은 확률 이론의 핵심 개념인 확률 분포, 엔트로피, 교차 엔트로피, KL 발산(Kullback-Leibler divergence)을 직관적으로 설명한다. 이 개념들은 우리가 불확실한 정보를 처리하는 방식과 인공지능(AI) 모델이 실제 데이터 분포를 학습하고 모방하는 데 어떻게 활용되는지 보여준다. 궁극적으로 모델이 실제와 얼마나 다른지 측정하여 AI 모델의 성능을 최적화하는 원리를 밝힌다.

풀시청 판단

  • 풀시청 가치: 확률 이론의 기본부터 엔트로피, 교차 엔트로피, KL 발산과 같은 심화 개념까지 체계적으로 이해하고 싶은 사람에게 매우 유용하다. 특히 머신러닝, 생성형 AI(generative AI) 분야에서 데이터 분포 학습 및 모델 최적화 원리를 파악하려는 개발자나 연구자에게 권장한다. 수식 자체의 증명보다는 개념의 직관적 이해와 실제 적용 사례에 중점을 두므로, 수학적 배경이 부족해도 쉽게 따라갈 수 있다.
  • 약점 및 한계: 영상 초반에 2분 30초가량의 스폰서 광고(Nord VPN)가 포함되어 있다[2:00]. 핵심 개념을 다루지만, variational inference 등 더 복잡한 생성 모델의 훈련 기법은 다루지 않는다[24:55]. 이론적 엄밀성을 추구하는 시청자에게는 개념 설명에 집중하므로, 수학적 증명이 생략된 점이 아쉽게 느껴질 수 있다.

핵심 내용

우리의 뇌와 AI는 불확실성을 확률로 해석한다

우리는 안개 속에서 모호한 형체를 보고 [0:00] 그것이 떠돌이개, 고양이, 혹은 쓰레기봉투일지 여러 가능성을 동시에 고려하고 각 가능성에 확률을 부여한다. 이는 뇌가 정보를 처리하는 근본적인 방식이자 [0:30] 현대 머신러닝의 발전을 뒷받침하는 원리다. AI 시스템도 이와 유사하게 데이터의 확률 분포를 학습하고 [1:01] 이를 통해 새로운 샘플을 생성하는데, 이를 생성형 모델링(generative modeling)이라 부른다. 확률과 불확실성의 언어는 엔트로피와 KL 발산 같은 핵심 개념을 바탕으로 한다 [1:13].

확률 분포는 세상의 불확실성을 표현하는 틀이다

확률 분포는 가능한 모든 상태에 0과 1 사이의 숫자를 할당하여 [4:15] 각 상태가 발생할 가능성에 대한 우리의 '믿음의 정도'를 반영한다 [4:25]. 동전을 던지거나 주사위를 굴리는 경우처럼 반복된 시도를 통해 빈도를 측정하는 '빈도주의'적 해석도 있지만 [5:10], 내일 비 올 확률처럼 단 한 번의 사건에는 적용하기 어렵다. 이 영상에서는 확률을 '믿음의 정도'로 보는 '베이즈주의' 관점을 채택한다 [5:51]. 모든 가능한 상태에 할당된 믿음의 정도는 반드시 합이 1이 되어야 한다 [6:15]. 예를 들어, 비가 올 확률이 0.7이라면 해가 뜰 확률은 0.3이다. 이러한 확률 분포는 키와 몸무게처럼 여러 특징을 가진 데이터의 경우 [8:04] 여러 차원으로 확장되어 복잡한 시스템의 불확실성을 설명한다. 머신러닝에서는 100x100 픽셀 이미지처럼 [8:45] 10,000차원 공간에서 이미지의 확률 분포를 추론하기도 한다.

샘플링: 확률 분포에서 새로운 데이터를 생성하다

확률 분포를 활용하는 중요한 방법 중 하나는 '샘플링(sampling)'이다 [9:11]. 주사위를 굴리면 해당 분포에서 무작위로 한 면이 선택되는 것처럼 [9:30], 10,000차원 이미지 분포에서 샘플링하면 실제와 같은 새로운 이미지를 생성할 수 있다 [9:40]. 이는 무작위 노이즈와 달리 [9:55] 분포가 내포하는 데이터의 구조를 반영하기 때문에 가능하다. 샘플링은 많은 생성형 AI 모델의 핵심이다.

엔트로피: 분포가 품고 있는 평균적인 '놀람'의 정도

'놀람(surprise)'은 어떤 사건이 발생했을 때 우리가 얼마나 놀랄지를 측정하는 개념이다 [10:16]. 확률이 낮은 드문 사건일수록 놀람의 정도는 크고, 반드시 일어날 사건은 놀람이 0이다 [11:06]. 여러 독립적인 사건의 확률은 곱해지지만 [11:37], 놀람은 합산되어야 하므로 [11:49] 놀람 함수는 확률의 역수에 로그를 취한 형태가 된다 [11:52]. 이 개별 놀람 값들을 확률로 가중 평균한 것이 바로 분포의 '엔트로피(entropy)'다 [12:11]. 엔트로피는 분포가 내포하는 평균적인 불확실성의 양을 나타낸다 [13:45]. 예를 들어, 양쪽 면에 떨어질 확률이 각각 49%, 옆면 2%인 두꺼운 동전의 엔트로피는 [12:42] 앞뒷면만 나오는 공정한 동전보다 크다. 즉, 두꺼운 동전이 더 많은 내재적 불확실성을 지닌다.

교차 엔트로피: 내 모델의 착각으로 인한 추가적인 놀람을 측정하다

실세계에서 우리는 실제 분포(P)를 직접 알 수 없고 [14:01] 우리가 믿는 근사 모델(Q)만 가지고 있다 [14:10]. 예를 들어, 실제로는 조작된 동전(P)인데도 우리가 공정한 동전(Q)이라고 믿는 경우 [15:22] 우리는 실제 일어난 사건에 대해 더 큰 놀람을 경험한다 [16:03]. '교차 엔트로피(cross entropy)'는 실제 분포(P)에서 생성된 사건을 관찰하면서 [16:34] 우리의 모델(Q)이 실제 분포라고 믿을 때 [16:40] 경험하는 평균적인 놀람을 정량화한다 [16:25]. 교차 엔트로피는 P의 고유한 불확실성과 우리의 모델 Q와 실제 분포 P 간의 불일치에서 오는 두 가지 놀람을 모두 포함한다 [17:01]. 모델 Q가 실제 분포 P와 완벽하게 일치한다면 교차 엔트로피는 곧 P의 엔트로피와 같다 [17:16]. 중요한 수학적 특징은 [17:27] 잘못된 모델을 믿으면 실제 분포 P의 엔트로피보다 항상 더 큰 놀람을 겪게 된다는 점이다 [17:45]. 또한 교차 엔트로피는 비대칭적이다 [17:56]. 조작된 동전(P)을 공정한 동전(Q)으로 믿을 때의 놀람과 [18:11] 공정한 동전(P)을 조작된 동전(Q)으로 믿을 때의 놀람은 그 값이 매우 다르다 [18:40].

KL 발산: 모델의 부정확성으로 인한 순수한 '차이'를 분리하다

교차 엔트로피는 내 모델이 실제와 다름으로 인해 발생하는 놀람과 실제 데이터 자체의 내재적 불확실성을 모두 포함한다. 그렇다면 모델의 부정확성에서만 기인하는 '순수한' 놀람, 즉 두 분포 간의 차이를 어떻게 측정할 수 있을까 [19:24]? 'KL 발산(Kullback-Leibler divergence)'은 바로 이 목적을 위해 사용된다 [19:40]. KL 발산은 교차 엔트로피에서 실제 분포(P)의 엔트로피를 빼서 계산한다 [19:51]. 즉, P가 가진 본질적인 놀람을 제외하고 [20:04] 모델 Q를 사용했을 때 추가로 발생하는 놀람을 측정한다 [20:19]. 조작된 동전 비유에서 [20:30] KL 발산은 동전 던지기 자체에서 오는 놀람이 아닌, 잘못된 모델을 믿음으로써 발생하는 놀람만을 분리하여 보여준다. 이러한 KL 발산은 많은 머신러닝 시스템, 특히 생성형 모델의 목표 함수로 활용된다 [20:46]. 예를 들어, 고양이 이미지 생성 AI를 만들 때 [21:05] 우리의 모델 Q가 실제 고양이 이미지 분포 P를 얼마나 잘 근사하는지 KL 발산을 통해 측정하고 [22:19] 이 값을 최소화하는 방향으로 모델을 훈련한다 [22:25].

KL 발산 최소화와 교차 엔트로피 최소화는 결국 같은 목표다

실제 머신러닝 모델 훈련 코드에서는 KL 발산 대신 교차 엔트로피를 손실 함수로 사용하는 경우가 많다 [22:41]. 이는 KL 발산 공식에서 실제 분포 P의 엔트로피 항 [22:59] H(P)가 모델 Q에 전혀 의존하지 않는 상수이기 때문이다 [23:04]. 실제 세상 고양이의 다양성은 모델이 아무리 바뀌어도 변하지 않는 고유한 값이다 [23:21]. 따라서 H(P)는 KL 발산 값 전체를 일정량 이동시킬 뿐 [23:48] KL 발산을 최소화하는 최적의 모델 Q를 찾는 데는 영향을 주지 않는다 [23:30]. 결과적으로 KL 발산을 최소화하는 것은 교차 엔트로피를 최소화하는 것과 수학적으로 동등하며 [23:40], H(P)를 계산하는 추가적인 연산을 줄여 [24:12] 계산 효율성을 높일 수 있다. 이 원리는 현대 생성형 모델을 비롯한 많은 머신러닝 알고리즘의 근간을 이룬다 [24:19].

주요 통찰·논점

확률을 '믿음의 정도'로 보는 베이즈주의적 관점은 복잡한 현실을 모델링하는 데 필수적이다

영상은 주사위처럼 반복 가능한 사건에 초점을 맞춘 '빈도주의' 확률 해석의 한계를 지적하고 [5:20] '믿음의 정도'로서 확률을 정의하는 '베이즈주의' 관점을 도입한다 [5:51]. 이 관점은 날씨 예보처럼 한 번만 일어나는 사건이나 [5:26] 우리가 부분적이고 불완전한 정보에 기반해 불확실성을 다뤄야 할 때 [0:35] 훨씬 더 유연하고 직관적인 틀을 제공한다. 머신러닝에서 실제 분포(P)를 알 수 없고 모델(Q)로 근사해야 하는 상황은 본질적으로 베이즈주의적 접근 방식에 기반한다.

KL 발산과 교차 엔트로피는 모델의 '틀림'을 측정하고 개선하는 핵심 도구다

영상은 엔트로피가 한 분포 자체의 내재적 불확실성을 측정하는 반면 [12:11], 교차 엔트로피는 실제 분포 P와 모델 분포 Q 사이의 평균적인 '놀람'을 [16:25], KL 발산은 이 놀람 중 모델 Q의 부정확성 때문에 발생하는 '추가적인' 놀람만을 [20:19] 분리하여 측정한다는 점을 명확히 설명한다. 이 두 지표는 머신러닝에서 모델 Q가 실제 데이터의 분포 P를 얼마나 잘 모방하는지 평가하는 '오차 함수(loss function)' 역할을 한다. 특히 KL 발산과 교차 엔트로피 최소화가 등가적이라는 통찰은 [23:40] 생성형 AI 모델을 효율적으로 훈련하는 기반을 제공한다.

인상적인 지점

  • 안개 속 형체 비유: 불확실한 정보 속에서 뇌가 여러 가능성에 확률을 부여하는 직관적인 과정을 잘 설명한다 [0:00]. 이 비유는 우리가 매일 마주하는 인지 과정을 확률이라는 개념으로 연결하여 흥미를 유발한다.
  • 놀람의 개념: 확률이 낮은 사건이 더 놀랍다는 점, 독립 사건의 놀람이 합쳐지는 성질이 확률의 역수에 로그를 취한 형태로 표현된다는 설명 [11:20]은 엔트로피의 수학적 정의를 매우 직관적으로 이해하게 돕는다.
  • 조작된 동전 비유: 우리의 모델(Q)이 실제(P)와 다를 때 발생하는 '추가적인 놀람'과 [15:22] 교차 엔트로피의 비대칭성을 명확히 보여주어 [18:01] KL 발산 개념의 필요성과 중요성을 효과적으로 강조한다.
