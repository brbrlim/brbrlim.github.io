NEW Gemini in Chrome Updates | Hands on with the Latest Chrome AI Features

TL;DR

이 영상은 Google Gemini가 Chrome에 통합되면서 웹 브라우징 경험이 어떻게 변화하는지 최신 기능을 통해 보여준다. 핵심은 웹 서핑을 넘어선 '에이전트 능력'으로, 강화된 측면 패널과 AI 이미지 변환 기능은 물론, Gemini가 사용자를 대신해 웹을 탐색하고 복잡한 작업을 능동적으로 수행하면서도 사용자의 통제권을 유지하는 혁신적인 기능들을 시연한다. 이는 멀티태스킹과 개인화된 작업 대행을 통해 브라우징의 효율성을 극대화한다.

풀시청 판단

이 영상은 Chrome에서 Gemini를 활용하는 방법을 실용적인 관점에서 빠르게 파악하고 싶은 사용자에게 유용하다. 특히 AI 비서가 웹 서핑을 넘어 능동적으로 작업을 수행하는 '에이전트 능력'에 관심이 있다면 풀시청할 가치가 충분하다. 복잡한 설정 없이 실제 시연을 통해 기능들을 직관적으로 보여주므로, 새로운 기능을 바로 적용해보고 싶은 사용자들에게 큰 도움이 된다.

다만, 이 영상은 기술적인 깊이나 이론적 배경을 다루지 않는다. Gemini의 작동 원리나 AI 기술에 대한 심층적인 이해를 얻으려는 목적이라면 적합하지 않다. 또한, 현재 미국 지역에서만 제공되며 특정 기능은 AI Pro 및 Ultra 구독자에게 우선적으로 제공된다는 점에서, 한국 사용자나 일반 사용자에게는 당장 적용하기 어려운 정보일 수 있다. 전반적으로 사용자 친화적인 데모 영상이지만, 시연 속도가 빠르고 기능이 많아 전체를 한 번에 시청하는 것이 이해에 더 효과적이다.

핵심 내용

새로운 측면 패널로 효율적인 멀티태스킹 [0:26]

Chrome의 모든 탭에서 Gemini 아이콘을 클릭하면 측면 패널이 나타난다. 이 패널을 통해 현재 보고 있는 탭과 관련성이 있거나 전혀 다른 내용에 대해서도 Gemini에게 질문할 수 있다. 예를 들어, 여행 예약 사이트 Viator에서 [0:49] 9시 이후 시작하는 2시간 미만 고평가 도보 여행을 찾아달라고 요청하면, Gemini가 모든 투어 옵션을 수동으로 정렬할 필요 없이 즉시 세 가지 조건을 만족하는 결과를 제시한다. 결과에는 투어 정보, 시간, 시작 시각, 그리고 상세 정보를 볼 수 있는 직접 링크가 포함된다.

Gemini가 정보를 검색하는 동안 사용자는 다른 탭으로 이동해 작업을 이어갈 수 있다. 이후 언제든지 원래 탭으로 돌아와 [2:05] 대화를 계속할 수 있다. 만약 다른 탭에서 기존 대화를 이어가고 싶다면, 측면 메뉴에서 "여기로 이동(Move Here)"을 클릭해 대화를 옮길 수 있다. 또한, 동일한 채팅 내에서 여러 탭의 정보를 비교하는 것도 가능하다. 오스틴 지역의 임대 주택을 검색하며 여러 매물을 새 탭으로 열면 [2:40] 이 모든 탭이 자동으로 하나의 채팅에 공유되어 쉽게 비교할 수 있다.

이미지 변환 기능: 'nano-banana' [3:07]

Gemini in Chrome은 'nano-banana'라는 기능을 이용해 웹상의 이미지를 변환할 수 있다. 예를 들어, 아파트 내부 사진에서 [3:15] 현재 소파를 과도기적 스타일의 회색 단면 소파로 바꿔달라고 요청하면, Gemini는 몇 초 만에 소파만 바꾸고 다른 모든 요소는 그대로 유지한 채 이미지를 재구성한다. 이 기능은 공간을 빠르게 시각화하거나 가상으로 꾸며볼 때 유용하다.

연결된 앱을 통한 에이전트 능력 [3:52]

Gemini in Chrome은 Gmail, Gcal, Google Maps, Google Flights, Google Shopping, YouTube와 같은 Google 앱들과 연동된다. 연결된 앱 설정이 활성화되어 있다면, Gemini에게 특정 작업을 지시할 수 있다. 예를 들어, Royal Botanic Garden Guided Walk 투어 정보를 Brett에게 이메일로 보내달라고 요청하면 [4:02], Gemini는 Gmail에서 Brett의 정보를 식별하고 해당 정보가 포함된 이메일 초안을 작성한다. 이 이메일은 Chrome 내부에서 직접 편집하고 [4:29] 전송할 수 있어, 앱을 오갈 필요 없이 작업을 완료할 수 있다.

자동 탐색(Autobrowse)으로 작업 대행 [5:01]

Gemini in Chrome의 가장 혁신적인 기능 중 하나는 사용자를 대신해 웹을 '자동 탐색'하는 능력이다. 이는 사용자가 다른 작업을 하는 동안 Gemini가 스스로 웹 페이지를 탐색하며 실제 작업을 완료한다는 의미다. 예를 들어, 항공편 검색 중 [5:14] 환승 시간을 확인하고 싶을 때, 일반적으로는 각 항공편의 상세 정보 페이지로 직접 클릭해 들어가야 한다. 그러나 Gemini에게 환승 시간을 알려달라고 요청하면, Gemini는 사용자의 허락을 받은 후 [6:02] 마치 사람이 직접 클릭하는 것처럼 자동으로 웹 페이지를 탐색하며 필요한 정보를 찾아 측면 패널에 추가한다.

또 다른 예시로, Trotto 레스토랑에서 4인용 예약 가능한 시간을 찾아달라고 요청하면 [6:19], Gemini는 다시 탭을 제어해 예약 과정을 시작한다. 사용자는 이 과정 중에도 다른 탭에서 작업을 할 수 있으며, Gemini가 백그라운드에서 작업 중임을 커서 아이콘으로 확인할 수 있다 [6:46]. Gemini가 작업을 완료하기 위해 사용자 개입이 필요할 때 (예: 예약을 최종 확정할 때)는 '작업 확인(Check your task)' 알림을 표시한다 [7:00]. 이때 사용자는 탭으로 돌아와 예약을 확인하고 최종 승인할 수 있다 [7:27]. Gemini는 사용자의 확인 없이 결제나 중요한 행동을 실행하지 않는다.

모든 대화 기록 저장 및 개인 지능 통합 계획 [7:45]

모든 Gemini in Chrome 채팅은 자동으로 저장된다. 닫았던 탭이라도 언제든지 측면 패널의 메뉴를 통해 최근 채팅 기록을 다시 열 수 있다 [7:50]. 또한 gemini.Google.com에 접속하면 모든 저장된 채팅과 nano-banana를 사용해 생성한 이미지들을 확인할 수 있다. Google은 향후 몇 달 안에 Gemini 개인 지능(personal intelligence) 기능을 Gemini in Chrome에 통합할 계획이다 [8:31]. 현재 이 기능들은 미국 내 Windows, macOS, Chromebook Plus에서 사용할 수 있으며, 자동 탐색 기능은 AI Pro 및 Ultra 구독자에게 먼저 제공된다 [8:36].

주요 통찰·논점

웹 브라우징 경험을 '수동'에서 '대행'으로 전환하다

Google Gemini in Chrome은 웹 브라우징의 본질을 단순히 정보를 검색하고 소비하는 수동적인 행위에서, AI가 사용자를 대신해 능동적으로 작업을 수행하고 목표를 달성하는 '대행' 경험으로 전환하려 한다. 이는 단순히 질문에 답하는 챗봇을 넘어, AI가 웹 페이지를 이해하고 상호작용하며 복잡한 다단계 작업을 완료할 수 있는 '에이전트' 역할을 한다는 의미다. '자동 탐색(autobrowse)' 기능은 이러한 변화의 핵심으로, AI가 사용자의 마우스와 키보드를 대체하여 마치 사람이 웹사이트를 조작하는 것처럼 움직이는 것을 시각적으로 보여준다. 이는 사용자가 여러 탭을 오가며 직접 처리해야 했던 번거로운 작업을 AI에게 위임하여 시간과 노력을 절약하는 새로운 패러다임을 제시한다.

AI의 자율성과 사용자 통제권 사이의 균형 [7:29]

Gemini의 에이전트 능력은 AI가 상당한 자율성을 가지고 웹 환경에서 작업을 수행하지만, 중요한 결정에서는 항상 사용자의 명시적인 승인을 요구하며 통제권을 유지한다. 예를 들어, 자동 탐색 기능으로 항공편 검색이나 레스토랑 예약 과정을 진행하더라도, 최종 결제나 예약 확정 단계에서는 반드시 사용자가 직접 확인하고 승인해야 한다. 이러한 접근 방식은 AI의 효율성을 극대화하면서도 사용자가 예상치 못한 결과나 원치 않는 행동을 방지할 수 있도록 안전장치를 마련한다. AI가 단순 정보 검색을 넘어 실질적인 작업 대행자로 진화하는 과정에서, 인간-AI 협업의 중요한 원칙인 '궁극적인 통제권은 인간에게 있다'는 점을 명확히 하는 것이다.

웹 브라우저를 개인 작업 허브로 재정의 [3:30]

Gemini in Chrome은 기존의 웹 브라우저를 단순한 정보 접근 도구에서, 개인화된 작업 수행 및 관리 허브로 재정의한다. 측면 패널을 통한 즉각적인 정보 검색 및 멀티태스킹 지원, 'nano-banana'와 같은 이미지 변환 도구, Gmail 등 연결된 앱을 통한 작업 관리, 그리고 자동 탐색을 통한 복잡한 작업 대행에 이르기까지, 모든 기능은 사용자가 Chrome 환경을 떠나지 않고도 다양한 업무를 효율적으로 처리할 수 있도록 설계되었다. 이는 웹 브라우저가 개인의 디지털 생활과 업무의 중심이 되어, 여러 애플리케이션이나 플랫폼을 오가는 대신 하나의 통합된 공간에서 대부분의 필요를 해결할 수 있게 만든다.

인상적인 지점

  • "Holy guacamole!" [4:51]: 연결된 앱을 통해 Gmail에서 이메일을 작성하고 전송하는 기능을 시연한 후 나온 이 감탄사는, 사용자가 앱을 오갈 필요 없이 브라우저 내에서 작업을 완료할 수 있게 되는 지점에서의 놀라움을 잘 드러낸다.
  • Gemini가 마우스 제어 [5:45]: 자동 탐색(autobrowse) 기능 시연 중, 발표자가 마우스에 손을 대지 않았는데도 Gemini가 스스로 웹 페이지의 링크를 클릭하며 정보를 찾아가는 모습은 AI의 '에이전트 능력'을 가장 직관적이고 인상적으로 보여주는 순간이다.
  • "채팅은 책임감 있게 하세요. 아주 빨리 가득 찰 수 있습니다." [8:21]: 모든 채팅과 생성 이미지가 저장된다는 설명을 마무리하며 던지는 이 농담은, AI와의 대화가 단순한 질의응답을 넘어 개인의 디지털 기록과 창작물로 이어질 수 있음을 유쾌하게 상기시킨다.
