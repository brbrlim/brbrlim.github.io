클로드 코드 800시간 쓰고 남은 스킬 6개

Jay Choi | 인디해커 라이프10:10게시 2026-05-30브리핑 2026-08-09
AI · 테크#ai-tools#claude-code#developer-tools#productivity#coding-assistant#workflow-optimization

TL;DR

이 영상은 Claude Code를 800시간 이상 사용하며 실제로 매일 유용하게 활용한 6가지 핵심 스킬(및 보너스 스킬)을 소개한다. 화려하지만 실용성이 떨어지는 스킬과 달리, 이 스킬들은 작업 속도를 높이고 코드 품질을 향상하며, AI를 개인의 작업 방식에 맞춰 최적화하는 방법을 보여준다. 궁극적으로 AI 도구를 단순히 소비하는 것을 넘어 자신의 스타일에 맞게 정제하고 발전시키는 과정의 중요성을 강조한다.

풀시청 판단

이 영상은 Claude Code를 활용해 코딩 작업을 하거나 AI 도구를 자신의 업무 흐름에 맞춰 최적화하고자 하는 개발자, 프로그래머, 또는 AI 코딩 어시스턴트 사용자들에게 매우 유용하다. 시중에 소개된 AI 스킬들이 '화려하기만 한' 경우가 많다는 화자의 지적에 공감하며, 실제 생산성에 기여하는 '숨겨진 보석' 같은 스킬을 찾고 있다면 꼭 볼 가치가 있다.

특히, 다음과 같은 사람들에게 도움이 된다.

  • Claude Code 사용자: 당장 작업 효율을 높일 수 있는 실용적인 스킬들을 얻는다.
  • AI 코딩 보조 도구 사용자: Claude Code뿐 아니라 다른 AI 코딩 어시스턴트에도 적용할 수 있는 보편적인 AI 활용 및 최적화 원칙을 배운다.
  • 대규모 코드베이스를 다루는 개발자: Understand 스킬처럼 복잡한 프로젝트 구조를 빠르게 파악하는 방법을 찾고 있다면 유익하다.

다만, 모든 스킬이 Claude Code에 특화되어 있다는 점과 각 스킬의 깊이 있는 활용법보다는 '무엇을 할 수 있는지'를 중심으로 빠르게 소개한다는 점은 한계다. 각 스킬의 세부적인 작동 원리나 고급 활용법을 기대한다면 다소 아쉬울 수 있다. 하지만 AI 도구 사용의 철학적 접근과 실용적 팁을 얻기에는 충분하다.

핵심 내용

모든 AI 코드 생성기의 기본기, Andrej Karpathy의 close.md [0:44]

첫 번째 스킬은 Anthropic에 합류한 전 Tesla AI 리더 Andrej Karpathy가 만든 close.md 파일이다. 이는 별도로 설치할 필요 없이 Markdown 파일 하나로 구성되지만, GitHub에서 15만 개가 넘는 스타를 받았다. Karpathy는 AI 코드 생성기를 사용하며 반복적으로 발생하는 세 가지 문제를 지적했다. 첫째, 무엇을 모르는지 모른 채 코딩을 시작하는 문제, 둘째, 100줄로 충분할 코드를 1000줄로 불필요하게 늘리는 문제, 셋째, 한 버그를 고치려다 주변 코드를 건드려 문제를 더 키우는 문제다. 이 스킬은 이 세 가지 문제를 명확한 네 가지 규칙으로 정리해 Claude Code가 최적화된 방식으로 코드를 생성하도록 돕는다. 설치는 두 줄의 명령어로 10초도 채 걸리지 않을 정도로 간단하지만, 체감하는 코드 품질 향상은 크다.

Claude에게 동영상 '시청' 능력을 부여하는 Claude Video [1:59]

이 스킬은 Claude Code가 YouTube 영상의 제목이나 설명뿐 아니라, 실제 영상 내용과 스크립트까지 이해할 수 있도록 돕는다. 스킬을 설치하면 Claude Code는 영상을 다운로드하여 프레임을 추출하고 자막을 추출한 뒤, 이 정보를 바탕으로 질문에 답할 수 있다. 특히, 영상 길이에 따라 프레임 추출 밀도가 자동으로 조절된다는 점이 특징이다. 예를 들어, 30초 미만의 짧은 영상은 약 30프레임으로 밀도 높게 분석하고, 10분 이상의 긴 영상은 약 100프레임으로 넓게 분석한다 [2:48]. 영상 기획 시 초반 10초를 어떻게 시작했는지, 전체 스크립트 흐름은 어떤지 등을 분석할 때 유용하며, 특정 구간만 잘라 분석하는 기능도 제공한다.

Claude에게 시니어 개발자 프로세스를 강제하는 Superpower [3:20]

Superpower는 Claude Code에게 시니어 개발자의 작업 프로세스를 강제하는 스킬이다. 일반적으로 Claude Code는 요청받으면 바로 코드를 작성하려 하지만, 이 스킬을 설치하면 완전히 달라진다. Claude는 먼저 사용자와 함께 요구 사항을 명확히 정리하고 [3:56], 모델의 계획을 수립한 뒤, 코드를 작성하기 전에 테스트를 먼저 작성하도록 유도한다 [4:04]. 심지어 테스트를 사용하지 않으면 코드를 삭제하기도 한다. 또한, 각 작업을 위해 깨끗한 맥락에서 하위 에이전트를 실행하며, 작업 완료 후 두 번의 리뷰(요구 사항 준수 여부, 코드 품질)를 진행한다 [4:24]. 이러한 과정을 통해 한 번에 완벽한 결과물을 보장하지는 않지만, 초기 결과물의 품질을 60점에서 80점 수준으로 크게 향상시키고, 이는 디버깅 시간과 토큰 비용 절감으로 이어진다 [4:41].

방대한 코드베이스를 한눈에 파악하는 Understand [4:59]

Understand 스킬은 처음 보는 코드베이스를 마주했을 때의 막막함을 해결하기 위해 고안되었다. 20만 줄이 넘는 코드베이스 앞에서 어디서부터 시작해야 할지 모를 때, 이 스킬을 설치하고 /understand를 입력하면 멀티 에이전트가 프로젝트 전체를 스캔한다. 이후 모든 파일, 함수, 프로토콜 관계를 추출하여 지식 그래프를 생성한다 [5:27]. /understand Dashboard 명령어를 통해 인터랙티브 대시보드를 열어 아키텍처 계층별로 코드를 확인하고, 노드를 클릭하여 해당 코드가 무엇을 하는지, 어디에 연결되는지 설명을 볼 수 있다 [5:34]. 코드를 읽어야 할 순서를 안내하는 '가이드 투어' 기능도 제공한다. 이 스킬은 코드뿐만 아니라 PDF, Markdown, 심지어 이미지를 시각 인식(Vision) 기능으로 읽어 지식 그래프에 통합할 수 있어, 다양한 종류의 지식 베이스를 조직화하는 데 매우 유용하다.

필요한 정보만 선별적으로 기억하는 Agent Memory [6:16]

Claude Code에도 내장된 메모리 관리 기능이 있지만, Agent Memory 스킬은 이를 훨씬 능가하는 기능을 제공한다. 이 스킬은 사용자가 별도로 무엇을 할 필요 없이 12개의 자동화된 리뷰 세션 동안 발생하는 모든 작업을 조용히 기록한다 [6:47]. 기록된 내용은 자동으로 압축되어 로컬 데이터베이스에 저장되며, 다음 세션이 시작될 때 필요한 맥락만 선별적으로 추출하여 다시 Claude Code에 주입한다 [6:53]. 기존 메모리 방식이 파일 전체를 맥락에 넣어 불필요한 내용이 포함되는 한계가 있었던 반면, Agent Memory는 벡터 검색과 그래프 검색을 결합하여 현재 작업에 필요한 정보만을 정확히 선별하고 검색할 수 있다 [7:05]. 웹 뷰어를 통해 Claude가 현재 프로젝트에 대해 무엇을 기억하고 있는지 직접 확인할 수도 있다.

나만의 스킬을 만들어 AI를 내 업무 방식에 맞추는 Skill Creator [7:27]

마지막으로 소개하는 Skill Creator는 Anthropic의 공식 스킬이다. 이 스킬은 사용자가 원하는 기능을 설명하면, Claude가 해당 스킬을 직접 만들고, 테스트하며, 심지어 패키징까지 해준다 [7:37]. 사용자가 직접 코드를 수정하거나 형식을 외울 필요 없이, 마치 YouTube 채널을 운영하는 사람이 영상 스크립트를 입력하면 SRT 자막 파일을 수정해 주는 스킬을 만들어달라고 요청하는 것처럼 쉽게 자신에게 맞는 스킬을 생성할 수 있다. 여기서 중요한 점은 스킬 생성이 일회성 작업이 아니라는 것이다 [8:00]. 매번 같은 프롬프트를 반복하는 대신, 스킬을 실행하고 결과가 만족스럽지 않으면 "다음에는 이렇게 해달라"고 스킬을 수정하면, 다음 세션부터는 수정 사항이 반영된 더 나은 결과가 자동으로 생성된다. 이는 AI 도구를 단순히 소비하는 것을 넘어, 자신의 업무 스타일에 맞게 정제하고 반복적으로 개선해 '진정으로 나만의 것'으로 만드는 과정의 핵심이다 [9:47].

주요 통찰·논점

화려함보다 실용성이 중요하다

화자는 시중에 소개되는 많은 AI 스킬들이 '화려한 기능'만을 내세우지만 실제로는 한두 번 사용하다가 버려지는 경우가 많다고 지적한다 [0:04]. 반면, 영상에서 소개하는 스킬들은 겉보기에는 복잡하지 않지만, 실제 작업 속도를 높이고 일상에서 반복적으로 손이 가는 '진짜' 유용한 도구들이라는 점을 강조한다. 이는 AI 도구를 선택할 때 눈에 띄는 기능보다 실질적인 생산성 향상에 기여하는지를 우선적으로 고려해야 한다는 메시지를 전달한다.

AI는 단순한 도구가 아니라 '최적화 대상'이다

영상의 핵심 메시지는 AI 도구를 단순히 사용하는 것을 넘어, 이를 자신의 업무 스타일에 맞게 '설정하고 최적화'해야 한다는 점이다 [9:37]. 똑같은 시간과 노력을 들이더라도, AI를 얼마나 정교하게 자신의 작업 흐름에 맞춰 훈련시키고 개선했는지에 따라 결과물의 품질이 완전히 달라진다고 설명한다. Skill Creator 스킬을 통해 개인화된 스킬을 만들고 반복적으로 수정해 나가는 과정이 바로 이러한 AI 최적화의 대표적인 예시다.

'일회성 프롬프트'에서 '반복적 스킬 개선'으로 진화해야 한다

많은 사람들이 매 프롬프트에 많은 노력을 들이지만, 이 프롬프트를 스킬로 전환하지 않는다고 화자는 지적한다 [8:06]. 이는 매번 같은 작업을 새로 시작하는 것과 같다고 강조한다 [8:33]. 대신, 한 번 만든 스킬을 지속적으로 개선하고 수정해 나가는 '반복적인 스킬 개선' 과정을 통해 AI의 활용도를 극대화할 수 있다는 것이 중요한 논점이다. Day 1에 AI를 사용하는 방식과 Day 30에 사용하는 방식은 완전히 달라져야 한다는 비유를 통해 이러한 진화의 필요성을 역설한다.

인상적인 지점

  • Andrej Karpathy의 close.md: 복잡한 설치 없이 Markdown 파일 하나로 Claude의 코드 품질을 크게 향상시킬 수 있다는 점이 인상적이다. AI가 흔히 저지르는 실수를 간결한 규칙으로 제어하는 접근 방식이 매우 효과적이다 [0:58].
  • Superpower의 '시니어 개발자 프로세스 강제': Claude가 코드를 바로 작성하는 대신, 요구 사항 정리, 계획 수립, 테스트 우선 작성, 하위 에이전트 활용, 두 번의 리뷰 등 체계적인 과정을 거치게 한다는 점이 AI 코드 생성의 신뢰도를 획기적으로 높이는 아이디어다 [3:33]. 특히 주니어 개발자도 따를 수 있을 만큼 명확한 계획을 세우게 한다는 비유가 핵심을 잘 전달한다 [4:19].
  • Understand의 '지식 그래프' 및 '가이드 투어': 낯선 대규모 코드베이스를 단번에 파악하기 어렵다는 문제에 대해, 지식 그래프를 생성하고 아키텍처별로 설명을 제공하는 것은 매우 직관적이고 강력한 해결책이다 [5:32]. 코드뿐 아니라 다양한 문서 형식까지 지원하는 점도 활용성을 넓힌다.
