GPT-4 - How does it work, and how do I build apps with it? - CS50 Tech Talk

CS5053:51게시 2023-05-01브리핑 2026-06-22
★ FavoritesAI · 테크#ai#gpt#llm-applications#prompt-engineering#software-development#ai-agents#cs50-tech-talk

TL;DR

이 영상은 GPT와 같은 대규모 언어 모델(LLM)이 어떻게 작동하는지 기초 원리를 설명하고, 이를 활용하여 다양한 애플리케이션을 구축하는 실제 사례와 개발 방식을 보여준다. 특히 프롬프트 엔지니어링의 중요성과 도메인 지식을 활용하여 LLM 기반 앱의 가치를 높이는 방법을 강조하며, LLM을 "새로운 연산 단위"로 보고 누구나 쉽게 빌드할 수 있음을 역설한다.

풀시청 판단

이 영상은 GPT의 기본 작동 원리(다음 단어 예측)부터 실제 애플리케이션 개발에 필요한 구체적인 방법론까지 폭넓게 다루어 AI 분야에 대한 이해도를 높이고자 하는 개발자나 기획자에게 매우 유용하다. 특히 강연 시점(2023년 3~4월경으로 추정)에는 최신 기술이었던 GPT-4의 작동 방식과 이를 활용한 에이전트 개념, 프롬프트 엔지니어링 기법을 풍부한 예시와 함께 설명한다.

이런 사람에게 추천한다:

  • LLM의 작동 원리를 비전공자도 이해하기 쉬운 비유와 함께 알고 싶은 사람.
  • 프롬프트 엔지니어링의 중요성과 실제 적용 사례를 통해 LLM 기반 애플리케이션 개발의 핵심을 파악하고 싶은 개발자.
  • 챗봇, 질의응답 시스템, 창작 보조, 자율 에이전트 등 LLM을 활용한 다양한 앱 카테고리와 빌드 아이디어를 얻고 싶은 스타트업 빌더 또는 해커톤 참가자.
  • 환각(hallucination) 문제 등 LLM의 한계와 이를 극복하기 위한 실용적인 접근법(복수 에이전트, 외부 데이터베이스 연동)에 관심 있는 사람.

약점 및 한계: 강연 시점이 2023년 상반기이므로, 이후 빠르게 발전한 LLM 생태계의 최신 정보(예: 멀티모달 LLM, 최신 미세 조정 기법 등)는 반영되어 있지 않다. 다만, LLM의 근본적인 작동 원리, 프롬프트 엔지니어링의 중요성, 그리고 에이전트의 기본 개념 등은 여전히 유효하며, 새로운 기술을 학습하는 데 훌륭한 기반 지식을 제공한다.

핵심 내용

GPT의 본질 — 다음 단어를 예측하는 확률 기계 [4:30]

GPT는 본질적으로 대규모 언어 모델(LLM)이며, 주어진 단어 시퀀스 다음에 올 가장 확률 높은 다음 단어를 예측하는 모델이다. 이 모델은 약 5만 개의 어휘 집합을 가지고 있으며, 인터넷에서 다운로드한 방대한 텍스트 데이터를 학습하여 단어들 간의 연결 확률을 파악한다. 예를 들어, "I am"이라는 입력이 주어지면, "happy"가 나올 확률이 높고 "school"이 나올 확률이 낮은 식으로 각 단어에 확률 값을 부여한다. 이 확률 분포를 기반으로 다음 단어를 샘플링하고, 그 단어를 다시 입력에 추가하여 새로운 단어를 계속 생성함으로써 길고 일관된 텍스트를 만들어낸다. 이러한 단순한 원리가 놀랍게도 복잡한 에세이나 대화를 생성할 수 있는 능력을 가능하게 한다 [6:22].

LLM의 성능 향상 — 규모와 명령어 튜닝 [7:05]

LLM은 모델의 크기를 키우고 더 많은 연산 자원을 투입하여 더 긴 시간 동안 훈련할수록 성능이 향상되고 표현력이 풍부해지며, 심지어 어느 정도 지능적인 능력을 보여주기도 한다. 하지만 초기 GPT-3 같은 모델은 단순히 인터넷 텍스트를 모방하여 다양한 텍스트 장르와 문체로 말할 수 있었지만, 사용자의 질문 의도를 명확히 파악하고 답변하는 데는 한계가 있었다 [7:43]. 이 문제를 해결하기 위해 OpenAI 과학자들은 명령어 튜닝(Instruction Tuning)과 인간 피드백 기반 강화 학습(RLHF: Reinforcement Learning from Human Feedback) 방식을 도입했다. 모델을 대화 형식의 질문-답변 데이터셋으로 추가 학습시켜, 단순히 다음 단어를 예측하는 것을 넘어 질문에 답하는 틀 안에서 단어를 예측하도록 만들었다. 이 결과가 바로 ChatGPT이며, 이로 인해 LLM은 단기간에 폭발적인 사용자 증가를 경험하고 질문에 답변하는 대화형 에이전트로 기능하게 되었다 [9:13].

GPT 기반 애플리케이션의 네 가지 유형 [12:08]

GPT와 같은 LLM은 "새로운 연산 단위" 또는 "새로운 종류의 전력"으로 비유된다 [12:20]. 개발자들은 LLM을 단순히 텍스트 생성에 사용하는 것을 넘어, 이를 알고리즘에 통합하고 다른 소프트웨어와 결합하여 새로운 형태의 애플리케이션을 구축하고 있다. 현재 많이 구축되는 LLM 기반 앱은 크게 네 가지 범주로 나눌 수 있다.

  1. 동반자(Companionship) [14:00]: 특정 목적을 가진 친구 같은 봇이다. 언어 학습 코치, 운동 코치 등 특정 역할을 부여하여 사용자와 대화한다.
  2. 질의응답(Question Answering) [18:06]: 특정 문서나 데이터에 기반하여 질문에 답하는 봇이다. 고객 서비스 봇이나 특정 자료의 내용 요약, 정보 검색 등에 활용된다.
  3. 유틸리티 기능(Utility Functions) [25:39]: 기본적인 언어 이해를 요구하는 반복적이고 지루한 작업을 자동화한다. 단위 테스트 생성, 문서 요약, 코드 리팩토링, 브랜드 가이드라인 준수 여부 확인 등이 포함된다.
  4. 창작(Creativity) [27:30]: 텍스트나 이미지 생성, 스토리텔링 등 창의적인 작업에 도움을 준다. AI가 다양한 가능성을 과다 생성하고 인간이 편집하는 방식으로 활용된다.

마지막으로 "야생의 실험(Wild Experiments)" [32:20]이라 불리는 자율 에이전트(Auto GPT, Baby AGI)는 GPT를 반복문 안에 넣어 스스로 목표를 설정하고 작업을 수행하도록 하는 시도이다.

프롬프트 엔지니어링의 마법과 도메인 지식의 힘

대부분의 GPT 기반 애플리케이션은 프롬프트 엔지니어링에 의해 결정된다 [14:09]. 단순히 GPT에 질문을 던지는 것을 넘어, 모델의 성격이나 목표를 정의하는 프롬프트를 미리 주입하거나, 질문과 답변에 필요한 추가 정보를 동적으로 프롬프트에 삽입하는 방식이다.

  • 동반자 봇: "당신은 친절하고 도움이 되는 중국어 선생님이며, 모든 상황에 대해 적절한 중국어 성어를 설명하고, 영어로 의미를 풀이한 후 언어 학습에 대한 격려의 말을 건넨다"와 같은 지시를 프롬프트에 추가하여 특정 페르소나를 부여한다 [17:02].
  • 질의응답 봇: 외부 문서(예: CS50 강의계획서 PDF)를 작은 조각으로 나누고, 각 조각을 임베딩 벡터(의미를 수치화한 벡터)로 변환하여 벡터 데이터베이스에 저장한다. 사용자의 질문이 들어오면 질문 또한 임베딩 벡터로 변환하여 데이터베이스에서 가장 유사한 문서 조각들을 찾아낸다. 그리고 "당신은 질문에 답변하는 전문가입니다. 사용자의 질문에 답변하되, 제가 제공한 원본 문서 자료만 사용하세요"라는 프롬프트에 검색된 문서 조각을 동적으로 삽입하여 답변을 생성한다 [21:00]. 데이터베이스 없이 단순한 정보를 프롬프트에 직접 넣어 질의응답 시스템을 만드는 것도 가능하다 [24:00].
  • 창작 보조: AI의 과다 생성 능력과 인간의 편집 능력을 결합하는 방식이다. "이야기 5가지 가능성을 생성해라"와 같이 프롬프트를 통해 여러 초안을 만들게 하고, 인간 사용자가 이를 수정하는 역할을 한다 [28:31]. 특히 이 과정에서 책 판매상이나 편집자의 시각과 같은 도메인 지식을 프롬프트에 녹여내면 AI가 더 목표 지향적이고 유용한 제안을 할 수 있다.

자율 에이전트 — GPT의 반복적 자기 지시 [33:35]

가장 실험적인 분야는 자율 에이전트(Auto GPT, Baby AGI)이다. 이는 GPT를 반복문(for Loop) 안에 넣어 GPT가 스스로 생각하고, 계획하고, 행동하도록 만드는 방식이다 [33:55]. 인간이 "X를 하라"는 목표를 주면, GPT는 스스로 "해야 할 일 목록"을 작성하고, 그 목록의 작업을 순차적으로 수행하며, 각 작업의 결과를 다음 단계의 입력으로 사용하여 목표에 도달할 때까지 이 과정을 반복한다. 여기에 웹 검색이나 투두리스트 생성 같은 **도구(tools)**를 에이전트에 부여하면, GPT는 더 복잡한 작업을 수행할 수 있는 "몸체(bigger body)"를 가지게 된다 [35:01]. 이 분야는 아직 실험 초기 단계이지만, 파이썬 코드의 역할이 줄어들고 AI가 스스로 지시하는 미래를 보여준다.

주요 통찰·논점

LLM의 환각(Hallucination)은 피할 수 없는 문제이자 기회 [37:51]

LLM은 "근거(ground truth)"가 없기 때문에 학습 과정에서 단어 간의 차이와 언어 패턴을 통해 의미를 파악할 뿐, 특정 정보가 참인지 거짓인지 자체를 알지 못한다. 따라서 모델은 가장 그럴듯한 답변을 생성하려 노력하며, 이 과정에서 때때로 사실과 다른 정보를 "환각"처럼 만들어내거나 두 가지 다른 주제를 혼동하기도 한다 [39:12]. 이는 모델의 합성 능력과 불가분의 관계에 있는 문제로, 완전히 없애기 어렵다.

하지만 몇 가지 실용적인 방법으로 환각을 줄일 수 있다:

  • 프롬프트 수정: "나의 최선은 ~이다"와 같은 문구를 답변 앞에 추가하도록 지시하면 환각을 최대 80%까지 줄일 수 있다는 연구 결과도 있다 [40:02].
  • 외부 검색 및 참조: 빙 챗(Bing Chat)처럼 외부 웹 검색 도구를 연결하여 모델이 정보를 직접 찾아보고 인용하도록 하면 정확성을 높일 수 있다.
  • 자기 검토: 모델에게 "내 답변에 실수가 있는지 확인해라"고 지시하면 스스로 오류를 찾아 수정하는 경우가 많다 [40:31].
  • 외부 데이터베이스: 도메인 특화된 지식에 대해서는 외부 데이터베이스를 연결하여 답변의 근거를 제공해야 한다. 이는 오늘 강연에서 시연된 질의응답 봇의 핵심 원리이기도 하다 [41:10].
  • 복수 에이전트 활용: 인간 사회에서 여러 명이 협력하여 오류를 검증하듯, 여러 AI 에이전트가 각기 다른 역할을 맡아 답변을 생성하고 검증하도록 하는 모델을 통해 환각 문제를 해결할 수 있다. 마치 우주선에 3개의 컴퓨터가 모두 동의해야 다음 단계로 나아가듯, AI 모델도 복수 검증을 거치면 신뢰도가 높아진다 [42:00].

LLM은 '외계인의 지능'과 같아 인간과 다르게 추론한다 [46:30]

GPT는 의식이 없으며, 인간처럼 생각하고 추론하지 않는다. 그러나 명령어 튜닝을 통해 특정 역할을 부여받으면, 마치 그 역할을 연기하는 것처럼 행동하며 해당 역할에 맞는 텍스트를 생성한다 [44:06]. 이는 언어 모델이 방대한 데이터를 학습하여 다양한 페르소나와 상호작용 방식을 모방하고 시뮬레이션할 수 있기 때문이다. LLM은 문해력 시험이나 LSAT(법학대학원 입학시험) 논리 문제를 풀기도 하지만, 프롬프트의 미묘한 변화에도 민감하게 반응하여 결과가 크게 달라질 수 있다. 모델의 추론 능력은 경험적으로 관찰되지만, 그 작동 방식은 여전히 인간의 사고방식과는 다른 '외계인'의 지능과 같아 정확히 이해하기 어렵다 [46:30].

LLM은 미래 컴퓨터의 '두 번째 프로세서'가 될 것이다 [49:01]

현재 우리는 LLM을 'GPT'나 'LLM'이라는 특정 기술 용어로 부르지만, 5년 또는 10년 후에는 이 기술이 마치 '마이크로프로세서'나 '그래픽 프로세서'처럼 컴퓨터 시스템의 기본적인 구성 요소로 자리 잡아 그 존재 자체를 의식하지 않게 될 것이라는 통찰을 제시한다. LLM은 인간의 인지 활동을 근사하는 '두 번째 프로세서'처럼 모든 소프트웨어에 통합될 것이며, '기반 모델(Foundation Model)'이라는 용어는 이러한 광범위한 확산을 의미한다 [49:10].
