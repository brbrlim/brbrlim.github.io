핵심 내용

MDP 복습: 알려진 세상에서 최적의 정책 찾기

마르코프 결정 과정(MDP)은 상태(states), 행동(actions), 전이(transitions), 보상(rewards), 할인율(discount factor)로 구성된 모델 체계이다 [0:41]. 에이전트는 상태에서 행동을 선택하고, 행동은 확률적 전이를 통해 새로운 상태와 보상으로 이어진다. 정책(policy, $\pi$)은 각 상태에서 취할 행동을 결정하며 [3:31], 목표는 기대 효용(expected utility)을 최대화하는 최적 정책을 찾는 것이다. 지난 강의에서는 MDP가 완전히 주어졌을 때 가치 반복(value iteration)이나 정책 평가(policy evaluation)를 통해 최적 정책을 계산하는 추론 알고리즘을 다뤘다 [1:00].

정책의 가치(value)는 V-함수(V-function)와 Q-함수(Q-function)로 표현된다. V-함수 Vπ(s)는 특정 상태 s에서 정책 π를 따랐을 때 얻을 수 있는 기대 효용이고 [5:47], Q-함수 Qπ(s, a)는 상태 s에서 행동 a를 먼저 취한 후 정책 π를 따랐을 때 얻을 수 있는 기대 효용이다 [6:13]. 이러한 가치 함수들은 재귀적 관계로 정의되며 [6:38], 이를 통해 최적 정책을 계산할 수 있었다.

강화 학습의 기본 문제: 모르는 세계에서 행동하며 배우기

강화 학습(RL)은 MDP와 달리 전이 확률(T)과 보상 함수(R)를 알지 못하는 상황에서 최적 정책을 찾아야 하는 문제이다 [7:41]. 에이전트는 시행착오를 통해 환경과 상호작용하며 데이터를 수집하고, 이 데이터를 바탕으로 환경 모델을 추정하거나 직접 최적 정책을 학습한다 [11:21]. 강사는 A/B 선택 게임을 통해 초기에는 아무 정보 없이 행동해야 하는 RL의 상황을 비유적으로 설명한다 [8:07].

강화 학습 에이전트(agent)는 환경(environment)에 행동을 보내고 [11:52], 환경은 새로운 상태와 보상을 에이전트에게 돌려준다. 에이전트는 이러한 경험을 통해 (1) 어떤 행동을 취해야 할지 [12:08], (2) 세계에 대한 자신의 모델을 어떻게 업데이트할지 [12:19] 두 가지 주요 질문에 답해야 한다. 즉, 강화 학습은 단순히 데이터를 수동적으로 받는 것이 아니라, 데이터를 어떻게 얻을지 스스로 결정해야 하는 '탐험'의 문제를 포함한다 [20:11].

모델 기반 몬테카를로: MDP 모델을 추정하여 최적 정책 찾기

모델 기반 몬테카를로(Model-Based Monte Carlo)는 에피소드(episode), 즉 일련의 상태-행동-보상 시퀀스 데이터를 통해 환경의 전이(T)와 보상(R) 모델을 직접 추정하는 방식이다 [14:12]. 예를 들어, 특정 상태 S에서 행동 A를 취했을 때 특정 상태 S'로 전이된 횟수를 세어 전이 확률을 추정하고, 관찰된 보상을 기록하여 보상 함수를 추정한다 [15:30].

MDP 모델이 추정되면, 기존의 가치 반복 알고리즘을 사용하여 최적 정책을 계산할 수 있다 [18:33]. 그러나 이 방법의 치명적인 문제점은 '탐험(exploration)'이 부족하면 특정 상태-행동 경로를 전혀 경험하지 못해 해당 부분의 모델을 추정할 수 없다는 점이다 [19:31]. 예를 들어, 다이스 게임에서 '그만두기' 행동을 한 번도 하지 않았다면, 이 행동의 보상이나 전이를 알 수 없다.

모델 프리 몬테카를로: MDP 모델 없이 Q-가치 직접 추정하기

모델 프리 몬테카를로(Model-Free Monte Carlo)는 전이와 보상 모델을 명시적으로 추정하는 대신, 각 상태-행동 쌍의 Q-가치(Qπ(s, a))를 직접 추정한다 [21:45]. Qπ(s, a)는 상태 s에서 행동 a를 취한 후 특정 정책 π를 따랐을 때 얻는 기대 효용을 의미한다 [23:31].

이 알고리즘은 여러 에피소드를 통해 특정 상태-행동 쌍 (s, a)이 나타날 때마다 그 이후에 얻는 총 할인된 효용(utility)을 기록하고 [25:02], 이 효용 값들의 평균을 내어 Qπ(s, a)를 추정한다 [24:25]. 예를 들어, 주사위 게임에서 '계속하기'를 했을 때 4, 8, 16의 효용을 얻었다면, 이들의 평균으로 Q-가치를 업데이트한다 [26:24]. 이러한 업데이트는 Q(s,a) ← (1-η) Q(s,a) + ηU와 같은 볼록 조합(convex combination) 형태로 표현될 수 있으며 [32:05], 이는 확률적 경사 하강법(Stochastic Gradient Descent, SGD)의 형태로도 해석할 수 있다 [35:27]. 이 방식은 특정 정책(π)의 가치(Qπ)를 추정하므로 '온-정책(on-policy)' 학습에 해당한다 [28:10].

SARSA: 부트스트래핑으로 정책의 Q-가치를 추정하는 온-정책 학습

몬테카를로 방식은 에피소드가 끝날 때까지 기다려야 전체 효용(U)을 계산할 수 있어 분산이 크다는 단점이 있다 [40:42]. SARSA는 이러한 문제를 해결하기 위해 '부트스트래핑(bootstrapping)' 기법을 도입한다 [45:35]. 부트스트래핑은 현재 추정하고 있는 Q-가치 자체를 업데이트 목표에 활용하는 것으로, 즉 "자신의 신발 끈을 잡아당겨 자신을 끌어올린다"는 비유처럼 스스로를 사용하여 추정치를 개선한다 [45:50].

SARSA는 상태(S), 행동(A), 보상(R), 다음 상태(S'), 다음 행동(A')의 5개 튜플(SARSA)을 관찰한 후 Q-가치를 업데이트한다 [43:24]. 업데이트 공식은 Q(s,a) ← Q(s,a) + η [R + γQ(s',a') - Q(s,a)] 형태이며 [43:38], 여기서 R + γQ(s',a')는 현재 관찰된 즉시 보상과 다음 상태-행동 쌍 (s', a')의 추정된 Q-가치를 할인하여 더한 값이다. 이는 전체 효용을 기다리지 않고 한 단계 앞선 추정치를 사용하여 분산을 줄이는 효과가 있다 [46:18]. SARSA는 특정 정책 π를 따르고 그 정책 π의 Q-가치를 추정하므로 모델 프리 몬테카를로와 마찬가지로 '온-정책' 학습 알고리즘이다 [50:00].

Q-러닝: 최적 정책의 Q-가치를 추정하는 오프-정책 학습

SARSA와 모델 프리 몬테카를로는 현재 따르는 정책의 Q-가치(Qπ)만 추정하므로, 궁극적인 목표인 최적 정책(Q_opt)을 직접 얻을 수 없다 [48:21]. Q-러닝(Q-learning)은 최적 정책의 Q-가치(Q_opt)를 직접 추정하는 '오프-정책(off-policy)' 학습 알고리즘이다 [49:15]. 오프-정책 학습은 현재 따르는 탐험 정책과 관계없이 최적 정책의 가치를 학습할 수 있다 [55:05].

Q-러닝의 업데이트 공식은 SARSA와 유사하지만, 다음 상태(s')에서 취할 행동(a')을 탐험 정책에 따라 선택하는 대신, Q_opt(s', a) 중 Q-가치를 최대화하는 행동 max_a' Q_opt(s', a')을 가정하여 업데이트한다 [50:06]. 공식은 Q(s,a) ← Q(s,a) + η [R + γ max_a' Q(s',a') - Q(s,a)] 형태이다 [52:13]. 이 max 연산이 Q-러닝을 최적 정책 학습으로 이끌며, 가치 반복(value iteration)과 유사한 역할을 한다 [53:11]. Q-러닝은 현재 무작위 탐험 정책을 따르더라도 최적 Q-가치를 학습할 수 있다 [54:50]. 예를 들어, 화산 게임에서 무작위로 움직여 자꾸 화산에 빠지면서도, Q-러닝은 최적 경로(20의 보상을 주는 경로)를 찾아낼 수 있음을 보여준다 [54:31].

탐험과 활용의 상충관계: 엡실론-그리디 정책

강화 학습의 핵심 과제 중 하나는 '탐험(exploration)'과 '활용(exploitation)' 사이의 균형을 맞추는 것이다 [58:12]. 탐험은 새로운 행동과 상태를 발견하여 더 나은 정책을 찾을 기회를 제공하지만, 당장의 보상을 희생할 수 있다. 활용은 현재까지 학습된 최적의 행동을 따라 가장 많은 보상을 얻으려 하지만, 아직 발견되지 않은 더 나은 경로를 놓칠 수 있다 [57:06]. 강사는 이를 식당 선택, 통학 경로, 연구 문제 선택 등에 비유하며 인생의 비유로 설명한다 [58:44].

'엡실론-그리디(Epsilon-greedy) 정책'은 이 상충관계를 해결하는 간단하고 효과적인 방법이다 [59:27]. 이 정책은 1-ε(엡실론)의 확률로 현재까지 학습된 Q-가치가 가장 높은 행동을 선택하여 활용하고(탐욕적 행동), ε의 확률로 무작위 행동을 선택하여 탐험한다 [59:37]. ε 값은 학습 초기에는 높게 설정하여 탐험을 장려하고, 학습이 진행될수록 줄여서 활용에 집중하도록 조정할 수 있다 [1:00:10].

광대한 상태 공간 문제와 함수 근사를 통한 일반화

현실 세계의 강화 학습 문제는 상태 공간(state space)이 너무 거대하여 모든 상태-행동 쌍의 Q-가치를 개별적으로 저장하고 업데이트하는 것이 불가능하다 [1:01:58]. '암기식 학습(rote learning)' 방식은 새로운 상태에 대해 전혀 일반화할 수 없다 [1:03:16].

이 문제를 해결하기 위해 '함수 근사(function approximation)'가 사용된다 [1:03:43]. Q-가치 Q(s,a)를 w · Φ(s,a)와 같이 특징 벡터(feature vector) Φ(s,a)와 가중치 벡터(weight vector) w의 내적으로 근사하는 것이다 [1:04:01]. 즉, Q-가치 테이블 대신 w라는 적은 수의 파라미터를 학습하여 모든 상태-행동 쌍에 대한 Q-가치를 표현한다 [1:04:50]. 이렇게 하면 Q-러닝 업데이트를 파라미터 w에 대한 확률적 경사 하강법 형태로 변경할 수 있다 [1:05:04]. w ← w + η [R + γ max_a' Q(s',a', w) - Q(s,a, w)] Φ(s,a)와 같이, 잔차(residual)와 특징 벡터의 곱을 가중치에 더하는 방식으로 업데이트가 이루어진다 [1:05:10]. 이는 선형 회귀(linear regression)에서 가중치를 업데이트하는 방식과 유사하며 [1:05:27], 이를 통해 본 적 없는 새로운 상태에 대해서도 Q-가치를 일반화하여 추론할 수 있다.

주요 통찰·논점

강화 학습의 기본 프레임워크: 모델-추론-학습의 연결 고리

강화 학습은 MDPs, 베이즈 네트(Bayesian networks), 회귀 분석(regression) 등 다른 인공지능 분야와 마찬가지로 '모델', '추론', '학습'이라는 세 가지 구성 요소를 가진다 [0:21]. MDPs가 환경을 모델링하고, 가치 반복이 최적 정책을 '추론'하는 역할을 한다면, 강화 학습은 이러한 MDP 모델 자체를 '학습'하는 과정이다 [1:22]. 즉, 강화 학습은 모르는 환경에서 모델을 배우고, 그 모델을 바탕으로 최적 행동을 찾아가는 순환적인 과정으로 이해할 수 있다 [11:21].

모델 기반 vs. 모델 프리: 환경 모델 명시적 추정 여부

강화 학습 알고리즘은 크게 '모델 기반(Model-Based)'과 '모델 프리(Model-Free)'로 나뉜다 [21:07]. 모델 기반 방식(예: 모델 기반 몬테카를로)은 환경의 전이 확률과 보상 함수를 명시적으로 추정하여 MDP 모델을 구성한 후, 이 모델 위에서 최적 정책을 계산한다 [15:14]. 반면, 모델 프리 방식(예: 모델 프리 몬테카를로, SARSA, Q-러닝)은 환경 모델을 직접 만들지 않고, 대신 정책의 Q-가치나 최적 Q-가치를 데이터로부터 직접 학습한다 [21:45]. 모델 기반은 더 적은 데이터로 학습할 수 있지만(샘플 효율적), 정확한 모델을 구축하기 어렵고, 모델 프리 방식은 모델 구축의 어려움 없이 유연하게 학습할 수 있어 최근 딥 강화 학습 분야에서 많이 활용된다 [30:39].

몬테카를로 vs. 부트스트래핑: 추정 목표의 시간적 범위

Q-가치를 추정하는 방식에 따라 '몬테카를로(Monte Carlo)'와 '부트스트래핑(Bootstrapping)'으로 구분된다. 몬테카를로 방법(예: 모델 프리 몬테카를로)은 한 에피소드 전체의 최종 보상 합계(효용)를 사용하여 Q-가치를 업데이트한다 [24:18]. 이는 편향되지 않은(unbiased) 추정치를 제공하지만, 에피소드가 끝나야 업데이트할 수 있고 분산이 크다는 단점이 있다 [40:42]. 반면, 부트스트래핑 방법(예: SARSA, Q-러닝)은 현재 관찰된 보상과 다음 상태의 '추정된' Q-가치를 결합하여 Q-가치를 업데이트한다 [45:35]. 이는 에피소드 도중에도 즉시 업데이트할 수 있고 분산이 작지만, 자신의 추정치를 사용하기 때문에 편향된(biased) 추정치가 될 수 있다 [46:13].

온-정책 vs. 오프-정책: 행동 정책과 학습 정책의 일치 여부

정책 학습 방식에 따라 '온-정책(On-policy)'과 '오프-정책(Off-policy)' 학습으로 구분된다 [27:17]. 온-정책 학습(예: SARSA, 모델 프리 몬테카를로)은 에이전트가 환경과 상호작용하며 데이터를 수집하는 '행동 정책(behavior policy)'과 학습하려는 '목표 정책(target policy)'이 동일한 경우를 말한다 [27:48]. 즉, 자신이 따르는 정책의 가치를 배우는 것이다 [28:10]. 오프-정책 학습(예: Q-러닝, 모델 기반 몬테카를로)은 행동 정책과 목표 정책이 다를 수 있는 경우이다 [27:56]. 주로 탐험을 위해 무작위적인 행동 정책을 따르면서도, 궁극적으로는 최적 정책의 가치를 학습하는 데 사용된다 [54:50]. 이는 에이전트가 최적으로 행동하지 않으면서도 최적 행동을 학습할 수 있게 한다.

강화 학습의 핵심 도전 과제: 탐험-활용 상충관계와 일반화

강화 학습의 성공을 위한 두 가지 중요한 과제는 (1) '탐험(exploration)'과 '활용(exploitation)'의 균형 잡기, 그리고 (2) '일반화(generalization)'이다 [58:12]. 충분한 탐험 없이는 최적의 경로를 찾지 못할 수 있고, 충분한 활용 없이는 최고의 보상을 얻지 못한다 [57:06]. 엡실론-그리디와 같은 전략은 이 균형을 조절한다 [59:27]. 또한, 현실 세계의 방대한 상태 공간에서는 모든 상태를 직접 경험할 수 없으므로, 경험하지 못한 상태에 대해서도 적절히 행동할 수 있도록 '함수 근사(function approximation)'를 통해 학습된 지식을 일반화해야 한다 [1:03:43].

강화 학습의 차원: 상태와 피드백의 복잡성

강의는 지도 학습(supervised learning)부터 강화 학습까지 인공지능 패러다임을 '상태(state)'와 '피드백(feedback)'의 두 가지 차원으로 분류한다 [1:09:05]. 지도 학습은 '상태 없음(stateless)'과 '완전 피드백(full feedback)'의 가장 단순한 형태이다. 반면 강화 학습은 '상태 있음(stateful)'과 '부분 피드백(partial feedback)'을 모두 가진 가장 복잡한 형태이다. '다중 팔 밴딧 문제(multi-armed bandits)'는 상태는 없지만 부분 피드백만 있는 경우이며 [1:10:33], 기계 번역처럼 '상태는 있지만 완전 피드백을 받는' 경우도 존재한다 [1:10:46]. 이러한 분류는 강화 학습이 왜 어려운 문제인지 이해하는 데 도움을 준다.

인상적인 지점

  • 강화 학습을 인생에 비유: 강사는 강화 학습의 '탐험-활용 상충관계'를 인생에서 새로운 경험을 시도할지(탐험), 아니면 이미 성공한 방법을 고수할지(활용)를 결정하는 과정에 비유한다 [58:16]. 이는 강화 학습의 본질을 직관적으로 이해시키는 탁월한 비유이다.
  • SARSA 알고리즘 이름의 유래: SARSA라는 이름이 단순히 상태(State)-행동(Action)-보상(Reward)-다음 상태(State')-다음 행동(Action')의 첫 글자를 따서 지어졌다는 설명은 학술 용어가 예상외로 직관적일 수 있음을 보여준다 [43:10].
  • Q-러닝의 반직관적인 학습 능력: 에이전트가 무작위 탐험 정책을 따르며 화산에 계속 빠지는 비최적 행동을 하더라도 [54:06], Q-러닝은 오프-정책 학습 덕분에 최적 정책의 Q-가치를 정확하게 학습할 수 있다는 점은 매우 흥미롭다 [54:50]. 이는 에이전트의 현재 행동이 반드시 최적이어야만 최적 정책을 배울 수 있는 것은 아니라는 강력한 메시지를 전달한다.
