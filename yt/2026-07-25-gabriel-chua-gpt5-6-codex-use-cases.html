OpenAI 내부자가 직접 알려주는 GPT-5.6과 Codex 활용법

TL;DR

이 영상은 OpenAI의 Gabriel Chua가 GPT Voice의 최신 발전과 Codex의 다재다능한 기능을 시연한다. 실시간 동시 통역부터 크롬 확장 프로그램 개발, 데이터 분석, PowerPoint 생성, 클라우드 기반 자동화까지, AI가 일상적인 작업과 전문 개발 환경을 어떻게 혁신할 수 있는지 구체적인 예시로 보여준다. 특히 GPT-5.6 Sol과 Codex의 에이전트 기능에 중점을 둔다.

풀시청 판단

이 영상은 AI의 최신 발전이 실제 생활과 개발 환경에 어떻게 적용되는지 궁금한 사람들에게 매우 유용하다. OpenAI의 최신 기술(GPT Voice, GPT-5.6 Sol, Codex)에 대한 최신 정보를 얻을 수 있으며, 특히 실시간 동시 통역, AI를 활용한 크롬 확장 프로그램 개발, 데이터 분석 및 프레젠테이션 자동 생성, 클라우드 환경에서의 AI 에이전트 활용 등 다양한 활용 사례를 직접 눈으로 확인할 수 있다.

다만, 영상은 기능 시연에 집중하므로 기술의 심층적인 작동 원리나 코딩 방법론에 대한 자세한 설명은 부족하다. AI 개발자나 연구자에게는 표면적인 내용으로 느껴질 수 있다. 또한, 소개된 GPT-5.6 Sol은 초기 접근이 제한적이라고 언급되며, 시연된 기능들이 데모 환경에 맞춰 최적화된 결과일 수 있다는 점을 고려해야 한다. 새로운 AI 기술의 '무엇을 할 수 있는지'에 초점을 맞추는 사용자에게 적합하며, '어떻게 작동하는지'에 대한 깊은 이해를 원한다면 추가 자료가 필요하다.

핵심 내용

실시간 동시 통역을 넘어선 GPT Voice의 발전: 즉각적인 대화

OpenAI는 실시간 동시 통역 기능을 탑재한 GPT 음성(Voice)을 공개했다. 과거에는 음성-텍스트 변환, LLM 처리, 텍스트-음성 변환의 단계별 처리 방식으로 인해 느리고 턴 방식 대화처럼 부자연스러운 부분이 있었다. 그러나 이제는 [2:23] 화자가 말하는 동안 GPT 라이브(Live)가 즉시 응답하여 매끄럽고 끊김 없는 상호작용이 가능해졌다. 이는 에어팟과 ChatGPT 계정만 있으면 누구나 무료로 사용할 수 있다 [3:01]. 때로는 더 복잡한 지능이 필요할 때, GPT 라이브 1은 GPT-5.5와 같은 더 큰 모델에 작업을 위임하여 검색 등 필요한 추가 기능을 수행한다.

GPT-5.6 Sol: Cerebras와 협력하여 초고속 추론 실현

OpenAI는 Cerebras 팀과 협력하여 GPT-5.6 Sol 모델을 Cerebras 시스템에 도입할 예정이다 [3:22]. 이 모델은 초당 최대 750 토큰이라는 전례 없는 속도로 최첨단 AI 성능을 제공한다. 이전에 연구용 미리 보기로 제공되던 GPT-5.3 Spark는 GPT-5.6 Sol에 통합되어 성능을 더욱 향상했다. 초기에는 접근이 제한되지만, 점차 더 많은 사용자에게 제공할 계획이다 [4:01].

코드 작업을 넘어선 Codex의 진화: AI 에이전트

Codex는 단순히 코드 생성 도구를 넘어선 다재다능한 AI 에이전트로 진화했다 [4:07]. 실시간 통역과 게임 개발, 이미지 생성 등 기존 기능에 더해 다양한 개선 사항과 새로운 기능이 추가되었다. 사용자는 자연어로 Codex와 대화하며 복잡한 작업을 지시할 수 있다.

Codex를 활용한 실시간 유튜브 채팅 번역 확장 프로그램 개발

Gabriel은 한국어로 진행되는 YouTube 라이브 스트리밍 채팅을 실시간으로 영어로 번역해 주는 크롬 확장 프로그램을 Codex를 활용하여 즉석에서 개발하는 과정을 시연한다 [5:00]. 그는 Codex에 구체적인 요구 사항을 자연어로 설명하고, Codex는 개발 계획을 수립하고 필요한 질문을 던지며 작업을 진행한다. 이는 Codex가 복잡한 소프트웨어 개발 프로젝트도 사용자와 대화하듯이 처리할 수 있음을 보여준다.

Codex의 직관적 상호작용 방식: 계획 모드 불필요, 부속 에이전트와 목표 설정

Codex는 별도의 '계획 모드' 없이 자연스러운 대화 방식으로 상호작용한다 [4:44]. 개발자는 원하는 것을 직접 말하면 된다. 또한, Codex는 '자동 검토(auto-review)' 기능을 통해 부속 에이전트(sub-agent)를 생성하여 작업을 분담하고, 사용자가 각 명령을 일일이 승인하거나 완전히 자율적으로 맡기는 중간 지점을 제공한다 [5:51]. 사용자는 Codex에게 스스로 목표를 설정하도록 지시할 수 있으며 [7:35], 이를 통해 에이전트가 보다 자율적으로 작업을 추진하게 된다.

OpenAI 개발자 플러그인으로 API 키 관리 및 활용 간소화

Codex는 OpenAI 개발자 플러그인(OpenAI Developers plugin)을 통해 API 키 관리 과정을 혁신한다 [6:45]. 과거에는 API 키를 웹사이트에서 생성하고 다운로드하여 안전하게 보관해야 했지만, 이제 Codex는 이 플러그인을 사용하여 자동으로 API 키를 발급하고 교체하며 [7:06], 에이전트나 ChatGPT 앱 개발을 위한 모범 사례를 교육하기도 한다 [6:51]. 이는 개발자가 API 관리 부담 없이 바로 개발에 착수할 수 있도록 돕는다.

대화 흐름을 방해하지 않는 부가 대화와 상황 공유

Codex와 작업하는 동안, 사용자는 주 작업 에이전트의 흐름을 방해하지 않고 별도의 '부가 대화(side conversation)'를 시작할 수 있다 [8:03]. 예를 들어, 에이전트의 진행 상황을 묻거나 도움이 필요한지 확인하는 등의 질문을 부가 대화로 처리하고, 이를 메인 스레드(main thread)로 전달하게 할 수 있다 [8:27]. 이 기능을 통해 개발자는 여러 작업을 동시에 진행하면서도 에이전트와의 소통을 유연하게 유지할 수 있다.

화면 캡처를 넘어서는 콘텍스트 전달 기능

Codex는 단순한 화면 스크린샷 기능을 넘어선 '앱 샷(App Shot)' 기능을 제공한다 [9:12]. 이 기능은 화면의 이미지를 캡처할 뿐만 아니라, 이미지 내의 모든 텍스트와 데이터를 함께 인식하여 Codex에 전달한다 [9:30]. 예를 들어, 이메일 내용을 앱 샷으로 캡처한 뒤 Codex에게 답장 작성을 요청하거나, 특정 이미지를 만화책 스케치 스타일로 변환해 달라고 지시하는 등 다양한 방식으로 콘텍스트를 활용할 수 있다.

Codex의 다재다능함: 데이터 분석부터 보고서, 이미지 생성까지

Codex는 소프트웨어 개발을 넘어 다양한 분야에서 활용된다. ICML 학술대회 논문 데이터셋을 분석하여 추세를 파악하고 초록별로 분류한 뒤, 이를 토대로 발표용 PowerPoint 프레젠테이션을 자동으로 생성할 수 있다 [10:14]. 또한, 이미지 생성 기능이 Codex 내에서 직접 작동하며 [10:35], 오픈 소스 저장소를 기반으로 IKEA 스타일의 사용 설명서를 이미지와 함께 만들도록 지시할 수도 있다 [10:46].

휴대폰으로 연동되는 모바일 Codex 및 클라우드 배포

Codex는 휴대폰과도 연동되어 언제 어디서든 작업을 이어갈 수 있다 [12:08]. 휴대폰에서 새로운 대화를 시작하거나 기존 작업의 진행 상황을 확인하고, 새로운 작업을 지시하는 등 실시간으로 상호작용이 가능하다 [12:47]. 또한, DigitalOcean 플러그인을 사용하여 Codex를 클라우드에 배포할 수 있으며 [13:01], DigitalOcean 드롭렛(droplet)을 가상 머신으로 활용해 Codex를 실행하면 노트북을 닫아도 작업이 중단되지 않고 클라우드에서 계속 처리된다 [16:09].

반복 작업을 자동화하는 Codex의 심장 박동(Heartbeat) 기능

Codex는 '심장 박동(heartbeat)'과 같은 자동화 기능을 제공한다 [13:46]. 이는 5분마다 특정 상태(예: 서버 준비 완료 여부)를 자동으로 확인하도록 설정할 수 있는 기능이다. 서버 부팅 등 시간이 걸리는 작업의 진행 상황을 수동으로 확인할 필요 없이 Codex가 알아서 처리한다 [13:57]. 이메일 처리, Slack 알림, PR(pull request) 자동 생성, 피드백 요약 등 다양한 반복 작업을 자동화하여 효율성을 극대화할 수 있다 [14:09].

주요 통찰·논점

AI와의 상호작용 패러다임 변화: 자연어 명령과 실시간 협업

이 영상은 AI와의 상호작용 방식이 단순히 텍스트 명령을 넘어서 실시간 자연어 대화와 시각적 콘텍스트(앱 샷)를 통해 이루어지는 새로운 패러다임을 제시한다 [4:44]. 개발 과정에서 Codex가 질문을 던지고 사용자가 응답하며, 부속 에이전트와 목표 설정을 통해 AI가 자율적으로 작업을 이어나가는 모습은 AI가 단순한 도구가 아닌 협력적인 파트너로 진화하고 있음을 보여준다. 이러한 변화는 비전문가도 AI를 활용해 복잡한 작업을 수행할 수 있는 가능성을 연다.

AI 에이전트의 자율성과 감독의 균형: 자동 검토와 목표 설정

Codex의 자동 검토(auto-review) 기능과 스스로 목표를 설정하는 능력은 AI 에이전트가 높은 자율성을 가질 수 있음을 보여준다 [5:51]. 동시에 사용자가 개입하여 작업을 승인하거나 진행 상황을 확인할 수 있는 메커니즘을 제공함으로써, AI의 자율성과 인간의 감독 사이에서 적절한 균형점을 찾으려는 노력을 엿볼 수 있다. 이는 복잡하고 중요한 작업을 AI에 위임할 때 신뢰성과 안정성을 확보하는 중요한 요소가 된다.

개발 워크플로우의 혁신: API 키 관리부터 클라우드 배포까지

Codex는 API 키 관리, 클라우드 환경 설정, 배포 등 기존 개발 과정에서 번거로웠던 작업들을 AI가 직접 자동화하여 개발 워크플로우를 대폭 간소화한다 [6:27]. DigitalOcean과 같은 클라우드 서비스와의 플러그인 연동을 통해 가상 머신 생성 및 설정, SSH 키 관리까지 자동으로 처리하는 모습은 개발자가 인프라 관리보다는 핵심 개발에 집중할 수 있도록 돕는 미래를 시사한다.

AI가 정보 처리 및 콘텐츠 생성 방식에 미치는 영향

앱 샷(App Shot) 기능으로 단순한 스크린샷을 넘어 이미지 내 텍스트와 데이터를 함께 인식하고 활용하는 능력은 AI의 정보 처리 방식에 큰 발전을 의미한다 [9:07]. 또한, ICML 논문 데이터셋을 분석하여 PowerPoint 프레젠테이션을 자동으로 생성하고, 복잡한 저장소를 기반으로 IKEA 스타일 설명서를 만드는 등 다양한 콘텐츠를 AI가 직접 생성하고 편집하는 능력은 미래의 문서 작업 및 디자인 분야에 혁신적인 변화를 가져올 잠재력을 보여준다.

인상적인 지점

  • 실시간 동시 통역 시연: 조코딩의 한국어 음성을 Gabriel의 에어팟에서 실시간 영어로 통역하고, Gabriel의 영어 음성을 조코딩의 에어팟에서 실시간 한국어로 통역하는 시연 [1:02]은 AI 음성 기술의 비약적인 발전을 직관적으로 보여준다.
  • API 키 발급 자동화: 과거에는 복잡했던 API 키 발급 및 관리를 Codex가 OpenAI 개발자 플러그인을 통해 자동으로 처리하는 기능 [7:06]은 개발 효율성 측면에서 매우 인상 깊다.
  • 앱 샷 기능: 단순한 스크린샷이 아니라 화면의 이미지와 그 안에 담긴 텍스트 및 데이터를 동시에 인식하여 Codex에 전달하는 '앱 샷' 기능 [9:30]은 AI의 콘텍스트 이해 능력이 얼마나 발전했는지 보여주는 좋은 예시다. 이메일 답장이나 이미지 변환 등 다양한 활용 가능성이 돋보인다.
  • PowerPoint 슬라이드 생성 및 발송: Codex가 데이터 분석 결과를 바탕으로 PowerPoint 슬라이드를 자동으로 생성하고, 심지어 이를 Codex 내에서 직접 편집하고 다른 사람에게 이메일로 발송까지 하는 기능 [14:15]은 AI의 문서 작업 자동화 능력을 극명하게 보여준다.
  • 클라우드 기반 작업 전환: 노트북을 닫아도 Codex 작업을 클라우드에서 계속 실행하게 하고, 휴대폰으로 클라우드 서버에 연결하여 작업을 관리할 수 있는 기능 [16:09]은 AI를 활용한 유연한 작업 환경의 미래를 제시한다.
