NEW Gemini in Chrome Updates | Hands on with the Latest Chrome AI Features

Tasia Custode9:22게시 2026-01-28
#gemini#chrome#ai-features#agentic-ai#autobrowse#google

TL;DR

이 영상은 Google Chrome에 새로 추가된 Gemini 기능들을 시연한다. 새 사이드 패널을 통해 탭 정보를 활용한 검색, 이미지 변환 기능인 Nano-Banana, Gmail 등 연결된 앱과의 연동, 그리고 사용자를 대신해 웹사이트를 직접 탐색하고 작업을 수행하는 에이전트 오토브라우즈(autobrowse) 기능들을 집중적으로 다룬다.

풀시청 판단

이 영상은 Google Chrome과 Gemini의 통합 기능을 효과적으로 활용하려는 모든 Chrome 사용자에게 높은 시청 가치를 지닌다. 멀티태스킹 효율성을 높이고 웹 브라우징 경험을 혁신하고 싶은 사람이라면 풀시청하여 새로운 AI 에이전트 기능의 잠재력을 파악하고 실제 활용 방법을 익힐 수 있다. 특히 항공편 검색, 식당 예약, 이메일 작성 등 일상적인 작업을 자동화하는 데 관심이 많다면 유용하다.

  • 약점 및 한계:
    • 기술적인 심층 분석보다는 사용자 관점의 데모 시연에 집중한다. 각 기능의 작동 원리나 내부 구조에 대한 설명은 없다.
    • 개인 정보 보호나 AI의 윤리적 함의에 대한 논의는 다루지 않는다.
    • 일부 기능은 현재 미국 내 Windows, macOS, Chromebook Plus 사용자에게만 제공되며, 오토브라우즈 기능은 AI Pro 및 Ultra 구독자에게 우선적으로 배포된다.

핵심 내용

멀티태스킹의 새 중심 — 크롬 사이드 패널 [0:26]

새로운 Chrome 사이드 패널은 사용자가 브라우징 중 Gemini에 쉽게 접근하여 다양한 작업을 수행하도록 돕는다. 사용자는 현재 보고 있는 탭과 관련된 질문을 하거나 완전히 새로운 질문을 던질 수 있다. 예를 들어, 여행 예약 웹사이트 Viator에서 특정 조건을 만족하는 워킹 투어를 검색해달라고 요청하면, Gemini는 해당 탭의 정보를 바탕으로 조건을 충족하는 투어 옵션을 요약하고 관련 링크를 제공한다 [0:49]. 특히 이 사이드 패널의 강점은 Gemini가 작업을 수행하는 동안 사용자가 다른 탭으로 이동하여 다른 작업을 진행할 수 있다는 점이다. 나중에 원래 탭으로 돌아오면 Gemini가 진행한 작업을 확인할 수 있으며 [1:33], 필요하다면 현재 대화를 다른 탭으로 이동시킬 수도 있다 [2:14]. 여러 탭에 걸쳐 분산된 정보를 한 채팅 안에서 비교하고 싶을 때도 유용하다. 예를 들어, 부동산 매물 사이트에서 여러 아파트 매물을 새 탭으로 열면, 이 탭들의 정보가 모두 하나의 Gemini 채팅으로 자동으로 공유되어 쉽게 비교할 수 있다 [2:30].

이미지 변환 — Nano-Banana [3:07]

Gemini는 웹상의 이미지를 즉석에서 변환하는 Nano-Banana 기능을 지원한다. 이 기능은 사용자가 이미지 내의 특정 요소를 다른 것으로 교체할 때 유용하다. 예를 들어, 아파트 내부 사진에서 현재 소파를 더 모던한 회색 섹션형 소파로 바꿔달라고 요청하면, Gemini는 이미지의 다른 부분은 그대로 유지한 채 소파만 요청에 따라 변경된 이미지로 보여준다 [3:19]. 이를 통해 사용자는 실제 구매나 배치 전에 시각적으로 공간을 상상해볼 수 있다.

에이전트 기능의 시작 — 연결된 앱 [3:46]

Gemini는 Gmail, Google Calendar, Google Maps, Google Flights, Google Shopping, YouTube 등 다른 Google 앱과 연동되어 에이전트(agentic) 기능을 수행할 수 있다. 예를 들어, 이전에 검색했던 투어 세부 정보를 Brett에게 이메일로 보내달라고 요청하면 [4:02], Gemini는 Gmail에 접근하여 Brett의 정보를 파악하고 해당 세부 정보가 담긴 이메일을 자동으로 작성한다. 이메일 내용을 Chrome 내에서 직접 편집할 수 있으며 [4:29], 다른 탭으로 이동하지 않고도 바로 이메일을 보낼 수 있어 작업 흐름을 끊기지 않게 유지한다.

웹 브라우징 자동화 — 오토브라우즈 [5:01]

Gemini의 가장 혁신적인 에이전트 기능 중 하나는 사용자를 대신해 웹 브라우징 작업을 자동으로 수행하는 오토브라우즈다. Gemini는 사용자의 마우스나 키보드 조작 없이 웹페이지를 탐색하고 클릭하여 필요한 정보를 얻거나 작업을 완료한다. 예를 들어, 항공편 검색 결과에서 각 항공편의 경유 시간을 확인하려면 보통 사용자가 직접 클릭해야 하지만 [5:27], Gemini는 사용자 대신 이 작업을 수행하여 경유 시간 정보를 사이드 패널에 추가해준다 [5:37].

식당 예약도 마찬가지다. 특정 식당에서 4인용 예약을 요청하면 [6:19], Gemini가 해당 식당 웹사이트로 이동하여 예약을 시도한다 [6:25]. 이때 사용자는 다른 탭에서 다른 작업을 계속할 수 있으며 [6:38], Gemini가 백그라운드에서 작업 중임을 탭에 표시하여 알려준다 [6:46]. 중요한 점은 Gemini가 예약이나 구매와 같은 최종적인 행동을 하기 전에는 반드시 사용자에게 확인을 요청한다는 것이다. 예를 들어, 특정 시간으로 예약을 완료하기 전에 사용자에게 "작업 확인"을 요청하여 최종 결정권을 부여한다 [7:20]. 이 기능을 처음 사용할 때는 Gemini가 브라우징 제어 권한을 요청하며 [6:02], 사용자는 언제든지 자동 작업을 일시 중지하고 수동으로 제어할 수 있다 [6:32].

주요 통찰·논점

Gemini와 Chrome의 통합으로 브라우징 방식이 바뀐다 [0:00]

Gemini가 Chrome에 통합되면서 웹 브라우징은 단순한 정보 검색을 넘어 능동적인 작업 수행의 영역으로 확장된다. 사이드 패널을 통해 탭의 맥락을 이해하고, 연결된 앱과 연동되며, 심지어 사용자를 대신해 웹사이트를 직접 탐색하는 오토브라우즈 기능은 브라우저를 개인 비서에 가까운 존재로 탈바꿈시킨다. 이는 사용자가 여러 탭을 오가며 정보를 수집하고 작업을 처리하는 비효율적인 방식을 근본적으로 개선하는 계기가 된다.

에이전트 기능으로 능동적인 작업 수행이 가능해진다 [3:50]

Gemini의 에이전트 기능은 단순히 정보를 요약하거나 생성하는 것을 넘어, 사용자의 의도를 파악하고 웹 환경에서 실제 행동을 수행한다. Gmail 연동을 통한 이메일 작성 및 발송, 웹사이트를 직접 탐색하는 오토브라우즈를 통한 항공편 정보 수집이나 식당 예약 등은 AI가 사용자의 복잡한 작업을 능동적으로 대신 처리할 수 있음을 보여준다. 이는 사용자가 반복적이고 시간 소모적인 작업을 AI에 위임하고 더 중요한 일에 집중할 수 있게 하여 멀티태스킹 효율성을 극대화한다.

AI 에이전트의 제어권은 사용자에게 있다 [06:02, 07:20]

강력한 에이전트 기능에도 불구하고, Gemini는 중요한 결정이나 최종적인 행동(예: 예약 완료, 구매)에 앞서 반드시 사용자에게 확인을 요청한다. 또한, Gemini가 웹 브라우징을 제어하기 전에 사용자 승인을 구하며 [6:02], 언제든지 자동 작업을 일시 중지하고 수동으로 제어할 수 있는 옵션을 제공한다 [6:32]. 이러한 사용자 통제권은 AI 에이전트의 신뢰성과 안전성을 보장하고, 사용자가 자신의 디지털 활동에 대한 주도권을 잃지 않도록 돕는 중요한 장치이다.

모든 작업 기록과 생성물은 저장된다 [7:45]

Gemini와의 모든 대화 기록은 자동으로 저장되어 언제든지 다시 확인할 수 있다. 크롬 사이드 패널 내의 최근 채팅 목록에서 과거 대화를 열거나 [7:50], Gemini 웹사이트(gemini.google.com)에서 모든 저장된 채팅을 확인할 수 있다 [8:05]. Nano-Banana로 생성된 이미지 또한 이 채팅 기록 내에 저장되므로 [8:16], 사용자는 자신의 작업 이력을 쉽게 관리하고 필요한 정보를 다시 찾아볼 수 있다.

인상적인 지점

  • Gemini가 항공편 경유 시간을 확인하기 위해 마우스 클릭 없이 웹페이지 내의 링크를 직접 탐색하고 정보를 수집하는 오토브라우즈 시연 [5:37]. AI가 웹사이트를 사용하는 방식을 시각적으로 보여주어 그 능동성을 직관적으로 이해하게 한다.
  • Gmail 연동을 통해 이메일을 자동으로 작성하고, 크롬 내에서 내용을 편집한 후 바로 발송까지 완료하는 시연 [4:29]. 다른 앱으로 이동할 필요 없이 작업이 연결되는 '끊김 없는' 경험이 인상적이다.
