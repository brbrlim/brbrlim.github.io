TL;DR

이 영상은 Google Chrome에 새로 추가된 Gemini 기능들을 소개한다. 웹 브라우징 중 여러 작업을 동시에 처리하고 싶거나, Gemini가 연결된 다른 Google 앱과 연동되어 복잡한 작업을 대신 처리해주기를 바라는 사용자에게 특히 유용하다. 새로운 사이드 패널, 이미지 변환 기능, 그리고 브라우저를 직접 조작하는 자동 탐색 기능 등, Gemini의 향상된 에이전트 역량을 실제 사용 사례와 함께 자세히 시연한다.

풀시청 판단

이 영상은 Google Chrome의 새로운 AI 기능, 특히 Gemini와 Chrome의 통합 업데이트에 관심 있는 사용자에게 실용적인 안내서 역할을 한다. Gemini를 사용해 멀티태스킹 효율을 높이거나 웹 작업을 자동화하고 싶은 사용자라면 [0:26]부터 시연되는 사이드 패널 기능과 [3:07]의 이미지 변환, 그리고 특히 [3:52]부터 시작되는 에이전트 기능 시연을 통해 많은 통찰을 얻을 수 있다.

다만, 이 영상은 새로운 기능의 소개와 시연에 초점을 맞추므로, 각 기능의 기술적 원리나 심층적인 배경 설명은 포함하지 않는다. 또한, 대부분의 기능이 현재 미국 내 Windows, macOS, Chromebook Plus 사용자에게 우선 제공되며, 자동 탐색 기능은 AI Pro 및 Ultra 구독자에게 먼저 공개되므로, 다른 지역이나 비구독자에게는 당장 적용되지 않을 수 있다. 영상은 전반적으로 홍보성 톤을 유지하며, 제품의 잠재적 한계나 개선점에 대한 언급은 거의 없다.

핵심 내용

새로운 사이드 패널로 크롬 탭에서 바로 Gemini와 대화한다

Gemini 사이드 패널은 모든 Gemini in Chrome 사용자에게 제공되는 핵심 기능이다 [0:26]. 사용자는 현재 보고 있는 웹페이지와 관련된 질문을 하거나, 완전히 독립적인 질문을 던질 수 있다. 예를 들어, 여행 사이트에서 특정 조건(2시간 미만, 오전 9시 이후 시작, 높은 평점)에 맞는 도보 투어를 찾아달라고 요청하면, Gemini가 수동으로 모든 옵션을 정렬할 필요 없이 즉시 조건에 맞는 3가지 투어 옵션을 제시한다 [0:49]. Gemini는 투어의 종류, 소요 시간, 시작 시간, 그리고 관련 링크까지 제공하여 사용자가 더 자세한 정보를 쉽게 확인할 수 있게 돕는다.

여러 탭을 오가며 작업해도 대화 맥락이 유지된다

Gemini 사이드 패널의 큰 장점은 사용자가 다른 탭으로 이동하여 작업을 계속하더라도, Gemini가 이전 탭에서 진행 중인 작업을 백그라운드에서 이어서 처리한다는 점이다 [1:26]. 예를 들어, 투어 정보를 검색하면서 동시에 뉴스 탭으로 이동하여 뉴스를 읽을 수 있다. 이후 다시 투어 탭으로 돌아와 Gemini와의 대화를 이어갈 수 있으며 [2:00], 필요하다면 진행 중인 대화를 다른 탭으로 옮겨 계속할 수도 있다 [2:11]. 이는 작업 흐름을 끊지 않고 여러 task를 효율적으로 관리할 수 있게 돕는다.

여러 탭의 정보를 한 번에 비교한다

Gemini는 여러 탭에 걸쳐 있는 정보를 한 번의 대화에서 비교하는 기능을 제공한다 [2:30]. 예를 들어, 오스틴 지역의 임대 아파트를 검색하면서 여러 매물을 새 탭으로 열면, 이 모든 탭의 정보가 하나의 Gemini 채팅에 자동으로 공유된다 [2:34]. 사용자는 이 기능을 활용하여 각 매물의 장단점을 Gemini에게 비교해달라고 요청하거나, 특정 기준에 따라 가장 적합한 옵션을 추천해달라고 할 수 있다. 이로써 여러 탭을 일일이 오가며 정보를 수집하고 비교하는 번거로움을 크게 줄일 수 있다.

Nano-banana로 웹 이미지의 요소를 즉석에서 바꾼다

Gemini in Chrome은 nano-banana 기술을 활용해 웹상의 이미지를 실시간으로 변환하는 기능을 제공한다 [3:07]. 예를 들어, 아파트 내부 사진에서 현재 소파를 다른 스타일(예: 과도기적 스타일, 회색, 섹션형)의 소파로 바꿔달라고 요청할 수 있다. Gemini는 몇 초 만에 요청에 따라 소파를 교체하면서 이미지의 다른 모든 요소는 그대로 유지한다 [3:23]. 이 기능은 웹에서 본 공간이나 제품을 사용자의 취향에 맞게 즉석에서 재구성하여 시각화하는 데 유용하다.

연결 앱(Gmail, Gcal 등)으로 Gemini가 직접 작업을 수행한다

Gemini in Chrome은 Gmail, Gcal, Google Maps, Google Flights, Google Shopping, YouTube 등 여러 Google 앱과 연결되어 에이전트 기능을 수행한다 [3:52]. 연결 앱 기능을 활성화하면, Gemini는 사용자의 지시에 따라 해당 앱에서 직접 작업을 처리한다. 예를 들어, 특정 투어 세부 정보를 친구에게 이메일로 보내달라고 요청하면 [4:02], Gemini는 Gmail에서 해당 친구를 식별하고, 요청된 정보가 담긴 이메일 초안을 자동으로 작성해준다. 작성된 이메일은 Chrome 내부에서 바로 수정하고 전송할 수 있어, Gmail 앱으로 이동할 필요 없이 작업을 완료할 수 있다 [4:29].

브라우저를 직접 조작해 정보를 찾아주는 자동 탐색 기능

Gemini in Chrome은 사용자를 대신하여 웹 페이지를 직접 탐색하고 정보를 수집하는 자동 탐색(autobrowse) 기능을 제공한다 [5:01]. 예를 들어, 항공편 검색 중 경유 시간을 확인하려면 보통 수동으로 각 항공편의 세부 정보 페이지를 클릭해야 한다. 하지만 Gemini에게 경유 시간을 문의하면, Gemini는 사용자의 마우스 조작 없이 직접 웹 페이지를 클릭하고 탐색하여 필요한 정보를 찾아 사이드 패널에 추가해준다 [5:22]. 이 기능은 복잡하고 반복적인 웹 탐색 작업을 자동화하여 시간을 크게 절약한다.

중요한 작업은 사용자에게 최종 확인을 거친다

자동 탐색 기능이 브라우저 제어권을 넘겨받아 작업을 수행하는 중에도 사용자는 언제든지 해당 작업을 일시 중지하고 수동으로 제어할 수 있다 [6:32]. 특히, 식당 예약이나 구매와 같이 중요한 작업을 완료하기 전에는 [7:20] Gemini가 반드시 사용자에게 최종 확인을 요청한다. 예를 들어, 특정 시간의 식당 예약을 진행하려고 할 때, Gemini는 예약 버튼을 누르기 전에 사용자에게 "작업을 확인해달라"는 알림을 표시한다 [7:29]. 이는 AI의 자동화된 기능이 개인의 의도와 다르게 작동하는 것을 방지하고, 사용자에게 항상 최종 결정권을 부여하는 안전장치 역할을 한다.

모든 대화와 생성 이미지는 자동으로 저장된다

Gemini in Chrome에서 이루어진 모든 대화 내용과 nano-banana를 이용해 생성된 이미지들은 자동으로 저장된다 [7:45]. 사용자가 탭을 닫더라도 걱정할 필요 없이, Gemini 사이드 패널의 메뉴에서 최근 대화 기록을 다시 열어볼 수 있다 [7:50]. 또한, gemini.google.com 웹사이트에서도 저장된 모든 대화 기록을 확인할 수 있으며 [8:05], 이는 생성된 이미지까지 포함한다. 이 기록 관리 기능은 사용자가 과거 작업을 쉽게 참조하고 이어서 할 수 있도록 돕는다.

곧 개인화된 지능이 추가되며, 일부 기능은 구독자에게 먼저 제공된다

Google은 향후 몇 달 안에 Gemini 개인화된 지능(personal intelligence) 기능을 Chrome의 Gemini에 통합할 예정이라고 밝힌다 [8:27]. 현재 새로운 Gemini in Chrome 기능은 미국 내 Windows, macOS, Chromebook Plus 기기에서 사용할 수 있으며, 특히 자동 탐색 기능은 AI Pro 및 Ultra 구독자에게 우선적으로 제공될 예정이다 [8:36]. 이는 Google이 Gemini의 고급 기능을 점진적으로 확대하고, 구독자를 위한 프리미엄 경험을 제공하려는 전략을 보여준다.

주요 통찰·논점

브라우징 경험을 '수동'에서 '에이전트 주도'로 전환한다

이 영상이 보여주는 가장 중요한 통찰은 웹 브라우징 경험의 근본적인 변화다. 기존의 브라우징이 사용자가 직접 페이지를 클릭하고 정보를 찾아 나서는 '수동적' 방식이었다면, Gemini의 에이전트 기능은 브라우저 자체가 사용자의 의도를 이해하고 능동적으로 작업을 수행하는 '에이전트 주도' 방식으로 전환될 가능성을 제시한다 [5:01]. 이는 사용자가 더 이상 단순 반복 작업에 시간을 낭비하지 않고, 더 복잡하고 창의적인 작업에 집중할 수 있게 돕는다.

맥락 유지와 다중 앱 연동으로 작업 전환 비용을 최소화한다

Gemini의 사이드 패널과 연결 앱 기능은 사용자가 여러 탭과 앱을 오가며 발생하는 '맥락 전환(context switching) 비용'을 극적으로 줄여준다 [2:11], [4:29]. 하나의 대화 흐름 안에서 웹 검색, 이미지 생성, 이메일 작성, 예약 등 다양한 작업을 매끄럽게 연결할 수 있게 함으로써, 기존에는 여러 애플리케이션을 넘나들며 발생했던 집중력 분산과 시간 낭비를 최소화하고 작업 효율성을 극대화한다.

인상적인 지점

Gemini가 직접 웹 페이지를 클릭하고 탐색하여 정보를 찾아내는 자동 탐색 기능 시연은 매우 인상적이다 [5:37]. 화자가 "마우스에 손을 대지 않았는데 Gemini가 필요한 곳을 클릭하고 있다"고 말하는 부분은 에이전트 AI의 발전이 현실에 얼마나 가까워졌는지 직관적으로 보여준다. 이는 AI가 단순한 정보 검색 도구를 넘어, 실제 사용자 인터페이스를 조작하여 목표를 달성하는 새로운 단계로 진입했음을 시사한다.
