TL;DR

Andrej Karpathy 강사는 이 영상에서 GPT-3와 ChatGPT의 기반이 되는 트랜스포머 아키텍처를 처음부터 구현하는 과정을 상세히 설명한다. PyTorch를 사용해 'Tiny Shakespeare' 데이터셋으로 문자 단위 언어 모델을 구축하며, 토큰화부터 어텐션 메커니즘, 다중 헤드, 잔여 연결, 레이어 정규화 등 주요 구성 요소를 코드를 통해 직접 보여준다. 마지막으로 모델을 스케일업하고, 실제 ChatGPT의 사전 훈련 및 미세 조정 단계와의 차이점을 짚어준다.

풀시청 판단

이 영상은 GPT와 트랜스포머 아키텍처의 내부 작동 원리를 코드를 통해 깊이 있게 이해하고 싶은 사람들에게 매우 유용하다. 특히 PyTorch에 대한 기본 지식과 기본적인 미적분학, 통계학 지식이 있다면 강사의 설명을 더 잘 따라갈 수 있다. 단순히 개념적인 이해를 넘어 실제로 작동하는 모델을 구축하는 과정을 처음부터 끝까지 지켜보며 코드가 각 개념과 어떻게 연결되는지 파악할 수 있다.

다만, 약 2시간에 달하는 긴 분량과 상당한 밀도의 코드 설명으로 인해 집중력이 요구된다. 또한 이전에 강사가 진행했던 make more 시리즈 등 더 기초적인 신경망 강의를 시청했다면 언어 모델링의 기본 틀을 더 쉽게 이해할 수 있다. 실제 ChatGPT와 같은 대규모 모델을 직접 구축하는 것은 막대한 컴퓨팅 자원이 필요하며, 영상에서 다루는 모델은 단순한 문자 수준의 '장난감' 모델이라는 점을 인지해야 한다. 사전 훈련 이후의 복잡한 미세 조정(RLHF 등) 과정은 깊이 있게 다루지 않으므로, 이 부분에 대한 기대는 낮추는 것이 좋다.

영상의 ### 셀프 어텐션의 핵심: 쿼리(Query), 키(Key), 값(Value)과 데이터 의존적 통신 [59:59] 챕터부터 ### 인코더-디코더와 디코더-온리 트랜스포머: GPT의 정체성 [1:42:24]까지는 트랜스포머의 핵심 개념과 주요 최적화 기법을 집중적으로 설명하므로, 이 부분만 시청해도 심층적인 기술적 통찰을 얻을 수 있다.

핵심 내용

ChatGPT의 작동 원리 이해: 트랜스포머 아키텍처

ChatGPT는 텍스트 기반 작업을 수행하는 확률적 인공지능 시스템으로, 주어진 프롬프트에 대해 다양한 응답을 생성한다 [0:49]. 이 시스템의 핵심은 단어, 문자 또는 토큰의 시퀀스를 모델링하는 언어 모델이며, 이를 통해 시퀀스를 완성하는 방식으로 작동한다 [1:40]. ChatGPT의 기저에는 2017년 논문 "Attention Is All You Need"에서 제안된 트랜스포머(Transformer) 아키텍처가 있다 [2:17]. 트랜스포머는 이후 5년간 AI 분야를 장악했으며, ChatGPT 또한 이 아키텍처를 기반으로 한다 [2:51].

GPT 구축의 목표와 과정: 'Tiny Shakespeare' 데이터셋

이번 영상의 목표는 ChatGPT와 유사한 트랜스포머 기반 언어 모델을 처음부터 직접 구축하는 것이다 [3:13]. 실제 ChatGPT는 방대한 인터넷 데이터를 기반으로 복잡한 사전 훈련과 미세 조정을 거치지만, 여기서는 교육적 목적을 위해 'Tiny Shakespeare'라는 약 1MB 크기의 셰익스피어 작품 데이터셋을 활용한다 [3:47]. 이 모델은 다음 문자를 예측하여 셰익스피어와 유사한 문맥의 텍스트를 생성하며, nanogpt라는 이름의 GitHub 저장소에 코드가 공개되어 있다 [5:21]. 이 과정을 통해 GPT의 내부 작동 방식을 이해하고 구현하는 데 중점을 둔다.

토큰화: 텍스트를 숫자로 변환하는 첫 단계

언어 모델은 텍스트를 직접 처리하지 못하므로, 이를 숫자 시퀀스로 변환하는 토큰화(tokenization) 과정이 필수적이다 [9:35]. 이번 구현에서는 단순함을 위해 문자 단위(character-level) 토큰화를 사용하며, 셰익스피어 데이터셋에서 총 65개의 고유 문자를 어휘(vocabulary)로 식별한다 [9:11]. 이 과정에서 각 문자는 고유한 정수에 매핑되며, 인코더(텍스트→숫자)와 디코더(숫자→텍스트) 함수를 통해 상호 변환이 가능하다 [9:57]. 실제 대규모 언어 모델(LLM)에서는 서브워드(subword) 토큰화 기법(예: SentencePiece, Byte-Pair Encoding)을 사용하여 어휘 크기와 시퀀스 길이 간의 균형을 맞춘다 [11:10].

데이터 준비: 학습 효율을 위한 배치와 블록 크기

트랜스포머를 훈련할 때는 전체 텍스트를 한 번에 입력하지 않고, 데이터셋에서 무작위로 샘플링한 작은 텍스트 청크를 사용한다 [14:44]. 각 청크의 최대 길이를 블록 크기(block_size)(또는 문맥 길이)라고 하며, 이 청크 하나에 여러 개의 예측 예시가 포함된다 [15:04]. 예를 들어, 9개 문자 청크에는 다음 문자를 예측하는 8개의 개별 예시가 숨어 있다 [15:56]. 이는 모델이 다양한 길이의 문맥에서 예측하는 데 익숙해지도록 돕는다 [17:23]. 또한, GPU의 병렬 처리 효율을 극대화하기 위해 여러 청크를 묶어 배치(batch) 단위로 동시에 처리한다 [18:13]. 이러한 배치 내의 각 청크는 완전히 독립적으로 처리되며 서로 통신하지 않는다 [18:37].

가장 단순한 모델: 바이그램 언어 모델의 한계

트랜스포머 구축을 시작하기 전에 가장 단순한 형태인 바이그램 언어 모델을 구현한다 [22:20]. 이 모델은 torch.nn.Embedding 테이블을 사용하여 입력 정수 토큰을 벡터로 변환한다 [23:09]. 이때 각 토큰의 임베딩 벡터는 다음 문자에 대한 예측 점수(logits)를 직접 나타낸다. 바이그램 모델은 오직 현재 토큰의 정체성만을 기반으로 다음 토큰을 예측하며, 이전 문맥 정보를 전혀 활용하지 않는다 [24:14].

모델의 예측 품질은 교차 엔트로피(cross_entropy) 손실 함수로 평가하며, AdamW 옵티마이저를 사용하여 손실을 줄이도록 모델 파라미터를 업데이트한다 [25:05][35:00]. 10,000회 반복 훈련 결과, 손실은 약 4.87에서 2.5로 감소하지만, 생성되는 텍스트는 여전히 의미 없는 문자열에 가깝다 [36:12]. 이는 토큰들이 서로 정보를 교환하지 않아 문맥을 이해하지 못하기 때문이다 [37:39].

자기회귀 예측을 위한 효율적인 가중 평균 계산: 마스킹 트릭

트랜스포머는 현재 토큰이 과거 토큰들과만 소통하고 미래 토큰들로부터 정보를 얻지 못하도록 '자기회귀적(autoregressive)' 속성을 가진다 [43:17]. 이는 다음 문자를 예측하는 언어 모델링에 필수적이다. 과거 정보의 가중 평균을 효율적으로 계산하기 위해 행렬 곱셈 트릭이 사용된다 [51:09]. torch.tril 함수로 하삼각 행렬(lower triangular matrix)을 생성하여 미래 토큰에 해당하는 가중치를 0으로 만들고, 각 행의 가중치 합을 1로 정규화함으로써 이전 토큰들의 정보를 평균화할 수 있다 [51:57]. 이 방법은 개별 토큰이 서로 다른 중요도를 가질 수 있도록 데이터 의존적인 가중치를 부여하는 기반이 된다 [57:25].

셀프 어텐션의 핵심: 쿼리(Query), 키(Key), 값(Value)과 데이터 의존적 통신

셀프 어텐션(Self-Attention)은 토큰 간의 데이터 의존적인 통신을 가능하게 하는 메커니즘이다 [59:59]. 각 토큰은 자신의 정보를 나타내는 세 가지 벡터를 생성한다: 쿼리(Query, '무엇을 찾고 있는가?'), 키(Key, '내가 무엇을 가지고 있는가?'), 값(Value, '만약 관심 있다면 내가 무엇을 전달할 것인가?') [1:04:00]. 특정 토큰의 쿼리 벡터와 모든 과거 토큰들의 키 벡터 간의 내적(dot product)을 계산하여 '친밀도(affinity)' 또는 '주의 점수(attention score)'를 산출한다 [1:04:21]. 이 점수들은 특정 토큰이 과거의 어떤 토큰에 더 집중해야 하는지를 데이터에 따라 결정하며, 이를 통해 중요한 정보만 선택적으로 취합할 수 있다 [1:07:51]. 마지막으로, 정규화된 주의 점수와 각 토큰의 값 벡터를 가중 합산하여 새로운 표현 벡터를 생성한다 [1:10:08].

어텐션의 정규화: 스케일링과 소프트맥스

셀프 어텐션에서 쿼리-키 내적을 통해 얻은 친밀도 점수는 소프트맥스(softmax) 함수를 거쳐 정규화된 가중치로 변환된다 [1:09:07]. 이때 점수들을 헤드 크기의 제곱근으로 나누는 스케일링(scaling) 과정이 중요하다 [1:17:12]. 이는 초기화 단계에서 친밀도 점수들의 분산을 제어하여 소프트맥스 출력이 너무 '뾰족(peaky)'해지는 것을 방지한다 [1:18:51]. 너무 뾰족한 소프트맥스는 모델이 단 하나의 과거 토큰에만 집중하게 만들어 학습을 방해할 수 있기 때문이다. 스케일링을 통해 소프트맥스 출력은 더 넓고 확산된 분포를 가지게 되어, 여러 과거 토큰에서 균형 있게 정보를 취합할 수 있도록 돕는다 [1:18:00].

어텐션 메커니즘에 대한 추가 통찰

어텐션은 기본적으로 유향 그래프(directed graph) 내 노드 간의 통신 메커니즘으로 이해할 수 있다 [1:11:41]. 각 노드는 다른 노드로부터 데이터 의존적인 가중치 합을 통해 정보를 집계한다.

  1. 공간 개념의 부재: 어텐션은 벡터들의 집합 위에서 작동하므로, 기본적으로 토큰의 공간적 위치를 알지 못한다. 따라서 위치 임베딩(positional embedding)을 추가하여 각 토큰에 위치 정보를 명시적으로 부여해야 한다 [1:12:48].
  2. 배치 독립성: 배치 내의 개별 예시들은 서로 독립적으로 처리되며, 배치의 행렬 곱셈은 이들을 병렬로 처리할 뿐 통신하지 않는다 [1:13:41].
  3. 인코더/디코더 블록: 언어 모델링처럼 미래 정보를 차단해야 할 때는 하삼각 마스크를 사용하는 디코더 블록을, 모든 토큰이 자유롭게 통신해야 할 때는 마스크가 없는 인코더 블록을 사용한다 [1:14:15].
  4. 셀프 어텐션과 교차 어텐션: 쿼리, 키, 값이 모두 동일한 원본(X)에서 파생되면 셀프 어텐션이라 부르며, 키와 값이 외부 소스에서 올 경우 교차 어텐션(Cross-Attention)이라고 한다 [1:15:41].

다중 헤드 어텐션: 다양한 관점에서 동시 통신

다중 헤드 어텐션(Multi-Head Attention)은 여러 개의 셀프 어텐션 메커니즘을 병렬로 실행하고 그 결과를 연결하는 방식이다 [1:22:01]. 이는 토큰들이 서로 다른 관점이나 '통신 채널'을 통해 다양한 종류의 정보를 동시에 탐색하고 집계할 수 있게 한다 [1:24:07]. 예를 들어, 한 헤드는 모음을 찾고 다른 헤드는 특정 위치의 자음을 찾는 등, 각 헤드가 데이터에서 상이한 종류의 관계를 학습할 수 있다. 병렬로 실행된 각 헤드의 출력을 최종적으로 결합하여 모델의 표현력을 풍부하게 만든다. 이를 통해 모델의 성능은 단일 헤드 어텐션보다 개선되는 경향을 보인다 [1:23:49].

피드포워드 신경망: 토큰별 독립적 사고

다중 헤드 어텐션을 통해 토큰들이 서로 정보를 교환하고 집계한 후, 각 토큰은 개별적으로 이 정보를 '사고'하고 처리할 필요가 있다 [1:25:28]. 피드포워드 신경망(Feed-Forward Network, FFN)은 이러한 역할을 수행하며, 다층 퍼셉트론(MLP)의 형태로 구성된다 [1:25:06]. 이 네트워크는 각 토큰에 대해 독립적으로 적용되며, 어텐션 메커니즘이 수행한 통신 작업 후에 추가적인 비선형 변환과 표현 학습을 담당한다 [1:26:09]. FFN은 일반적으로 ReLU 또는 Gelu와 같은 비선형 활성화 함수를 포함한다 [1:25:42].

깊은 네트워크를 위한 최적화: 잔여 연결(Residual Connection)

트랜스포머는 여러 층을 쌓아 깊은 신경망을 형성하는데, 깊은 네트워크는 최적화 문제를 겪기 쉽다. 이를 해결하는 주요 기법 중 하나는 잔여 연결(Residual Connection)(또는 스킵 연결, Skip Connection)이다 [1:28:23]. 잔여 연결은 특정 변환(예: 어텐션 또는 피드포워드)의 입력값을 그 변환의 출력값에 더해 다음 층으로 전달하는 방식이다 [1:29:51]. 이는 역전파 시 그래디언트가 네트워크의 깊은 층까지 손실 없이 원활하게 흐르도록 하는 '그래디언트 고속도로(gradient super highway)' 역할을 한다 [1:29:50]. 이를 통해 네트워크는 초기 단계에서 거의 아무것도 학습하지 않더라도 최적화가 가능하며, 학습이 진행됨에 따라 잔여 블록이 점차 기여하게 된다 [1:30:05].

깊은 네트워크를 위한 최적화: 레이어 정규화(Layer Normalization)

깊은 신경망의 최적화를 돕는 또 다른 핵심 기법은 레이어 정규화(Layer Normalization)이다 [1:35:08]. 배치 정규화(Batch Normalization)와 유사하지만, 레이어 정규화는 배치 차원이 아닌 피처(채널) 차원에 걸쳐 각 개별 예시를 정규화한다 [1:34:00]. 즉, 각 토큰의 임베딩 벡터 내 32개의 피처(채널)에 대해 평균과 분산을 계산하여 이를 표준 정규 분포에 가깝게 만든다 [1:36:30]. 이는 모델 학습을 안정화하고 속도를 높이는 데 기여한다. 트랜스포머에서는 일반적으로 변환(어텐션, 피드포워드) 전에 레이어 정규화를 적용하는 프리-놈(pre-norm) 방식을 사용한다 [1:35:36].

레귤러리제이션: 드롭아웃으로 과적합 방지

모델의 복잡도가 증가하고 파라미터 수가 많아질수록 훈련 데이터에 과적합(overfitting)될 위험이 커진다. 이를 방지하기 위한 정규화(regularization) 기법 중 하나가 드롭아웃(Dropout)이다 [1:38:10]. 드롭아웃은 각 훈련 단계마다 무작위로 신경망의 특정 뉴런(또는 중간 계산 결과)을 0으로 비활성화하여 훈련에서 제외한다 [1:39:02]. 이는 마치 매번 다른 하위 네트워크(sub-network) 앙상블을 훈련하는 것과 같은 효과를 내며, 모델이 특정 피처나 경로에 과도하게 의존하는 것을 막는다 [1:39:09]. 추론 시에는 모든 뉴런이 활성화되어 앙상블 효과를 종합적으로 활용한다. 드롭아웃은 잔여 연결 직전, 다중 헤드 어텐션 출력 후, 또는 소프트맥스 이후 등 다양한 위치에 적용될 수 있다 [1:38:13].

완성된 GPT 모델 스케일업과 'Tiny Shakespeare' 결과

위에서 설명한 모든 트랜스포머 블록, 잔여 연결, 레이어 정규화, 드롭아웃 등을 통합하여 완전한 디코더 전용 트랜스포머 모델을 구축한 후, 하이퍼파라미터를 대폭 확대하여 모델을 스케일업한다 [1:37:49]. 예를 들어, 배치 크기를 64, 블록 크기를 256, 임베딩 차원을 384, 헤드 수를 6개(각 헤드 크기 64), 레이어 수를 6개로 설정한다 [1:39:34]. 이처럼 스케일업된 모델을 15분간 A100 GPU에서 훈련한 결과, 검증 손실(validation loss)은 이전 2.07에서 1.48로 크게 개선된다 [1:40:31]. 생성된 텍스트는 여전히 의미론적으로는 비논리적이지만, 셰익스피어 특유의 문체와 대화 구조를 훨씬 더 잘 모방하게 된다 [1:41:24].

인코더-디코더와 디코더-온리 트랜스포머: GPT의 정체성

최종적으로 구현된 트랜스포머는 디코더 전용(decoder-only) 아키텍처이며, 이는 ChatGPT의 기반이 되는 GPT 모델과 동일하다 [1:42:45]. 디코더 전용 모델은 자기회귀적 속성을 가지도록 하삼각 마스크를 사용하여 미래 정보를 차단하며, 특정 조건 없이 텍스트를 생성하는 언어 모델링에 적합하다 [1:43:16].

반면, 원본 "Attention Is All You Need" 논문에서 제시된 트랜스포머는 기계 번역을 위한 인코더-디코더 아키텍처였다 [1:43:37]. 이 모델은 프랑스어 문장과 같은 입력(소스 언어)을 인코더에서 처리하고, 그 인코딩된 정보를 기반으로 영어 문장과 같은 출력(타겟 언어)을 디코더에서 생성한다 [1:44:39]. 인코더는 마스크 없이 모든 토큰이 서로 통신할 수 있도록 하며, 디코더는 추가적인 교차 어텐션(cross-attention) 블록을 통해 인코더의 출력으로부터 정보를 받아 조건부 텍스트 생성을 수행한다 [1:45:14]. 우리가 구축한 모델에는 인코더나 교차 어텐션 블록이 없으므로, 이는 오직 텍스트 모방에 중점을 둔 디코더 전용 GPT 모델임을 의미한다 [1:46:16].

ChatGPT의 실제 학습 과정: 사전 훈련과 미세 조정

실제 ChatGPT와 같은 대규모 언어 모델은 두 가지 주요 단계로 학습된다 [1:49:00].

  1. 사전 훈련(Pre-training): 방대한 인터넷 데이터셋을 사용하여 대규모 디코더 전용 트랜스포머 모델을 훈련한다 [1:50:06]. 이 단계의 목표는 텍스트를 자연스럽게 이어가는 '문서 완성기(document completer)'를 만드는 것이다 [1:51:33]. 이 영상에서 구현한 모델은 이 사전 훈련 단계의 '아주 작은 버전'에 해당한다 [1:49:12]. GPT-3의 가장 큰 모델은 1,750억 개의 파라미터를 가지며, 수천억 개의 토큰으로 훈련된다 [1:50:14].
  2. 미세 조정(Fine-tuning): 사전 훈련된 모델을 사용자의 질문에 응답하는 'AI 비서'로 정렬(align)하는 단계이다 [1:52:20]. 이는 일반적으로 세 단계로 진행된다 [1:53:39].
    • 지도 미세 조정(Supervised Fine-tuning): 질문-답변 형식의 데이터셋으로 모델을 훈련하여 비서처럼 응답하도록 유도한다 [1:53:58].
    • 보상 모델(Reward Model) 학습: 인간 평가자들이 모델의 여러 응답을 선호도에 따라 순위를 매기고, 이 데이터를 사용하여 응답의 바람직함을 예측하는 별도의 보상 모델을 훈련한다 [1:53:19].
    • 강화 학습(Reinforcement Learning): 보상 모델을 사용하여 정책 최적화(PPO, Proximal Policy Optimization)와 같은 강화 학습 기법으로 모델의 샘플링 정책을 미세 조정하여 높은 보상을 받는 응답을 생성하도록 학습한다 [1:53:43]. 이 미세 조정 단계의 데이터는 OpenAI 내부에 있으며 복제가 훨씬 어렵다 [1:54:19].

주요 통찰·논점

트랜스포머의 핵심: 데이터 의존적 통신과 병렬 처리

트랜스포머 아키텍처의 혁신은 고정된 패턴에 의존하는 대신, 입력 데이터 자체를 기반으로 토큰 간의 관련성을 동적으로 학습하는 데이터 의존적 통신(data-dependent communication)에 있다 [1:03:32]. 각 토큰이 쿼리와 키를 사용하여 다른 토큰들과의 친밀도를 계산하고, 이를 바탕으로 가치 있는 정보를 취합하는 셀프 어텐션 메커니즘은 이 통신의 핵심이다. 또한, 다중 헤드 어텐션, 병렬 처리되는 배치 및 효율적인 행렬 연산을 통해 이러한 복잡한 통신을 고도로 병렬화하여 대규모 데이터셋에서도 효율적인 학습이 가능하게 한다 [52:50]. 이러한 설계는 언어 모델이 단순히 문법을 넘어 문맥과 의미론적 관계를 심층적으로 이해할 수 있는 기반을 제공한다.

복잡한 AI 시스템의 구성 요소 이해

ChatGPT와 같은 복잡한 AI 시스템은 단일한 혁신이 아니라 여러 가지 정교한 구성 요소와 최적화 기법이 겹겹이 쌓여 완성된다 [1:28:00]. 이 영상은 토큰화, 임베딩, 어텐션, 피드포워드 신경망, 잔여 연결, 레이어 정규화, 드롭아웃 등 트랜스포머의 핵심 요소를 하나씩 구현하며, 각 요소가 전체 시스템에서 어떤 역할을 하고 왜 필요한지를 명확히 보여준다. 특히 잔여 연결과 레이어 정규화는 깊은 신경망의 학습 안정성을 확보하는 데 필수적인데, 이들은 그래디언트 흐름을 개선하고 활성화 분포를 제어하여 최적화 문제를 완화한다 [1:29:08][1:35:08]. 이러한 모듈식 접근 방식은 거대 AI 모델이 어떻게 설계되고 개선되는지 직관적으로 이해할 수 있게 돕는다.

GPT 아키텍처와 LLM 스케일링의 중요성

GPT와 같은 디코더 전용 트랜스포머 아키텍처는 조건 없는 텍스트 생성이라는 언어 모델링의 본질적 문제에 최적화되어 있다 [1:42:45]. 이 아키텍처는 과거 문맥에만 의존하여 다음 토큰을 예측하는 자기회귀적 특성을 유지하며, 대규모 데이터를 통해 사전 훈련될 때 강력한 일반화 능력을 발휘한다 [1:49:09]. 또한, 모델의 크기(파라미터 수)와 훈련 데이터셋의 규모를 함께 확장하는 스케일링이 LLM 성능 향상에 결정적인 역할을 한다는 점이 강조된다 [1:50:14]. 영상의 'Tiny Shakespeare' 모델은 수백만 개의 파라미터와 수십만 개의 토큰으로 훈련되지만, GPT-3는 수천억 개의 파라미터와 수천억 개의 토큰으로 훈련되어 엄청난 성능 차이를 보인다 [1:50:46]. 이는 아키텍처 자체는 유사해도 규모가 곧 새로운 능력을 창출한다는 통찰을 제공한다.

사전 훈련과 미세 조정의 분리된 역할

ChatGPT의 뛰어난 성능은 대규모 데이터로 모델을 학습시키는 사전 훈련 단계와, 특정 목표에 맞게 모델의 행동을 정렬하는 미세 조정 단계가 명확히 분리되어 있기 때문이다 [1:49:03]. 사전 훈련은 모델이 인터넷상의 방대한 텍스트 패턴을 학습하여 일관성 있는 텍스트를 생성하는 '문서 완성기' 능력을 부여한다 [1:51:33]. 하지만 이 단계만으로는 사용자의 질문에 적절히 응답하는 'AI 비서'의 역할을 수행하지 못한다. 미세 조정은 지도 학습, 보상 모델 학습, 강화 학습 등의 복잡한 다단계 과정을 통해 모델을 특정 작업이나 사용자 의도에 맞게 미세하게 조정하며, 비로소 대화형 AI의 '유용성'을 완성한다 [1:52:20]. 이 두 단계의 역할과 중요성을 이해하는 것은 현대 LLM의 개발 과정을 파악하는 데 필수적이다.

인상적인 지점

비유의 힘: 복잡한 개념을 직관적으로

강사는 어려운 개념을 설명할 때 비유를 적극적으로 활용하여 직관적인 이해를 돕는다.

  • 쿼리/키/값: 쿼리를 "무엇을 찾고 있는가?" [1:04:12] 키를 "무엇을 포함하고 있는가?" [1:04:18] 값은 "만약 관심 있다면 내가 무엇을 전달할 것인가?" [1:11:16] 로 설명하여 토큰 간의 정보 교환 과정을 명확히 보여준다.
  • 잔여 연결: 역전파 시 그래디언트가 막힘없이 흐르는 그래디언트 고속도로(gradient super highway) [1:29:50] 비유는 깊은 네트워크 최적화의 핵심 원리를 쉽게 각인시킨다.
  • 배치 처리: 배치 내 독립적인 여덟 개의 노드 풀(pools of eight nodes) [1:14:00] 비유는 병렬 연산의 개념을 구체적으로 시각화하는 데 도움을 준다.
