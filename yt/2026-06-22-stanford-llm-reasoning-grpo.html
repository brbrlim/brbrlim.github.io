TL;DR

이 강의는 LLM의 추론 능력 향상 기법과 그 훈련 방식을 상세히 다룬다. 특히 단계적 사고(Chain of Thought, CoT)를 대규모로 적용하기 위한 강화 학습(RL) 방법론인 GRPO(Group Relative Policy Optimization)를 소개하며, DeepSeek R1 모델이 이 기술을 활용하여 복잡한 추론 문제를 해결하고 그 지식을 작은 모델에 증류하는 과정을 설명한다. 모델의 추론 과정을 명시적으로 유도하고 검증 가능한 보상으로 학습하는 것이 핵심이다.

풀시청 판단

이 강의는 LLM 추론 능력 개발의 최신 동향과 기술적 세부 사항에 깊이 파고든다. 특히 PPO와 GRPO 같은 강화 학습 알고리즘의 원리, 수학적 유도 과정, 그리고 실제 모델(DeepSeek R1)에 적용된 구체적인 파이프라인을 다루므로, LLM의 훈련 방법론, 특히 강화 학습 및 추론 능력 개선 연구에 관심 있는 개발자, 연구자, 또는 관련 분야의 대학원생에게 매우 유용하다.

강의는 LLM이 왜 추론 능력이 필요한지, 기존 LLM의 한계가 무엇인지부터 시작하여 추론의 정의, 평가 지표(pass@k의 수학적 유도 포함), 그리고 핵심 훈련 알고리즘(GRPO)과 그 개선 방안까지 체계적으로 설명한다. DeepSeek R1의 다단계 훈련 파이프라인과 작은 모델에 지식을 증류하는 방법까지 구체적인 사례를 들어 설명하므로, 실제 시스템 설계에 대한 통찰을 얻을 수 있다.

다만, 확률론과 강화 학습에 대한 기본적인 이해가 없으면 일부 기술적인 부분(pass@k 유도, GRPO 손실 함수)이 어렵게 느껴질 수 있다. LLM 추론 분야에 대한 높은 수준의 지식과 함께 구현 관점의 세부 사항을 원하는 사람들에게 가장 큰 가치를 제공한다.

핵심 내용

LLM 추론의 정의와 바닐라 LLM의 한계

강의는 LLM 추론을 '문제를 해결하는 능력'으로 정의한다. 특히 수학 문제나 코딩 문제처럼 여러 단계를 거쳐야 풀 수 있는 복잡한 문제 해결에 초점을 맞춘다 [14:01]. 예를 들어, 단순히 지식을 묻는 질문(스탠퍼드 LLM 수업 코드는?)과 달리, 곰의 나이를 계산하는 문제는 몇 년도에 태어났고 현재가 몇 년도인지를 파악하는 다단계 추론이 필요하다 [15:25].

기존의 '바닐라 LLM'은 텍스트와 코드의 구조를 잘 이해하지만 [9:11], 다음 토큰을 예측하는 방식으로 훈련되었기 때문에 복잡한 추론 문제 해결 능력이 제한적이다 [9:44]. 또한, 훈련 데이터의 '절단 시점(cutoff date)' 이후의 지식은 알지 못하며 [10:34], 단순히 텍스트를 생성할 뿐 실제 행동으로 이어지지 않고 [11:17], 자유 형식 텍스트라 기존 NLP 모델처럼 평가하기 어렵다는 한계도 가진다.

사고의 연쇄(Chain of Thought, CoT) — 추론 모델의 핵심 아이디어

LLM의 추론 능력을 향상하는 핵심 아이디어는 '사고의 연쇄(Chain of Thought, CoT)' 개념을 활용하는 것이다 [16:14]. 이는 LLM이 최종 답변만 내놓는 대신, 사람이 복잡한 문제를 풀 때처럼 중간 단계를 거쳐 생각하는 과정을 명시적으로 출력하도록 하는 방법이다 [16:32]. 이렇게 하면 LLM은 전체 문제를 해결하기 어려운 하나의 '블랙박스'처럼 다루는 대신, 익숙한 작은 단위 문제들로 분해하여 처리하고, 각 단계에서 훈련 데이터에서 학습한 패턴을 활용할 수 있다 [19:54].

LLM이 더 많은 토큰을 생성하도록 허용하는 것은 실질적으로 모델에 더 많은 연산 자원(compute)을 주는 것과 같아, 복잡한 문제에 대해 더 깊이 '생각'할 기회를 제공한다 [20:31]. 따라서 추론 모델의 출력은 단순히 '답변'이 아니라 '추론 과정 + 답변'의 형태를 띤다 [22:03]. ChatGPT와 같은 챗봇 UI에서 '생각 중(Thinking)'이라는 메시지가 뜨는 것은 모델이 바로 이 추론 과정을 생성하고 있음을 나타낸다 [25:02]. 또한, 이러한 추론 토큰은 사용자에게 비용으로 청구된다 [26:50].

추론 모델 평가 지표: pass@k

추론 모델의 성능을 평가하기 위해 코딩과 수학 문제에 특화된 벤치마크들이 사용된다 [28:05]. 코딩 문제의 경우 HumanEval, CodeForces, SWE-bench 등이 있으며, 모델이 생성한 코드가 테스트 케이스를 통과하는지 여부로 정답을 판별한다 [29:08]. 수학 문제의 경우 AIM(US 수학 올림피아드 예선 시험)이나 GSM 8-K 같은 벤치마크가 사용되며, 모델이 제시한 최종 답변을 파싱하여 정답 여부를 확인한다 [30:00].

이러한 추론 모델의 핵심 평가 지표는 pass@k이다 [32:09]. pass@k는 모델이 하나의 문제에 대해 k개의 답변을 생성했을 때, 그 중 적어도 하나라도 정답일 확률을 추정한다 [32:45]. 이는 여러 시도를 통해 정답을 얻을 가능성이 높아지는 상황(예: 코딩 문제에서 여러 솔루션을 시도하여 테스트 통과 여부 확인)에 유용하다. pass@k의 추정은 n개의 샘플 답변을 생성하고 그 중 c개가 성공했을 때, n개의 답변 중 임의로 k개를 선택했을 때 적어도 하나가 정답일 확률을 계산하는 방식으로 이루어진다 [37:07]. 이는 '1 - (모든 k개 답변이 오답일 확률)'로 계산할 수 있으며, 조합론적 공식을 통해 1 - (n-c choose k) / (n choose k)로 표현된다 [43:06].

모델의 답변 다양성에 영향을 미치는 '온도(temperature)'는 pass@k 값에 중요한 영향을 미친다 [45:28]. 온도가 너무 낮으면 답변이 다양하지 않아 k를 늘려도 pass@k가 증가하지 않고, 너무 높으면 다양성은 커지지만 답변의 정확도가 떨어질 수 있다. 따라서 적절한 온도를 선택하는 것이 중요하다 [46:00].

SFT 대신 RL(강화 학습)을 쓰는 이유

추론 능력을 갖춘 LLM을 훈련하기 위해서는 Supervised Fine-Tuning (SFT) 대신 강화 학습(RL)이 선호된다 [51:15]. 그 이유는 다음과 같다.

  1. 추론 사슬 작성의 어려움: 추론 과정(CoT)을 사람이 직접 작성하는 것은 특히 복잡하고 긴 문제일수록 매우 어렵고 노동 집약적이다 [49:33]. SFT는 고품질의 레이블된 데이터가 필요한데, CoT 데이터는 구축하기 매우 어렵다.
  2. 모델의 고유한 추론 방식: 모델이 추론하는 방식은 사람이 생각하는 방식과 다를 수 있다 [50:04]. 따라서 사람이 작성한 CoT 데이터로 모델을 훈련하는 것이 항상 최적의 방법은 아닐 수 있다.
  3. 내재된 검증 가능한 보상 신호: 추론 문제(코딩, 수학)는 정답 여부를 명확히 확인할 수 있는 '검증 가능한(verifiable)' 보상 신호를 제공한다 [50:36]. 코딩 문제는 테스트 케이스 통과 여부로, 수학 문제는 정답과의 일치 여부로 모델의 성능을 직접 평가할 수 있다. 이러한 명확한 보상 신호는 강화 학습에 이상적이다.

따라서 강화 학습은 모델이 스스로 추론 과정을 생성하고 그 결과에 대한 피드백(보상)을 통해 능력을 향상하도록 유도할 수 있다. 훈련 시에는 '생각(think)' 토큰의 존재 여부와 최종 답변의 정확성을 종합적으로 고려한 보상을 사용한다 [52:00]. 이러한 방식으로 RL 훈련을 진행하면 모델의 추론 성능이 크게 향상됨이 관찰된다 [53:16].

GRPO: 가치 함수 없는 RL 알고리즘

GRPO(Group Relative Policy Optimization)는 추론 모델 훈련에 특화된 강화 학습 알고리즘이다 [58:45]. PPO와 마찬가지로 보상(advantage)을 최대화하면서도 기존 정책이나 기본 모델에서 너무 많이 벗어나지 않도록 정책을 업데이트하는 것을 목표로 한다 [59:25].

GRPO의 핵심 차이점은 '이점(advantage)'을 계산하는 방식에 있다 [1:00:19]. 전통적인 PPO는 가치 함수(value function)를 별도로 훈련하여 이점을 추정하는데, 이는 복잡하고 비용이 많이 든다 [1:03:02]. 반면 GRPO는 특정 프롬프트에 대해 여러 개의 답변(g개)을 생성한 후, 각 답변의 보상(r)을 해당 그룹 내 다른 답변들의 평균 보상과 비교하여 이점을 계산한다 [1:01:51]. 즉, reward - average(rewards)와 유사한 방식으로 상대적인 이점을 구한다. 이 방식은 가치 함수를 훈련할 필요 없이, 여러 샘플을 생성하여 보상의 그룹 평균을 기준으로 삼아 정책을 업데이트할 수 있도록 한다.

GRPO 훈련 과정은 다음과 같다 [1:06:09].

  1. 정책 모델(LLM)에 쿼리를 입력하여 g개의 답변을 생성한다.
  2. 각 답변에 대해 보상 모델(또는 검증 가능한 보상 함수)을 사용하여 보상을 계산한다.
  3. 계산된 g개의 보상을 활용하여 각 답변의 이점(r - mean(rewards) / std(rewards))을 계산한다.
  4. 이 이점 값을 사용하여 정책 모델을 튜닝하며, 기준 모델(SFT 모델)로부터 너무 멀리 벗어나지 않도록 KL 발산(KL divergence) 항을 추가한다.

PPO는 하나의 답변과 그에 따른 보상 및 가치 함수를 통해 이점을 계산하는 반면 [1:08:00], GRPO는 그룹 내 다수의 답변을 비교하여 이점을 계산하므로 가치 함수가 필요 없다는 것이 핵심적인 차이다 [1:11:21].

GRPO의 문제점과 개선: 출력 길이 편향

GRPO를 통해 모델을 훈련할수록 모델의 성능은 향상되지만, 동시에 생성되는 답변의 길이가 불필요하게 길어지는 현상이 관찰된다 [1:17:00]. 이는 특히 성능이 안정화된 이후에도 계속해서 길이가 증가하여, 불필요한 연산 비용과 사용자 요금 증가로 이어진다 [1:19:02].

이러한 현상의 원인은 GRPO의 손실 함수에 있다 [1:19:34]. GRPO 손실 함수는 각 토큰의 기여도를 계산할 때 1 / 출력 길이(output length)를 곱하는 항을 포함한다. 이로 인해 짧은 출력에 있는 토큰은 더 큰 가중치를 받고, 긴 출력에 있는 토큰은 더 작은 가중치를 받게 된다 [1:22:11]. 이는 모델에게 부정적인 이점(잘못된 답변)이 있을 경우, 짧은 잘못된 답변에 있는 토큰을 더 크게 페널티하고, 긴 잘못된 답변에 있는 토큰은 상대적으로 적게 페널티하는 비대칭적인 학습을 유도한다 [1:24:22]. 결과적으로 모델은 "짧은 나쁜 답변보다 긴 나쁜 답변을 선호하는" 경향을 학습하게 되어, 불필요하게 긴 답변을 생성하게 된다 [1:24:43].

이 문제를 해결하기 위해 DAPO, Dr. GRPO와 같은 후속 연구에서는 이 1 / 출력 길이 정규화 계수를 제거하거나 [1:25:03], 모든 토큰의 기여도를 동일하게 조정하는 방법을 제안했다 [1:25:21]. 이러한 개선을 통해 모델의 성능은 유지하면서도 출력 길이가 비정상적으로 길어지는 현상을 억제할 수 있었다 [1:26:26].

DeepSeek R1: 단계별 추론 능력 향상 파이프라인

DeepSeek R1은 추론 능력을 극대화하기 위한 다단계 훈련 파이프라인을 제시한다 [1:35:51].

  1. R1-Zero (개념 증명 단계): DeepSeek은 먼저 사전 훈련된 기본 모델에 SFT 없이 곧바로 GRPO를 적용하여 추론 능력을 훈련한다 [1:32:29]. 이때 보상은 '생각(think)' 토큰 존재 여부와 최종 답변의 정확성으로 구성된다 [1:33:00]. 이 단계만으로도 추론 벤치마크 점수가 크게 향상됨을 보여주지만 [1:34:15], 생성된 추론 사슬에 언어 혼합이나 문법 오류가 발생하는 문제가 발생했다 [1:35:06].

  2. R1 파이프라인: 이러한 문제를 해결하고 모델을 정교화하기 위해 DeepSeek R1은 다음 단계를 거친다.

    • 콜드 스타트 SFT (Cold Start SFT): R1-Zero에서 생성된 추론 사슬 중 문제가 있는 부분을 사람이 직접 수정하여 언어 일관성과 형식 준수(think/answer block)를 맞춘다 [1:36:50]. 이 수정된 소규모 데이터를 이용해 SFT를 진행하여 모델이 올바른 형식으로 생각하도록 초기 정렬(alignment)을 한다 [1:37:16].
    • 추론 중심 RL (Reasoning-focused RL): 콜드 스타트 SFT 모델에 GRPO를 적용한다. 이때 보상은 답변의 정확성, 형식 준수 보상 외에 '언어 일관성 보상'을 추가하여 모델이 올바른 언어를 사용하도록 유도한다 [1:38:32].
    • 혼합 SFT (Mixed SFT): 이 단계에서는 추론 데이터와 비추론 데이터를 혼합하여 SFT를 진행한다 [1:39:15]. 비추론 데이터는 기존 모델에서 사용되던 20만 쌍의 다양한 도메인 데이터를 재활용하고 [1:39:47], 추론 데이터는 '거부 샘플링(rejection sampling)' 기법으로 생성한다 [1:40:04]. 이는 모델이 답변을 생성하게 한 후 LLM 판별(judge)을 통해 고품질의 답변만 선별하여 데이터셋으로 구축하는 방식이다.
    • 선호도 튜닝 RL (Preference Tuning RL): 마지막 단계에서는 추론 데이터와 비추론 데이터를 다시 혼합하여 RL 훈련을 진행한다 [1:41:17]. 추론 데이터에는 이전과 동일한 보상을 사용하고, 비추론 데이터에는 모델이 유용하고 해롭지 않은 답변을 생성하도록 '유용성(helpfulness)'과 '무해성(harmlessness)' 보상을 적용한다. 이때 무해성은 전체 출력(추론 과정 포함)에, 유용성은 최종 답변에 중점을 둔다.

이러한 DeepSeek R1 파이프라인을 통해 폐쇄형 추론 모델(closed-source model)에 필적하는 높은 성능을 달성했다 [1:42:29].

작은 모델을 위한 추론 능력 증대: 지식 증류

대규모 추론 모델의 강력한 능력을 작은 모델에서도 구현하기 위해 '지식 증류(distillation)' 기법이 사용된다 [1:43:30]. 전통적인 증류는 교사(teacher) 모델의 다음 토큰 예측 확률 분포를 학생(student) 모델이 모방하도록 훈련하는 방식이었다 [1:44:47].

하지만 추론 모델의 경우, DeepSeek R1과 같은 교사 모델이 특정 프롬프트에 대해 '생각 토큰'을 포함한 전체 답변 시퀀스를 생성하도록 한다 [1:45:18]. 그리고 학생 모델은 이 교사 모델이 생성한 전체 시퀀스를 예측하도록 SFT 훈련을 받는다 [1:45:33]. 즉, 다음 토큰의 확률 분포를 모방하는 대신, 교사가 만든 '사고의 연쇄 + 답변' 시퀀스 전체를 직접 모방하도록 훈련하는 것이다. 이 방식은 작은 모델이 직접 강화 학습을 통해 추론 능력을 학습하는 것보다 훨씬 효율적으로 성능을 얻을 수 있음을 보여준다 [1:46:32].

주요 통찰·논점

확인 가능한 보상 신호가 있다면 SFT 없이도 RL로 추론 능력 향상 가능

강의는 DeepSeek R1-Zero 사례를 통해 [1:30:03], 복잡한 추론 문제처럼 정답을 명확히 검증할 수 있는 보상 신호가 존재한다면, 사람이 직접 작성한 고품질 추론 데이터(CoT) 없이도 강화 학습만으로 LLM의 추론 능력을 크게 향상할 수 있음을 보여준다. 이는 CoT 데이터 구축의 높은 비용을 회피하면서도 강력한 성능을 달성할 수 있는 가능성을 제시한다.

GRPO는 가치 함수 없이 그룹 비교 기반 이점을 계산하여 RL을 간소화한다

전통적인 강화 학습 알고리즘인 PPO는 이점(advantage)을 계산하기 위해 별도의 가치 함수(value function)를 훈련해야 한다 [1:03:02]. GRPO는 이 복잡한 가치 함수 훈련 과정을 생략하고, 특정 프롬프트에 대한 여러 답변의 보상을 서로 비교하여 상대적인 이점을 계산한다 [1:01:51]. 이는 LLM 환경에서 강화 학습을 더 효율적이고 간결하게 적용할 수 있는 방법을 제공하여 추론 모델 훈련의 중요한 발판이 되었다.

모델의 '생각'을 유도하는 과정에서 발생하는 비효율성 (긴 출력)은 RL 손실 함수 조정으로 해결한다

LLM이 추론 과정에서 더 많은 토큰을 생성하도록 유도하면 성능은 향상되지만 [1:18:35], 모델이 불필요하게 긴 답변을 생성하는 부작용이 나타난다 [1:19:02]. 이는 GRPO의 손실 함수에 포함된 1 / 출력 길이 항이 짧은 잘못된 답변에 더 큰 페널티를 주어, 모델이 긴 잘못된 답변을 덜 나쁘게 인식하는 편향을 유발하기 때문이다 [1:24:43]. 이러한 비효율성은 손실 함수에서 해당 항을 제거하거나 조정하는 DAPO, Dr. GRPO와 같은 개선책으로 해결될 수 있으며 [1:25:03], 이는 RL 알고리즘 설계 시 미묘한 인센티브 구조가 모델의 행동에 미치는 영향을 강조한다.

대규모 추론 모델의 지식을 작은 모델에 효율적으로 전달하는 지식 증류 기법

대규모 모델을 직접 훈련하기 어려운 경우, DeepSeek R1과 같은 강력한 추론 모델을 '교사(teacher)'로 활용하여 작은 모델에 지식을 '증류(distillation)'할 수 있다 [1:43:30]. 여기서 증류는 교사 모델이 생성한 '추론 과정 + 답변'의 전체 시퀀스를 학생 모델이 직접 모방하도록 훈련하는 방식을 취한다 [1:45:33]. 이 방법은 작은 모델이 처음부터 강화 학습을 통해 추론 능력을 학습하는 것보다 훨씬 효율적이며, 자원 제약이 있는 환경에서 강력한 추론 능력을 보급하는 핵심 전략이 된다.

인상적인 지점

강의에서 GRPO 손실 함수의 1 / 출력 길이 항이 의도치 않게 모델이 "짧은 나쁜 답변보다 긴 나쁜 답변을 선호하게" 만드는 부분을 설명할 때 [1:24:43] 매우 인상 깊었다. 수학적 유도(derivation)를 통해 손실 함수 내의 미세한 계수가 어떻게 모델의 비효율적인 행동(불필요하게 긴 출력)으로 이어지는지 명확하게 보여주며, 이는 ML 모델 훈련 시 손실 함수의 설계가 얼마나 중요하고 예측 불가능한 부작용을 낳을 수 있는지를 잘 드러낸다.
