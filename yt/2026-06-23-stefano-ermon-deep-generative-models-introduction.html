TL;DR

스탠퍼드 대학교 CS236 '딥 생성 모델' 강의의 첫 번째 영상으로, 생성 모델이 이미지, 음성, 텍스트, 코드, 비디오, 로봇 공학, 과학 등 다양한 인공지능 하위 분야의 근본적인 과제를 어떻게 해결하는지 설명한다. 화자는 리처드 파인만의 "내가 만들 수 없는 것은 이해할 수 없다"는 명제를 빌려, 생성 모델이 데이터를 생성하는 능력이 곧 그 데이터를 이해하는 척도이며, 이 이해를 바탕으로 다양한 현실 세계 문제를 해결할 수 있다고 강조한다. 이 강좌는 엄격한 통계 및 수학적 접근을 통해 딥 생성 모델의 핵심 개념과 구성 요소를 심층적으로 다룬다.

풀시청 판단

이 영상은 딥 생성 모델 분야에 대한 흥미를 유발하고, 이 분야가 해결하고자 하는 문제, 현재 달성한 발전 수준, 그리고 앞으로 다룰 핵심 개념들을 포괄적으로 소개한다.

  • 누구에게 가치 있는가:

    • 생성형 AI 전반에 대한 깊은 이해를 원하는 사람: 생성 모델의 철학적 배경과 광범위한 응용 사례를 접할 수 있다.
    • CS236 강의 수강을 고려하는 학생: 강의의 목표, 내용, 선수 지식, 평가 방식 등 전반적인 운영 계획을 파악할 수 있다.
    • 생성 모델의 이론적 기초에 관심 있는 연구자/개발자: 통계 모델링, 확률 분포, 다양한 모델 구조(GAN, 확산 모델, 자기회귀 모델 등)에 대한 학습 로드맵을 얻을 수 있다.

  • 무엇을 얻는가:

    • 생성 모델의 핵심 가치와 철학: 왜 생성 모델이 인공지능의 근본적인 과제를 해결하는 중요한 접근법인지 이해한다.
    • 생성 모델의 놀라운 발전과 광범위한 응용 사례: 이미지, 음성, 텍스트, 코드, 비디오, 로봇 공학, 신약 개발 등 다양한 분야에서 생성 모델이 어떻게 활용되는지 시각적으로 확인한다.
    • 강의의 엄격한 이론적 접근 방식에 대한 인상: 확률 이론, 미적분학, 선형 대수 등 수학적 배경의 중요성을 인지한다.

  • 약점 및 한계:

    • 실질적인 기술적 내용은 거의 없음: 첫 강의인 만큼 기술적인 세부 내용은 다루지 않는다. 모델의 작동 방식에 대한 깊은 설명을 기대하면 실망할 수 있다.
    • 일부 최신 트렌드 반영 부족 가능성: 2023년 강의이지만, AI 분야의 급격한 발전 속도를 고려할 때 일부 언급된 사례나 모델이 빠르게 구식이 될 수 있다. (예: DALL-E 3가 "최신"으로 언급되지만 더 새로운 모델들이 계속 나오고 있다.)
    • 윤리적 논의의 깊이 부족: 딥페이크 등 윤리적 문제에 대한 우려를 표하지만, 해당 주제는 이 강의의 주요 내용이 아니므로 깊은 논의는 기대하기 어렵다.

핵심 내용

생성 모델의 핵심 철학: "내가 만들 수 없는 것은 이해할 수 없다"

인공지능의 다양한 하위 분야인 컴퓨터 비전, 자연어 처리, 음성 처리, 로봇 공학 등에서 마주하는 근본적인 과제는 이미지나 음성 신호, 언어 토큰 시퀀스와 같은 복잡한 고차원 신호나 객체를 이해하는 일이다 [1:52]. 이러한 객체들을 이해하는 것은 매우 어려운데, 예를 들어 컴퓨터 관점에서 이미지는 단순한 숫자 행렬에 불과하기 때문이다 [2:12].

화자는 리처드 파인만의 "내가 만들 수 없는 것은 이해할 수 없다"는 명언에서 영감을 받은 철학을 생성 모델에 적용한다 [3:13]. 즉, 특정 이미지나 텍스트의 의미를 이해한다고 주장한다면, 새로운 이미지나 텍스트를 창조할 수 있어야 한다는 것이다 [3:52]. 사과가 무엇인지 안다면 머릿속에 사과를 그릴 수 있어야 하고, 이탈리아어를 할 줄 안다면 이탈리아어로 말하고 쓸 수 있어야 하는 것과 같은 이치다. ChatGPT 같은 대규모 언어 모델이 일관성 있고 의미 있는 텍스트를 생성하는 능력은, 언어의 문법적 규칙뿐만 아니라 상식과 세상에 대한 특정 수준의 이해를 가지고 있음을 시사한다 [4:40]. 이러한 이해는 다양한 인공지능 과제를 해결하는 데 활용될 수 있다.

생성 모델은 데이터 시뮬레이터: 확률 분포를 학습하고 새로운 데이터를 생성한다

생성 모델은 데이터를 시뮬레이션하는 방식으로 작동한다 [10:57]. 기존 기계 학습 문제에서 데이터가 주로 입력으로 사용되는 것과 달리, 생성 모델에서는 데이터가 출력의 대상이 된다. 즉, 모델은 학습 데이터를 바탕으로 새로운 데이터를 생성하는 방법을 배운다.

이러한 딥 생성 모델은 기본적으로 이미지 x나 텍스트 시퀀스 x와 같은 입력에 대한 확률 분포 P(x)를 학습한다 [9:03]. 이 확률 분포는 특정 입력 x가 생성 모델에 의해 얼마나 그럴듯한지를 나타내는 스칼라 확률 값을 부여한다. 모델이 이 확률 분포를 학습하면, 그 분포에서 표본을 추출(sampling)하여 학습 데이터와 유사한 새로운 객체를 생성할 수 있게 된다 [10:34]. 이 과정에서 사전 지식(예: 신경망 구조, 손실 함수, 최적화기)과 대규모 데이터가 결합되어 좋은 통계적 생성 모델을 구축하는 데 활용된다 [9:27].

생성 모델은 캡션, 스케치, 흑백 이미지, 다른 언어의 텍스트, 의료 기기 측정값 등 다양한 제어 신호를 통해 데이터 생성 과정을 조절할 수 있다 [11:34]. 이를 통해 텍스트로 이미지 생성, 이미지 초해상화, 인페인팅(inpainting), 의료 영상 재구성, 기계 번역 등 여러 응용 분야에서 활용된다 [12:07]. 또한, 모델은 특정 데이터 포인트가 이 시뮬레이터에 의해 생성될 가능성이 높은지 낮은지를 평가하여 이상치 탐지(outlier detection)와 같은 응용에도 사용될 수 있다 [12:40].

다양한 양상의 생성 모델 발전과 응용

생성 모델은 여러 양상(modality)에서 놀라운 발전을 이루고 있으며, 이를 통해 다양한 현실 세계의 문제를 해결한다.

이미지 (Image)

약 10년 전에는 단순히 사람의 형체를 대략적으로 재현하는 흑백 이미지 생성도 인상적인 성과였으나 [15:59], 생성적 적대 신경망(GAN)의 발전으로 점차 고해상도에 사실적인 이미지 생성이 가능해졌다 [16:28]. 특히 스탠퍼드에서 개발된 스코어 기반 확산 모델(score-based diffusion models)은 이미지 생성 기술을 더욱 발전시켜, 실제로 존재하지 않는 사람들의 매우 사실적인 고해상도 이미지를 만들어낼 수 있게 되었다 [16:47]. Stable Diffusion, DALL-E, Midjourney와 같은 텍스트-이미지 시스템은 확산 모델을 기반으로 하며, "우주비행사가 말을 타는 모습"처럼 모델이 이전에 보지 못한 개념의 조합도 훌륭하게 시각화해낸다 [17:32]. 이러한 모델은 텍스트 프롬프트 외에 스케치를 이용한 이미지 생성, 흑백 사진 색상화, 저해상도 이미지 초해상화, 이미지 인페인팅 등 다양한 역문제(inverse problems) 해결에도 효과적으로 활용된다 [22:01].

음성 (Speech)

음성 분야에서도 생성 모델은 텍스트-음성 변환(text-to-speech)에서 큰 진전을 보였다 [25:55]. 초기 WaveNet 모델(2016년)은 기존 방식보다 훨씬 자연스러운 음성을 생성했으며 [26:04], 최근 확산 모델 기반 시스템은 억양과 감정까지 담아내어 거의 사람과 구별하기 어려운 수준에 도달했다 [26:46]. 또한, 오디오 초해상화(audio super resolution) 기능을 통해 저품질 음성 신호를 고품질로 복원하는 것도 가능해졌다 [27:40].

언어 (Language)

대규모 언어 모델(LLM)은 인터넷상의 방대한 텍스트 데이터를 학습하여, 어떤 문장이 의미 있는지 이해하는 확률 분포를 학습한다 [28:23]. 이를 통해 주어진 프롬프트에 맞춰 문장을 완성하거나 [28:51], ChatGPT처럼 복잡한 질문에 대해 유용한 정보를 제공할 수 있다 [29:43]. 또한, 다른 언어의 텍스트를 제어 신호로 사용하여 기계 번역과 같은 응용에도 직접적으로 기여한다 [31:14].

코드 (Code)

코드는 본질적으로 텍스트의 한 형태이므로, 언어 생성 모델의 발전은 코드 생성에도 영향을 미친다 [32:06]. 현재 시스템들은 주석이나 설명에 기반하여 함수의 본문을 자동 완성하거나 [32:31], 프로그래밍 과제를 해결하고 경쟁 프로그래밍 대회에서 좋은 성적을 내는 수준에 이르렀다 [32:54]. 이는 자연어를 정형 언어로 번역하는 능력을 보여준다.

비디오 (Video)

비디오 생성은 현재 활발히 연구되고 있는 분야 중 하나이다 [33:36]. 텍스트 캡션을 통해 비디오를 생성할 수 있으며, 아직 비디오의 길이가 짧다는 한계가 있지만, 프레임 간의 높은 일관성과 사실적인 품질을 보여준다 [34:07]. 여러 짧은 비디오를 연결하여 더 긴 스토리텔링 콘텐츠를 만드는 것도 가능하다 [35:49]. 이는 미디어 산업에 큰 변화를 가져올 잠재력을 가지고 있다.

로봇 공학 및 의사 결정 (Robotics & Decision-making)

로봇 공학 분야에서 생성 모델은 일련의 행동(action)을 생성하는 데 활용될 수 있다 [38:15]. 모방 학습(imitation learning)을 통해 인간의 좋은 행동 예시를 학습하여, 자동차 운전이나 물체 쌓기 같은 작업을 수행하는 새로운 행동 궤적(trajectories)을 생성하도록 모델을 훈련할 수 있다 [38:47].

과학 및 공학 (Science & Engineering)

과학 및 공학 분야에서도 생성 모델은 분자 및 단백질을 합성하는 데 사용된다 [40:03]. 특정 속성을 가진 분자나 단백질을 설계하거나, 신약 개발, 더 나은 촉매 설계 등에 활용된다. 이는 이미지가 아닌 다른 양상(예: 아미노산 서열)에 대한 생성 모델을 구축하는 것이다 [41:16].

딥 생성 모델 강좌의 목표와 주요 내용

이 강좌는 딥 생성 모델 분야의 핵심 개념, 과제, 장단점을 엄격하게 다루어, 학생들이 기존 시스템을 이해할 뿐만 아니라 차세대 시스템을 설계하고 개선하며 새로운 응용 분야를 찾아낼 수 있도록 돕는다 [43:10].

주요 내용은 세 가지 핵심 아이디어로 구성된다.

  1. 표현 (Representation) [44:55]: 확률 분포를 어떻게 신경망으로 모델링하여 복잡한 고차원 객체(예: 이미지의 픽셀 간 상호작용, 문장의 단어 연결)를 표현할 것인가.
  2. 학습 (Learning) [44:59]: 데이터 분포와 모델 분포 간의 유사성을 측정하는 다양한 손실 함수와 학습 방법(확산 모델, GAN, 자기회귀 모델 등)을 다룬다. 고차원 확률 분포 간의 유사성을 측정하는 어려움이 핵심이다.
  3. 추론 (Inference) [46:19]: 모델에서 효율적으로 표본을 추출하는 방법, 생성 과정을 역으로 바꾸어 표현(representation)을 얻는 방법, 비지도 학습(unsupervised learning) 및 클러스터링(clustering)에 활용하는 방법을 탐구한다.

강좌에서 다룰 주요 모델 유형은 다음과 같다 [47:56].

  • 자기회귀 모델 (Autoregressive Models): 대규모 언어 모델 등에 사용되며, 각 데이터 포인트를 순차적으로 생성한다.
  • 흐름 기반 모델 (Flow-based Models): 연속적인 데이터(예: 이미지)에 사용되며, 변수 변환을 통해 복잡한 분포를 단순한 분포로 매핑한다.
  • 잠재 변수 모델 (Latent Variable Models): 변분 오토인코더(VAE)와 같이 잠재 변수를 사용하여 모델의 표현력을 높인다.
  • 암묵적 생성 모델 (Implicit Generative Models): 생성적 적대 신경망(GAN)처럼 명시적인 확률 분포 대신 표본 추출 과정을 직접 모델링한다.
  • 에너지 기반 모델 (Energy-based Models) 및 확산 모델 (Diffusion Models): 최신 이미지 및 오디오 생성 기술의 핵심이며, 텍스트와 비디오 생성에도 활용된다.

이 강좌는 상당한 수학적 이론과 알고리즘을 포함하며, 프로그래밍 과제(PyTorch 사용)와 최종 프로젝트를 통해 실습 기회를 제공한다.

주요 통찰·논점

생성 모델은 단순한 데이터 생성을 넘어 "이해"의 척도이다

이 강의의 핵심 통찰은 생성 모델이 단순히 데이터를 그럴듯하게 모방하는 것을 넘어, 데이터의 근본적인 "의미"를 이해하는 수준에 도달했음을 보여준다는 점이다 [4:02]. 화자는 리처드 파인만의 "내가 만들 수 없는 것은 이해할 수 없다"는 명제를 인용하여, 모델이 새로운 이미지를 생성하거나, 복잡한 텍스트 프롬프트에 따라 상상 속의 장면을 구현하는 능력은 해당 개념과 세계에 대한 깊은 수준의 이해를 반영한다고 주장한다 [18:42]. 이 "이해"가 모델의 강력한 성능을 뒷받침하며, 이를 바탕으로 번역, 요약, 추론, 문제 해결 등 다양한 고수준의 인공지능 작업을 수행할 수 있게 된다.

"데이터 지향" 대 "사전 지식 지향" 모델의 스펙트럼

생성 모델은 데이터를 기반으로 학습하지만, 모델 구축에는 데이터와 사전 지식(prior knowledge)의 조합이 필요하다 [8:08]. 화자는 컴퓨터 그래픽스와 같이 물리 법칙, 광원 전송, 객체 속성 등 많은 사전 지식을 활용하는 방식과, 이 강의에서 다룰 생성 모델처럼 인터넷에서 수집된 대규모 이미지나 텍스트 데이터에 주로 의존하며 가능한 한 적은 사전 지식(예: 신경망 구조, 손실 함수)을 사용하는 "데이터 지향" 방식 사이의 스펙트럼을 설명한다 [8:27]. 이는 인공지능 모델 설계에서 데이터의 중요성을 강조하면서도, 어떤 종류의 "가이드라인" 또는 "가정"이 모델의 학습과 성능에 얼마나 영향을 미치는지에 대한 중요한 논점을 제공한다.

단일 모델로 다양한 "역문제" 해결: 제어 신호를 통한 다목적 활용

생성 모델의 강력한 특징 중 하나는 다양한 "역문제"(inverse problems)를 해결하는 데 활용될 수 있다는 점이다 [21:33]. 예를 들어, 이미지 생성 모델은 단순히 새로운 이미지를 만드는 것을 넘어, 텍스트 캡션, 스케치, 마스크 영역, 저해상도 이미지, 흑백 이미지 등 다양한 제어 신호를 입력받아 조건부 생성(conditional generation)을 수행한다 [11:50]. 이를 통해 텍스트-이미지 변환, 이미지 색상화, 초해상화, 인페인팅, 이미지 편집 등 광범위한 응용이 가능해진다. 이는 하나의 근본적인 생성 능력을 통해 여러 종류의 문제를 해결할 수 있는 모델의 다목적성을 보여주며, 다양한 현실 세계 애플리케이션에 대한 엄청난 잠재력을 시사한다.

생성 모델의 윤리적 문제: 딥페이크와 오용 가능성

화자는 생성 모델의 놀라운 발전과 함께 야기될 수 있는 윤리적 우려에 대해서도 언급한다 [41:58]. 컴퓨터가 실제와 구별하기 어려운 콘텐츠를 생성하는 능력이 향상되면서, 딥페이크(deepfakes)와 같은 현상이 발생하여 진짜와 가짜를 구분하기 어려워지는 문제가 발생한다. 이러한 기술은 악용될 소지가 많으므로, 강의에서 이 문제에 대해 논의할 필요성을 강조하며 기술 개발과 함께 윤리적 고려가 필수적임을 시사한다.

인상적인 지점

  • 파인만의 인용으로 생성 모델의 철학 설명: 리처드 파인만의 "내가 만들 수 없는 것은 이해할 수 없다"는 인용구를 생성 모델의 핵심 철학으로 연결하여, 데이터 생성 능력이 곧 이해의 척도라는 직관적인 설명을 제공한 점이 매우 인상적이다 [3:19].
  • "우주비행사가 말을 타는" 이미지: Stable Diffusion이 "우주비행사가 말을 타는 모습"이라는 캡션만으로 상상 속의 장면을 매우 그럴듯하게 구현해내는 시연은 모델의 단순한 패턴 모방을 넘어선 복합적인 개념 이해 능력을 극명하게 보여준다 [18:15].
  • 의료 영상 재구성: 생성 모델이 CT 스캔과 같은 실제 의료 기기 측정값을 제어 신호로 활용하여 의료 영상을 재구성하고, 이를 통해 환자에게 가해지는 방사선량을 줄일 수 있다는 점은 매우 실질적이고 중요한 응용 사례로 다가온다 [14:41].
